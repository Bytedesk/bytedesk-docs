# Tools 工具

微语中的 Tools，是 AI 工作流调用实际业务能力的执行层。它的核心作用，不是让模型只输出文本，而是让模型在需要时能够查询数据、触发动作、协同后端流程，从而完成真正可执行的业务操作。

## 一、微语中的 Tools 是什么

在微语的 AI 架构中，Tools 用于把模型推理和可执行能力连接起来，常见场景包括：

- 查询业务数据
- 触发服务动作
- 通过结构化接口调用领域逻辑
- 让大模型推理和后端流程协同工作

当前代码中已经存在与工具相关的机器人设置、工具配置和部分领域工具抽象，说明 Tools 已经是微语 AI 能力的重要组成部分。

## 二、当前已有基础

目前项目里已经具备一些工具能力基础：

- 机器人级别的 tools 列表与 tools 设置
- 部分模块中的后端工具抽象
- 面向外部开放 tools 与 agent 调用能力的后续规划

这意味着微语已经具备从“纯问答”走向“可执行 AI 工作流”的基础结构。

## 三、Tools 适合解决什么问题

当 AI 工作流不仅需要回答问题，还需要实际操作系统时，Tools 会非常有价值，例如：

- 查询客户资料或订单数据
- 在客服会话中获取业务记录
- 以可追踪方式调用服务端动作
- 支撑客服助手、自动化流程和 AI Copilot 场景

## 四、与其它能力页的关系

- [技能](./skills) 更偏向可复用的 AI 能力包与工作流知识。
- [MCP](./mcp) 更偏向标准协议层的外部 agent 互通。
- [文本模型指南](./model_text) 负责模型推理层配置。

## 五、总结

Tools 是微语 AI 推理层与业务执行层之间的桥梁。它是微语从简单聊天回复，走向智能助手、可执行 Agent 与业务自动化的重要基础能力。
