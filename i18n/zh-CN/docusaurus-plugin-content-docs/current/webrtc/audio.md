# 音频客服

音频客服用于在网页或应用内与客服进行实时语音沟通，适合需要快速说明问题但不方便打字的场景。

## 功能概览

当前微语音频客服页面已支持以下能力：

1. 支持访客手动发起音频呼叫，也支持通过嵌入式页面自动拉起音频客服。
2. 发起前自动检测麦克风和扬声器状态，设备未就绪时会给出明确提示。
3. 支持来电接听、拒绝、呼出取消和通话中挂断。
4. 通话过程中支持静音、查看通话状态与通话时长。
5. 音频通话接通后，可在支持的场景下继续切换到视频通话。
6. 在 iframe 嵌入场景下，支持最小化、放大、关闭窗口，以及来电提示音开关。
7. 当客服不在线时，页面会自动切换到离线留言面板，支持直接录制并提交语音留言，也支持填写文字留言表单。

## 使用前准备

1. 访客设备已连接网络，且麦克风可用。
2. 浏览器或 App 已授予麦克风权限，并可正常输出声音。
3. 客服已登录工作台并处于可接待状态。
4. 如果以嵌入方式接入，建议先确认宿主页面允许弹出音视频窗口。

如果客服暂时不在线，访客仍可通过离线留言面板提交语音留言或文字留言，无需额外跳转页面。

## 访客端：发起音频会话

1. 在会话页面点击音频通话入口。
2. 页面会先检测麦克风和扬声器；首次使用时，按提示允许浏览器访问设备。
3. 设备通过检测后，系统向客服发起音频呼叫。
4. 呼叫阶段页面会显示“正在等待对方接听语音”等状态提示，访客可随时取消。

![webrtc_auido](/img/webrtc/webrtc_auido.png)

## 自动拉起音频客服

如果项目以嵌入式方式集成微语音频客服，可以在打开页面时直接指定音频呼叫意图。页面会先完成访客信息、会话线程和设备检查，再自动发起呼叫。

这种方式适合以下场景：

1. 在业务系统中点击“一键语音客服”后直接进入呼叫页。
2. 在移动端 H5、App WebView 或 iframe 中快速拉起语音服务。
3. 需要减少访客额外点击步骤的引导式接入场景。

## 客服端：接收并接听请求

1. 客服工作台收到音频会话请求提醒。
2. 点击接听后进入语音沟通。
3. 如当前忙线，可直接拒绝；访客侧会同步收到状态变化。
4. 若访客主动取消或客服侧挂断，双方页面都会同步结束本次呼叫。

![webrtc_audio_agent](/img/webrtc/webrtc_audio_agent.png)

## 客服离线时：语音留言与文字留言

当系统检测到当前客服线程已转为离线状态时，音频客服页面不会继续停留在通话界面，而是自动切换为离线留言面板。

此时访客可进行以下操作：

1. 直接点击“开始语音留言”，系统会先播放一声短提示音，再开始录音。
2. 录音结束后，页面会自动上传语音文件，并展示可回放的音频预览。
3. 上传完成后，可点击“提交语音留言”，将语音作为离线留言提交给系统。
4. 也可以点击底部“文字留言”按钮，打开表单填写标题、内容、称呼、手机号、邮箱等信息。
5. 如果已经录好语音，再提交文字留言时，页面会一并附带已上传的语音文件。

这一模式适合以下场景：

1. 客服临时离线，但用户希望先把问题描述清楚。
2. 用户不方便长时间等待，希望先留下语音，待客服上线后回访。
3. 用户既想口述问题，也希望补充联系方式和文字说明。

## 通话中：访客端界面说明

通话过程中，访客端页面会持续展示当前通话状态，并提供以下控制：

1. 静音/取消静音：临时关闭或恢复本地麦克风。
2. 切换视频：在允许的场景下，可从音频通话升级为视频通话。
3. 挂断：主动结束当前语音会话。
4. 通话时长：接通后页面会实时显示累计时长。

如果检测到麦克风或扬声器不可用，页面会显示设备检查面板，方便访客重新检测后再继续发起或接听。

![webrtc_auido_chatting](/img/webrtc/webrtc_auido_chatting.png)

## 通话中：客服端界面说明

客服可在工作台持续语音沟通，并同步查看会话信息，提升处理效率。

![webrtc_audio_agent_chatting](/img/webrtc/webrtc_audio_agent_chatting.png)

## 嵌入式窗口能力

当音频客服页面以内嵌窗口方式打开时，顶部工具栏还支持以下操作：

1. 开启或关闭来电/呼叫提示音。
2. 最小化当前通话窗口。
3. 放大当前通话窗口。
4. 关闭窗口并回收当前会话。

## 结束通话

任意一方点击结束后，音频会话立即结束，双方返回普通会话状态。

![webrtc_auido_over](/img/webrtc/webrtc_auido_over.png)

## 常见问题

### 客服不在线时还能做什么？

1. 可以直接录制语音留言并提交。
2. 可以填写文字留言表单。
3. 可以同时提交语音和文字说明，方便客服后续回访。

### 听不到对方声音怎么办？

1. 检查系统音量和设备输出是否正确。
2. 确认浏览器或 App 没有被静音。
3. 建议切换网络后重试。

### 无法开启麦克风怎么办？

1. 检查系统隐私设置中是否允许麦克风权限。
2. 检查浏览器站点权限是否允许使用麦克风。
3. 关闭占用麦克风的其他应用后重试。

### 为什么音频客服按钮不可点击？

1. 当前会话线程尚未初始化完成。
2. 麦克风或扬声器未通过设备检测。
3. 页面正在执行设备检测或自动呼叫流程，请稍候重试。

### 为什么离线语音留言无法开始录音？

1. 浏览器未授予麦克风权限。
2. 当前浏览器不支持录音能力。
3. 麦克风正被其他应用占用，建议释放后重试。
