# 工单设置

![工单设置页面](/img/manual/admin/ticket/settings.png)

工单设置用于配置工单的基础规则、分类、SLA 与可见性。

## 页面布局

左侧为设置列表，右侧为选中设置的配置标签，并支持「外部 / 内部」范围切换。

## 配置项

| 配置项 | 说明 |
| --- | --- |
| 基础设置 | 工单基础规则 |
| 分类设置 | 工单分类与字段 |
| 流程与表单 | 绑定流程与表单 |
| SLA 设置 | 时效与服务等级 |
| 通知设置 | 状态变动通知 |
| 自动建单 | 自动创建工单规则 |
| 可见性设置 | 部门与成员可见范围 |

## 管理设置

1. 点击「创建」新建设置，或选择已有设置「编辑」
2. 配置各标签项
3. 绑定工作组
4. 「发布」后生效
