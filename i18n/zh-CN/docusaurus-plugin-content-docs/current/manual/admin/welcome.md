# 工作台首页

![工作台首页](/img/manual/admin/welcome-new.png)

工作台是登录后的默认首页，承载组织初始化与账号安全相关引导。

## 组织选择与创建

- **创建组织**：首次使用时可创建组织，填写组织信息
- **选择组织**：加入多个组织时切换当前组织

## 账号验证

通过验证邮箱与手机号提升账号安全性：

1. 在工作台点击「账号验证」
2. 验证邮箱：输入发送到邮箱的验证码
3. 验证手机号：完成图形验证并输入短信验证码

## 微信公众号订阅引导

可扫码订阅微信公众号，接收系统通知。

## 统计数据

企业版与平台版在工作台展示关键统计数据；普通版显示空态提示。
