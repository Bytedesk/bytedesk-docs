# 大模型管理

![大模型管理页面](/img/manual/admin/ai/model-new.png)

大模型管理用于配置 AI 供应商与模型。

## 页面布局

左侧为模型供应商列表，右侧为选中供应商的配置标签。

## 支持供应商

系统支持多种模型供应商，包括：Ollama、智谱 AI、DeepSeek、通义（DashScope）、硅基流动、腾讯、百度、火山引擎、MiniMax、讯飞星火、月之暗面、百川、零一万物、阶跃星辰、OpenRouter、Groq、Anthropic、OpenAI、Gemini、Coze、Dify、n8n、MaxKB、RagFlow 等。

## 配置供应商

1. 在左侧选择供应商
2. 填写该供应商的 API Key 等配置
3. 测试连接后保存

:::tip 提示
不同的模型供应商需单独配置密钥；配置完成后可在机器人或智能体中选用。
:::
