# 客服管理

![客服管理页面](/img/manual/admin/service/agent-new.png)

客服管理用于维护客服账号、接待配置与工作状态。

## 客服账号

在「客服账号」标签中查看与维护客服账号，可添加、编辑、禁用客服。

## 客服配置

在「客服配置」标签中配置客服的接待行为，包含以下子项：

- **欢迎语 / 提示信息**：访客进入会话时的问候与提示
- **服务设置 / 展示设置**：接待能力与展示样式
- **输入联想**：输入框联想设置
- **评价**：满意度评价设置
- **询前问卷 / 留言**：会话前问卷与离线留言
- **排队设置**：排队规则
- **自动已解决**：自动关闭会话规则
- **工作时间**：接待时间范围
- **坐席状态设置**：客服状态与话后整理
- **音视频**：音视频会话能力
- **智能体**：关联机器人/智能体
- **Toolbar / 快捷回复按钮 / 右侧设置**：工作台界面定制

## 客服状态

企业版在「客服状态」标签中查看客服状态日志。

## 客服席位

企业版在「客服席位」标签中管理客服席位。
