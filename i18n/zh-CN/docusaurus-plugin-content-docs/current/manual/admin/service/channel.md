# 渠道管理

![渠道管理页面](/img/manual/admin/service/channel.png)

渠道用于对接各类访客接入来源。

## 页面布局

左侧为渠道列表，右侧为选中渠道的详情配置。

## 支持渠道

系统支持多种接入渠道，包括：网页、App、微信、企业微信、飞书、抖音、小红书、微博、京东、拼多多、Messenger、WhatsApp、Telegram、Line、Email、Shopify、Lazada 等。

## 配置渠道

1. 在左侧选择渠道
2. 填写渠道对接参数
3. 保存并启用
