# 服务质检

![服务质检页面](/img/manual/admin/quality.png)

服务质检用于对会话进行质量检查与评分。

## 会话质检

包含以下子项：

| 子项 | 说明 |
| --- | --- |
| 质检 | 对会话执行质检与评分 |
| 质检结果 | 查看质检结果 |
| 申诉 | 处理质检申诉 |
| 质检统计 | 质检数据统计 |

## 人工质检配置

包含质检方案、质检任务、质检规则三部分，用于定义质检标准与任务分配。

## 智能质检

基于规则的自动质检（智能质检结果与统计），用于批量自动评分。

:::note 说明
智能质检按版本开放；质检项与规则由管理员在质检配置中定义。
:::
