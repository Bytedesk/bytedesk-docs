# 成员管理

![成员管理页面](/img/manual/admin/team/member-new.png)

成员管理用于维护组织内成员及其部门、角色与状态。

## 页面布局

左侧为部门树，右侧为成员列表。可按部门筛选成员。

## 成员字段

成员列表显示以下字段：

| 字段 | 说明 |
| --- | --- |
| 昵称 / Uid / 用户名 | 成员标识 |
| 手机 / 邮箱 / 电话 | 联系方式 |
| 部门 / 所属组织 | 组织归属 |
| 角色 | 成员角色 |
| 禁用状态 | 是否强制下线 |
| 可登录平台 | 允许登录的平台 |
| 创建 / 更新时间 | 时间信息 |

## 添加成员

1. 点击「添加成员」按钮
2. 填写成员账号、联系方式、部门与角色等信息
3. 设置可登录平台
4. 保存

## 管理成员

- **编辑**：修改成员信息
- **分配角色**：调整成员角色
- **禁用 / 启用**：禁用后成员强制下线，无法登录
- **调整部门**：将成员移动到其他部门

:::note 说明
成员的“可登录平台”决定其能访问的子系统，如管理后台、客服工作台、访客端等。
:::
