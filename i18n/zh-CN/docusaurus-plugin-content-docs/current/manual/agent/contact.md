# 通讯录

通讯录用于管理组织内成员与外部联系人，便于发起会话与查找客户。

![通讯录](/img/manual/agent/contact.png)

## 联系人分类

左侧按以下分类组织联系人：

| 分类 | 说明 |
| --- | --- |
| 组织内联系人 | 组织内的成员 |
| 外部联系人 | 访客与外部客户 |
| 新的联系人 | 最近新增的联系人 |
| 星标联系人 | 已收藏的联系人 |
| 邮箱联系人 | 通过邮箱导入的联系人 |
| 我的群组 | 我加入的群组 |
| 服务台 | 服务台相关联系人 |

## 查找与发起会话

1. 在左侧选择联系人分类
2. 在列表中找到目标联系人
3. 点击联系人可查看资料并发起会话

顶部搜索框支持按昵称、手机号、邮箱等关键词检索联系人。
