# 客服工作台快速开始

客服工作台（Agent Desktop）是客服人员日常接待客户、处理工单、协同解决问题的统一入口。本文档帮助你快速了解工作台的组成，并完成从登录到接待第一位访客的完整流程。

## 什么是客服工作台

客服工作台提供以下核心能力：

- **会话接待**：接入并通过文字、图片、文件、语音与访客沟通
- **工单处理**：从会话创建工单，跟踪处理、转派、解决与验证
- **AI 客服助手**：生成回复建议、会话总结与下一步建议
- **数据与记录**：查看会话记录、客户信息与留言

## 获取与登录

1. 向管理员获取客服账号（用户名/密码或手机号）
2. 打开客服工作台客户端或网页入口
3. 选择登录方式：账号密码、手机号验证码或扫码登录
4. 登录后系统默认进入「聊天」工作台

:::tip 提示
首次使用如遇到“无权限访问”提示，通常是账号未分配客服角色或权限，请联系管理员确认。
:::

## 界面概览

![客服工作台聊天页](/img/manual/agent/chat.png)

宽屏下工作台完整展示四栏布局：

![客服工作台宽屏布局](/img/manual/agent/chat-wide.png)

工作台左侧为**主导航**，默认包含以下菜单（按账号权限与版本显示）：

| 菜单 | 说明 |
| --- | --- |
| 聊天 | 会话工作台，接待与回复访客 |
| 工单 | 工单列表与处理 |
| 待办 | 日历与待办事项 |
| 通讯录 | 组织内与外部联系人 |
| 数据 | 会话记录、客户管理、留言管理 |
| 设置 | 个人资料、基本设置、通知 |

「聊天」页面采用四栏布局：**会话分类列表、会话列表、对话窗口、右侧面板**。窗口变窄时右侧面板、分类列表会依次收起。

## 切换接待状态

点击左下角头像，可在下拉中切换接待状态：

![接待状态切换](/img/manual/agent/status.png)

| 状态 | 说明 |
| --- | --- |
| 在线 | 接收新会话，系统继续分配新访客 |
| 小休 | 暂时休息，不再分配新访客（可选择小休原因，如会议、培训） |
| 忙碌 | 仅处理当前会话，不再分配新访客 |
| 离线 | 不接收新会话和消息 |

:::warning 注意
离线或退出前，如仍有进行中会话，系统会弹出确认提示，避免误操作丢失接待中的访客。
:::

## 一天工作流

1. **上线**：登录并将状态切换为「在线」
2. **接待**：在「排队中」会话分类接入访客，开始对话
3. **回复**：使用文字、图片、快捷回复或 AI 客服助手回复
4. **协同**：需要协助时将会话转接或邀请同事
5. **建单**：复杂问题从会话创建工单，跟踪处理
6. **结束**：问题解决后结束会话，邀请访客评价
7. **下线**：处理完进行中会话后切换为「离线」
