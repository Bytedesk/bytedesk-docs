# 会话工作台

会话工作台是客服日常接待的核心页面，包含会话分类、会话列表、对话窗口与右侧面板四部分。

![会话工作台布局](/img/manual/agent/chat.png)

## 页面布局

| 区域 | 说明 |
| --- | --- |
| 会话分类 | 按类型与状态对会话分组，快速定位待处理会话 |
| 会话列表 | 当前分类下的会话清单 |
| 对话窗口 | 与访客的消息往来与输入区 |
| 右侧面板 | 客服助手、快捷回复、访客信息、工单详情等 |

## 会话分类

常见会话分类及含义：

| 分类 | 说明 |
| --- | --- |
| 进行中会话 | 正在接待的会话 |
| 排队中 | 等待客服接入的访客 |
| 历史会话 | 已结束的会话 |
| 待处理留言 | 访客离线的留言 |
| 待处理工单 | 关联的待处理工单会话 |
| 手动接入路由 | 等待手动接入的路由池会话 |
| 机器人会话 | 机器人正在接待的会话 |
| 折叠的会话 | 折叠收纳的会话 |

默认显示：进行中会话、历史会话、排队中、全部会话、折叠的会话。

## 接入访客

访客发起咨询后会进入「排队中」会话分类。

1. 打开「排队中」分类
2. 点击目标访客右侧的「接入」按钮
3. 接入后会话进入「进行中会话」，即可开始回复

:::tip 提示
可在设置中开启「自动接入下一位排队访客」，系统会按顺序自动接入，减少手动操作。
:::

## 回复访客

在对话窗口底部输入区可发送以下内容：

- **文字**：直接输入并回车（或 Ctrl/Enter）发送
- **表情**：点击表情按钮选择
- **图片/文件**：点击上传按钮选择图片或文件
- **语音**：切换到语音输入录制并发送
- **快捷短语**：输入时自动联想快捷回复，或输入 `/` 触发快捷指令

消息发送后支持右键操作：复制、翻译、语音播放、撤回、放大阅读、添加快捷回复、下载、语音转文字、转发、收藏、多选、提醒、置顶等。

## 使用快捷回复

1. 在右侧面板打开「快捷回复」标签
2. 点击或搜索目标快捷回复
3. 内容自动填入输入框，确认后发送

快捷回复由管理员在管理后台维护，可显著提升常见问题的回复效率。

## 转接会话

需要将访客转给其他客服或工作组时：

1. 点击对话窗口顶部的「转接」按钮
2. 选择目标客服或工作组
3. 确认转接

转接后访客会话会转移到目标客服，由对方继续接待。

## 邀请同事

如需同事加入当前会话共同处理：

1. 点击对话窗口顶部的「邀请」按钮
2. 选择要邀请的同事
3. 对方接受后即可加入会话

邀请请求会在对方工作台弹出应答窗口，可选择同意或拒绝。

## 创建工单

1. 点击对话窗口顶部的「创建工单」按钮
2. 填写工单标题、问题摘要、分类、优先级、处理人等信息
3. 可选择关联当前访客会话
4. 保存后生成工单，并可在右侧面板「工单详情」中跟踪

## 会话总结

点击对话窗口顶部的「会话总结」，系统会根据对话内容生成会话小结，便于记录与交接。

## 结束会话与邀请评价

1. 点击对话窗口顶部的「结束会话」按钮
2. 确认结束
3. 可选择「邀请评价」，向访客发送满意度评价邀请

结束后会话进入「历史会话」，可随时查看历史消息。

## 右侧面板

右侧面板提供多个标签页，按需切换：

| 标签 | 说明 |
| --- | --- |
| 客服助手 | AI 回复建议、会话总结与下一步建议 |
| 快捷回复 | 快捷回复库 |
| 工单详情 | 当前会话关联的工单 |
| 流转过程 | 工单流转记录 |
| 访客信息 | 访客资料 |
| 会话信息 | 当前会话属性 |
| 历史会话 | 该访客的历史会话 |
| 历史工单 | 该访客的历史工单 |

## AI 客服助手

右侧面板的「客服助手」标签可在接待过程中实时辅助客服：

![AI 客服助手](/img/manual/agent/agent_assistant.png)

- **生成回复**：根据对话上下文生成建议回复，一键填入输入框
- **总结问题**：自动生成会话小结，便于交接与记录
- **下一步**：给出后续处理建议（如转接、建单、结束会话）

## 消息未读提醒

存在未读消息时，会话列表与导航菜单会显示未读角标，长时间未处理会弹出提醒：

![未读消息提醒](/img/manual/agent/agent_thread_unread_tip.png)

## 监控、强插与接管

企业版中，主管可对工作组会话进行监控、强插或接管：

- **监控**：旁观会话过程
- **强插**：加入会话参与回复
- **接管**：接管会话处理权

相关按钮在对话窗口顶部显示，退出后恢复。
