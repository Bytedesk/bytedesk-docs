# 登录客服工作台

![客服工作台登录页](/img/manual/agent/auth/login.png)

## 登录方式

客服工作台支持三种登录方式，可在登录页顶部切换。

### 账号密码登录

1. 输入管理员分配的账号与密码
2. 勾选隐私协议与服务条款
3. 点击「登录」

### 手机号验证码登录

1. 输入手机号
2. 点击「获取验证码」，完成图形验证并输入短信验证码
3. 点击「登录」

### 扫码登录

1. 在已登录的手机端或授权应用中打开扫码入口
2. 扫描登录页二维码完成登录

## 注册与忘记密码

- **注册**：未注册用户可点击「注册」按引导创建账号
- **忘记密码**：点击「忘记密码」，通过手机号或邮箱验证后重置密码

## 服务器切换

如需登录私有部署或其他服务器：

1. 点击登录页的「服务器切换」入口
2. 输入或选择目标服务器地址
3. 保存后重新登录

:::note 说明
服务器地址通常由管理员提供；连接失败时请检查网络与服务器地址是否正确。
:::

## 登录后

登录成功后系统进入「聊天」工作台，并显示当前账号的菜单与权限。若部分菜单不可见，说明当前账号未开通对应权限，请联系管理员。
