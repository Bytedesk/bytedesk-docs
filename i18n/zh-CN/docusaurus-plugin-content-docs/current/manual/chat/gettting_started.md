# 访客端快速开始

微语访客端用于网站、应用或业务系统中的在线咨询。您可以直接以匿名访客身份发起会话，也可以登录后查看历史会话和工单。页面中实际显示的按钮由企业管理员配置，不同咨询入口可能略有差异。

## 打开咨询窗口

访客端通常通过以下方式打开：

- 点击网站右下角的在线咨询图标，在悬浮窗口中开始对话；
- 点击企业提供的客服链接，在独立页面中打开对话；
- 从业务系统、公众号或其他页面进入嵌入式客服窗口；
- 点击通知或历史记录中的工单入口，进入“我的工单”。

打开页面后，系统会根据咨询入口自动连接对应的企业、客服工作组或机器人。请不要随意修改地址栏中的参数，否则可能无法找到正确的服务入口。

## 认识聊天界面

![访客端聊天界面](/img/manual/chat/gettting_started.png)

聊天页面主要包含以下区域：

1. **顶部栏**：显示客服或机器人名称，并提供返回、历史记录等入口。
2. **消息区**：显示欢迎语、快捷问题、排队提示以及双方的聊天记录。
3. **输入区**：输入并发送文字；根据配置还可发送表情、图片、文件或语音。
4. **扩展工具栏**：可能包含评价、留言、商品、订单、工单、平台客服和音视频通话等入口。

## 完成第一次咨询

1. 等待欢迎语和快捷问题加载完成。
2. 在输入框中描述问题，尽量同时说明使用场景、出现的现象和期望结果。
3. 点击发送按钮，等待机器人或人工客服回复。
4. 如果机器人未解决问题，点击“转人工”；人工繁忙时，页面会显示排队状态。
5. 客服离线或当前不在服务时间时，根据页面提示提交留言并填写可联系到您的方式。
6. 服务结束后，如页面出现评价邀请，可提交星级、解决情况和意见。

## 使用机器人与人工客服

机器人可能先通过欢迎语、热门问题或“猜你想问”帮助您快速定位答案。机器人回复下方可能显示“有帮助”“没帮助”或“转人工”：

- 问题已解决时，可点击“有帮助”；
- 答案不准确时，可点击“没帮助”并继续补充问题；
- 需要人工处理账号、订单或复杂业务时，点击“转人工”。

转人工后请留意排队提示。进入人工会话前重复刷新页面，可能影响当前排队和会话状态。

## 提交和跟踪工单

当问题需要后续处理时，可从工具栏进入“工单”或“我的工单”：

1. 创建工单并填写标题、问题描述、紧急程度和联系方式；
2. 根据页面要求选择问题分类、填写补充字段或上传附件；
3. 提交后在工单列表查看状态；
4. 打开详情查看处理信息和处理流程；
5. 工单解决后，根据提示确认“已解决”或“未解决”。

工单功能由企业配置。若当前入口没有显示工单按钮，可联系人工客服代为创建。

## 使用建议

- 不要在聊天内容或附件中发送密码、验证码、银行卡号等敏感信息；
- 上传图片或文件前，确认其中不包含无关的个人信息；
- 网络中断后先等待页面自动恢复，再检查消息是否发送成功；
- 需要长期跟踪的问题建议登录后提交工单，避免清理浏览器数据后无法继续查看；
- 页面功能或名称与本文不一致时，以企业当前启用的配置为准。
