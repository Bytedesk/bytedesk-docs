# 账号与密码安全

当前访客端代码已提供密码修改服务接口，但没有面向访客公开的独立“修改密码”页面或路由。因此，本页不提供不存在的界面操作步骤。

## 需要修改或重置密码时

1. 先检查登录页是否提供部署方定制的“忘记密码”或账号管理入口；
2. 若没有可用入口，请联系企业管理员或客服核验身份；
3. 由管理员按当前部署的账号策略协助重置；
4. 重置后使用新密码登录，并确认旧密码已经失效。

:::warning 注意
不要通过聊天消息发送原密码、短信验证码或其他登录凭据。客服人员也不应索要完整密码。
:::

## 保护账号

- 为不同系统使用不同密码，并定期更新重要账号密码；
- 不在公共设备上保存密码；
- 使用完成后退出账号，尤其是在共享设备上；
- 收到陌生登录通知时，及时联系管理员并修改密码；
- 私有部署用户应确认当前连接的是可信服务器地址。

## 登录异常

连续多次输入错误密码后，账号可能被临时锁定。请按照页面提示等待，不要反复尝试。无法恢复时，请向管理员提供账号和发生时间，不要提供密码。
