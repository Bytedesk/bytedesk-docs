# 聊天会话

聊天会话用于与机器人或人工客服沟通。页面按钮会根据企业配置、会话类型、客服状态和当前版本动态显示。

## 发送消息

1. 在底部输入框中输入内容。
2. 点击发送按钮或使用页面支持的发送快捷键。
3. 等待消息状态更新并查看对方回复。

![发送消息与机器人回复](/img/manual/chat/thread/thread.png)

消息仍在发送时不要重复提交。若提示发送失败，请检查网络后重试。

## 使用工具栏

![聊天工具栏](/img/manual/chat/thread/toolbar.png)

工具栏可能包含以下功能：

| 功能 | 用途 |
| --- | --- |
| 表情 | 选择并发送表情 |
| 上传 | 发送图片、文件或其他允许的附件 |
| 语音转文字输入 | 使用麦克风识别语音并填入输入框，仅在浏览器和配置支持时显示 |
| 评价 | 对当前服务发起评价；聊天记录不足时可能不可用 |
| 留言 | 客服离线或需要后续联系时提交留言 |
| 商品 / 订单 | 选择业务系统提供的商品或订单并发送给客服 |
| 工单 | 打开“我的工单”，创建或跟踪服务请求 |
| 平台客服 | 联系平台客服，仅在平台开启时显示 |

上传文件时请等待进度完成。文件类型和大小由企业配置，超出限制时页面会给出提示。

## 转人工与排队

机器人接待过程中，可点击“转人工”。系统转接成功后会提示客服即将为您服务；人工繁忙时会进入排队，并通过排队消息更新状态。

- 排队期间保持页面打开，避免反复发起转人工；
- 如需补充问题，可继续发送必要信息；
- 长时间未接入时，可按页面提示改为留言；
- 转接按钮是否出现取决于机器人和工作组配置。

## 提交留言

![留言表单](/img/manual/chat/thread/thread-2.png)

点击“留言”后，按页面要求填写姓名、联系方式、留言类型和内容。常见留言类型包括咨询、投诉、建议、技术支持、销售咨询和故障反馈等，实际选项以页面为准。

提交前请确认联系方式准确。留言提交后，服务人员会通过配置的渠道跟进；留言不等同于实时聊天回复。

## 服务评价

![满意度评价](/img/manual/chat/thread/rate.png)

当客服邀请评价或工具栏允许主动评价时：

1. 选择星级或满意程度；
2. 选择问题是否解决；
3. 输入意见后提交。

已经提交的评价可能折叠显示，避免重复操作。若聊天记录数量不足，系统可能暂不允许评价。

## 历史记录与会话结束

![历史会话列表](/img/manual/chat/thread/history.png)

登录用户可通过页面提供的历史入口查看相关记录。匿名访客的历史记录依赖当前浏览器保存的身份，清理浏览器数据后可能无法恢复。

会话结束后仍需持续跟踪的问题，可进入[我的工单](../ticket/ticket.md)查看处理进度。
