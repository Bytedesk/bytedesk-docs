# 微语文档

微语文档是微语协作平台中的办公文档模块，把**文字文档、电子表格、演示文稿、PDF 和 Markdown** 五类常用文档装进同一个工作台：创建、编辑、保存都和平时一样，同时还内置一位"随叫随到"的 AI 助手——从零起草初稿、润色文字、美化排版，一句话就能完成。

简单来说：**像使用微软 Office 一样编辑文档，像拥有秘书一样使用 AI。**

:::tip 模块说明
微语文档正在持续完善中，部分能力会分阶段上线。
:::

## 📄 支持的文档类型

| 类型 | 常见格式 | 能做什么 |
| ---- | -------- | -------- |
| 文字文档 | Word（.docx） | 撰写通知、方案、报告、周报等，支持样式、目录、图表、公式、修订与批注 |
| 电子表格 | Excel（.xlsx） | 数据记录与计算，支持公式、图表、数据透视表、条件格式 |
| 演示文稿 | PowerPoint（.pptx） | 制作汇报、培训、宣讲 PPT，支持母版、版式、智能参考线 |
| PDF | .pdf | 直接修改文字与图片、添加批注、填写表单、页面增删，还能把 PDF 转成 Word/Excel/PPT |
| Markdown | .md | 轻量笔记与文档，适合写说明、README 等 |

## 🤖 AI 助手能帮您做什么

打开任意文档左侧的"AI 助手"面板，用大白话下达指令即可。

### 生成文档内容

- **从零起草**：说一句"帮我写一份项目周报""写一篇产品发布公告""列一个活动策划提纲"，AI 直接为您写出初稿
- **续写**：接着现有内容往下写
- **填写模板**：自动找出文档里的占位符并填写

### 完善和美化文档格式

- **润色全文**：使语气更专业、表达更清晰流畅
- **AI 排版**：自动修正标题层级、统一列表格式、去除多余的加粗和斜体、补齐首行缩进——只调整格式，不改动任何文字内容
- **修改选中内容**：选中一段文字后，可以一键润色、精简、扩写、修正语法和错别字
- **批量修改**：把多处修改意见加入队列，一次发送，AI 统一处理

### 更多能力

- **总结要点**：长文档一键总结
- **生成配图 / 联网搜索 / 图片搜索**：为文档配图、查资料、插入网络图片
- **修订追踪**：AI 的改动以"修订"形式标记，可以在审阅中逐一接受或拒绝
- **版本快照**：每轮 AI 修改前自动保存快照，不满意可一键回滚

## 💼 和微软 Office / WPS 兼容吗

兼容。微语文档直接使用微软 Office 的真实格式（.docx/.xlsx/.pptx），不经过中间转换：

- 用 Word/Excel/PowerPoint 打开微语文档编辑过的文件，格式不会乱
- Word 文档采用"改了什么就只重写什么"的保存方式，未改动的内容原样保留
- 分页位置与 Word 保持一致，所见即所得

同样兼容 WPS Office：

- 用 WPS 文字 / WPS 表格 / WPS 演示打开微语文档编辑过的文件，格式不会乱
- 在 WPS 中编辑保存的文档，也可以直接在微语文档中打开并继续编辑

## ❓ 常见问题

**AI 功能需要额外配置吗？**

需要在 AI 设置中配置大模型服务。支持主流大模型（OpenAI、Claude、Gemini、DeepSeek、Kimi、GLM、通义千问等），也支持自定义 OpenAI 兼容接口接入。

**我的文档会上传到云端吗？**

文档要么保存在本地，编辑和保存均在您自己的电脑上完成；要么同步到您私有部署的微语服务器，方便团队协作与共享。只有使用 AI 功能时，相关内容才会发送给您配置的大模型服务。

**PDF 转换支持扫描件吗？**

支持。在 macOS 和 Windows 上可通过系统 OCR 识别扫描件，并转换为可编辑的 Word/Excel/PPT。

**有哪些平台？**

提供 macOS、Windows、Linux 桌面客户端，支持浅色/深色主题。

## 📌 小贴士

- AI 修改前会自动生成版本快照，大胆尝试也不用担心改坏文档
- 开启"修订追踪"后，AI 的所有改动都会留痕，适合对文档质量要求高的场景
- 选中文字后再下指令，改写默认只作用于选中部分
