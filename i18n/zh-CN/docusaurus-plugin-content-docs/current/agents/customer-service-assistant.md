# 客服助手 Agent

客服助手 Agent 是面向人工客服的 AI Copilot。它帮助客服快速理解客户背景、检索可信知识、生成回复草稿、总结会话内容，并推荐下一步服务动作，让 AI 成为客服团队的一部分，而不是替代人工服务流程。

本文档描述产品方向与实现规划，相关能力会随着微语 AI、知识库、工作流、工单和数据分析模块逐步完善并分阶段上线。

## 适用场景

- 网站客服、移动端客服、社媒私信、邮件、呼叫中心等全渠道接待过程中的实时辅助。
- 针对重复问题进行知识库检索和回复草稿生成。
- 自动生成会话小结、客户意图、情绪信号和服务质检提醒。
- 当问题需要持续跟进时，建议创建工单或升级处理。
- 根据客户上下文推荐转接、升级、补偿、回访或工作流动作。
- 当通话从 IVR 或语音服务 Agent 转人工时，为坐席提供连续接待辅助。

## 核心能力

- 上下文感知：读取会话历史、访客画像、组织、渠道、标签、订单、工单和知识库权限。
- 回复建议：基于已审核知识、FAQ 和优秀历史回复生成可编辑的回复草稿。
- 服务提醒：提示客服注意语气、缺失信息、SLA 风险、敏感词和未解决意图。
- 小结自动化：为会话关闭、工单流转、质检复盘和后续跟进生成结构化摘要。
- 动作推荐：建议创建工单、添加标签、预约回访、转接专家或触发工作流。
- 转接连续性：展示语音已采集字段、转写重点、置信度信号和下一步建议，让人工坐席不用重新询问。

## 实现规划

1. 构建会话上下文组装器，汇聚消息、访客画像、客服资料、组织设置、知识片段和订单/工单引用。
2. 为不同工作组、客服角色、渠道和服务场景配置可调整的助手提示词。
3. 在 Desktop 客服工作台中实现流式回复建议，并提供采纳、编辑、拒绝和重新生成操作。
4. 持久化已采纳建议、会话小结和质检反馈，让系统从优秀人工回复中持续学习。
5. 增加具备权限控制的工具调用能力，包括知识检索、客户查询、工单创建、订单查询和工作流执行。
6. 在呼叫中心场景中，将通话记录、录音、ASR 转写和语音 Agent 小结接入客服工作台。
7. 建立采用率、采纳率、响应时间降低、摘要准确率、转接连续性和服务质量提升等分析指标。

## 衡量指标

- 降低平均首次响应时间和会后处理时长。
- 提升一次解决率和知识命中率。
- 让新老客服都能保持更稳定的服务质量。
- 提升工单小结质量，减少跟进信息遗漏。
- 将优秀人工服务经验沉淀为可复用的知识和流程。

## 与其他 Agent 的关系

客服助手 Agent 是整套智能体系统面向人工客服的工作台。它可以调用售前 Agent 处理商品/方案咨询，调用售中 Agent 辅助订单与成交，调用售后 Agent 处理投诉和退换货，调用语音服务 Agent 获取呼叫中心上下文，也可以调用运营 Agent 进行客户分群和后续触达建议。
