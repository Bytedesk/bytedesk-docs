# 售前 Agent

售前 Agent 用于帮助访客明确需求、比较方案、获得个性化推荐，并留下高质量线索。它把被动咨询转化为有引导的成交机会，同时让人工销售团队专注处理更高价值的客户。

本文档描述产品方向与实现规划，相关能力会随着商品资料、客户画像、工作流自动化和渠道集成逐步完善并分阶段上线。

## 适用场景

- 官网、独立站、落地页中的访客购买前咨询。
- 商品、套餐、价格、功能、服务范围和行业方案对比。
- B2B、教育、医疗、零售、房产等行业的线索初筛。
- 社媒私信接待、主动建联和线索收集。
- 访客停留、浏览商品、重复搜索或表达明确意图后的主动邀请。

## 核心能力

- 意图挖掘：识别预算、使用场景、紧急程度、客户角色、地区、来源渠道和采购阶段。
- 方案推荐：根据客户需求匹配商品、套餐、解决方案、文档和知识库内容。
- 线索收集：采集姓名、电话、公司、需求、预计采购时间和偏好联系方式。
- 转化引导：推荐演示、试用、优惠、预约、表单或转人工销售。
- 风险识别：发现犹豫、异议、价格敏感、竞品比较和流失风险。

## 实现规划

1. 按组织或工作组配置售前表单、线索字段和线索评分规则。
2. 接入商品目录、解决方案文档、价格规则、FAQ 和客户案例。
3. 基于页面路径、来源、停留时长、访问次数和消息意图配置主动触发规则。
4. 将合格线索沉淀到 CRM，并关联会话、访客、渠道和负责人。
5. 支持预约演示、分配销售、发送资料、创建跟进任务等工作流动作。
6. 建立线索收集率、有效线索率、转人工率和后续成交进展等分析指标。

## 衡量指标

- 提升咨询到留资的转化率。
- 让人工跟进前获得更完整的客户信息。
- 更快响应全渠道高意向访客。
- 打通市场、售前和销售团队之间的协作。
- 减少因商品问题无人响应或响应延迟导致的流失。

## 与其他 Agent 的关系

售前 Agent 负责需求发现和线索创建。当客户准备下单时，可交给售中 Agent；当客户提出已有订单或服务问题时，可转给售后 Agent 或人工客服。
