# 语音服务 Agent

语音服务 Agent 面向实时电话服务场景，覆盖呼入接待、语音 IVR、服务受理、预约确认、工单创建、派单协同、外呼回访和客诉预警。它不是一个孤立的电话机器人，而是把电话入口纳入服务履约闭环的数字员工。

本文档描述产品方向与实现规划，相关能力会随着微语呼叫中心、ASR/TTS、工作流、工单、客户画像、订单和数据分析模块逐步完善并分阶段上线。

## 设计目标

电话服务相比文本客服实时性更强，对长回答和流程断点的容忍度更低。客户会自然表达、插话、改口、跳字段、追问旁支问题，也可能在一次通话里从报修转为投诉。因此，语音服务 Agent 要说得短、问得准、能处理打断，并且能把对话拉回服务目标。

目标是把自然语音对话转化为可执行服务流程：

1. 理解客户要解决什么问题。
2. 只追问缺失且必要的信息。
3. 将客户回答转化为结构化字段。
4. 触发正确的工作流、工单、派单、回访或人工转接。
5. 确认服务结果，并把数据反馈给运营和管理分析。

## 适用场景

- 呼入报修：识别问题，采集地址、设备型号、故障现象、紧急程度、图片或录音凭证，并创建工单。
- 报装预约：确认服务地址、可上门时间、安装条件、联系人，并同步给后续服务团队。
- 语音 IVR：识别客户口语化意图，通过自然对话引导菜单选择，回答简单问题，并在置信度低时转人工。
- 进度确认：主动外呼客户，确认工单是否已受理、已上门、延期、已解决或仍然卡住。
- 满意度回访：核实是否准时上门、问题是否解决、服务人员是否规范、收费是否一致、客户是否满意。
- 客诉预警：识别负面情绪、重复来电、承诺未兑现、异常延期和高风险表达。

## 核心能力

- 短语音交互：使用简短提示，避免长段播报，并逐项确认关键字段。
- 槽位采集：抽取身份、手机号、地址、订单号、产品、设备、故障、预约时间、紧急程度和期望结果。
- 打断处理：支持语音打断、改口、跳步骤、重复追问，并能回到未完成的服务目标。
- 流程执行：创建工单、更新工单状态、分配工作组、安排回访、发送通知并记录跟进结果。
- 人工转接：在置信度低、客户情绪高、需要政策审批或坐席忙线时，转接到合适队列或坐席。
- 完整证据链：关联通话记录、录音、ASR 转写、会话小结、工单、客户画像、回访结果和质检记录。

## 服务闭环架构

1. 呼叫接入：FreeSWITCH/Kamailio 接入呼入电话，根据组织配置路由到 IVR、语音 Agent、队列或人工坐席。
2. 实时语音层：ASR 将客户语音转为文本，Agent 决策下一步动作，TTS 生成简短语音回复，并支持打断。
3. 上下文组装：加载来电号码、访客/会员画像、组织、工作组、未结工单、近期通话、订单引用和知识库权限。
4. 意图与槽位引擎：识别场景，抽取必要字段，检测缺失字段，并在打断和改口中维护对话状态。
5. 工具与工作流层：通过具备权限控制的工具执行客户查询、订单查询、工单创建、工作流执行、回访安排和通知推送。
6. 人机协同：转人工时携带已采集字段、摘要、转写和下一步建议，避免人工坐席重新询问。
7. 复盘优化：分析完成率、转人工率、打断节点、缺失字段、负面情绪、回访结果和 Bad Case。

## 实现规划

1. 定义语音场景模板，包括报修、报装、改约、进度查询、满意度回访、客诉回访和离线留言。
2. 构建通话上下文组装器，关联来电号码、访客/会员、组织、工作组、坐席状态、工单、订单、通话记录、录音和 ASR 转写。
3. 为每个场景实现槽位定义和校验规则，包括必填字段、选填字段、确认规则和兜底提示。
4. 增加语音对话策略，包括短提示、打断恢复、改口处理、超时、静音、多次失败和按置信度转人工。
5. 接入工单创建、工单更新、工作流路由、预约排期、回访任务、订单查询和通知推送工具。
6. 持久化结构化语音结果，包括意图、槽位、小结、转接原因、工单引用、回访结果、客户情绪和质检信号。
7. 提供后台配置能力，包括启用场景、音色风格、开场白、转人工规则、队列路由、工作时间、离线留言和兜底话术。
8. 建立数据看板，跟踪自助承接率、服务完成率、转人工率、回访完成率、满意度、客诉风险、SLA 风险和字段采集质量。

## 治理与安全

- 权限边界：语音工具必须遵守组织、角色、工作组和数据范围权限。
- 写操作确认：关闭工单、修改预约、发起退款申请、撤销投诉等影响客户权益的动作，需要客户明确确认。
- 审计留痕：每次工具调用都记录输入、输出、操作者类型、关联通话、关联工单和调用原因。
- 人工可接管：人工坐席可以随时接管、修正字段、重开工单，并将 Bad Case 标记为后续优化样本。
- 隐私控制：录音、转写和敏感字段遵守组织配置的保留、脱敏和下载策略。

## 衡量指标

- 提升呼入接起率，降低放弃率。
- 提升报修或预约信息采集完成率。
- 降低因为字段缺失导致的重复沟通。
- 加快工单创建、派单和回访确认。
- 更早发现服务结果、客诉风险和 SLA 风险。
- 明确降低人工回访工作量。

## 与其他 Agent 的关系

语音服务 Agent 与客服助手 Agent、售后 Agent 共享服务上下文。它可以在转人工后让客服助手 Agent 辅助坐席继续处理，也可以调用售后 Agent 处理订单、退款、报修和投诉场景，并把回访与客诉信号同步给运营 Agent，用于客户挽回和复购运营。
