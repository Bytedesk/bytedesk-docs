# 运营 Agent

运营 Agent 用于把服务会话转化为可复用的增长资产。它帮助团队进行客户分群、发现运营机会、设计活动策略、触发精准跟进，并复盘客户全生命周期中的服务与增长效果。

本文档描述产品方向与实现规划，相关能力会随着客户数据、标签、工作流、渠道触达和数据分析模块逐步完善并分阶段上线。

## 适用场景

- 市场与运营团队希望激活存量客户，而不是只依赖新增流量。
- 服务团队从会话中发现重复需求、购买异议或产品问题。
- 管理者希望识别哪些客户需要跟进、教育、续费、挽回或关怀。
- 企业需要面向沉睡用户、高意向访客、复购用户、VIP 客户和不满意客户自动触达。
- 组织需要建立从服务数据到活动执行再到效果复盘的闭环。

## 核心能力

- 客户资产沉淀：汇聚画像、渠道、行为、会话、订单、工单、标签和满意度数据。
- 客户分群：按意图、生命周期阶段、价值、风险、商品兴趣和服务历史生成动态人群。
- 策略生成：推荐活动主题、目标人群、触达内容、触达时间、渠道和预期目标。
- 工作流执行：触发消息、任务、回访、优惠、问卷、知识推送或人工跟进。
- 复盘优化：对比活动前后的转化、留存、复购、满意度和服务工作量变化。

## 实现规划

1. 建立连接访客、用户、成员、组织、渠道、会话、订单、工单和标签的客户数据模型。
2. 增加生命周期、意图、价值、风险、满意度和渠道行为等分群定义与规则构建器。
3. 沉淀线索培育、复购、续费、防流失、投诉挽回和客户教育等运营剧本。
4. 将活动动作连接到邮件、短信、公众号通知、网页会话、社媒渠道和内部任务。
5. 增加审批、频控、退订、隐私和审计控制，确保自动触达可控合规。
6. 构建分群增长、活动转化、复购、留存、满意度和 ROI 看板。

## 衡量指标

- 从既有流量和服务会话中激活更多客户。
- 提升复购率、续费率和留存率。
- 更清楚地看到客户生命周期阶段与增长机会。
- 降低人工分群和跟进的工作量。
- 建立跨渠道可衡量的服务到增长闭环。

## 与其他 Agent 的关系

运营 Agent 消费客服助手 Agent、售前 Agent、售中 Agent 和售后 Agent 产生的信号，并把优化后的标签、活动和客户策略反馈到服务旅程中，让每个 Agent 随着业务运营持续变得更懂客户。
