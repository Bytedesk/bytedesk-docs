# 售中 Agent

售中 Agent 面向销售旅程中的成交环节，覆盖报价说明、下单引导、支付提醒、履约咨询，以及客服系统与业务系统之间的协同。它的目标是减少从咨询到交付之间的摩擦，帮助企业稳住成交过程。

本文档描述产品方向与实现规划，相关能力会随着微语对订单、支付、物流和外部业务工具的接入逐步完善并分阶段上线。

## 适用场景

- 客户询问如何购买、升级、续费或组合购买产品与服务。
- 客服或销售需要解释报价、折扣、套餐和交付周期。
- 客户在支付、确认订单或提交资料阶段犹豫。
- 服务团队需要查询订单状态、库存、发货、发票或合同进度。
- B2B 团队需要把在线咨询平滑转交给销售运营流程。

## 核心能力

- 下单引导：说明购买步骤、所需信息、支付方式和交付时间。
- 报价辅助：基于配置的商品、折扣和审批规则生成报价草稿。
- 业务查询：通过具备权限控制的工具查询订单、客户、合同、发票和物流数据。
- 履约协同：提醒待支付、资料缺失、发货延迟和审批卡点。
- 人工交接：把价格例外、商务谈判、大客户和敏感商业问题升级给人工处理。

## 实现规划

1. 定义销售阶段状态，例如有意向、已报价、待支付、已支付、履约中、异常延迟和已完成。
2. 通过受控工具层接入 CRM、订单、支付、合同、发票和物流接口。
3. 为折扣、承诺边界、退款边界和合规话术配置组织级策略提示词。
4. 实现报价草稿、订单详情、支付提醒和履约进度等结构化卡片消息。
5. 允许 Agent 为人工销售或运营团队创建跟进任务、关联工单和内部备注。
6. 从会话、订单和客户维度追踪成交与履约指标。

## 衡量指标

- 缩短从咨询到订单确认的时间。
- 降低因价格、流程或支付信息不清导致的流失。
- 提升待支付与履约异常的可见性。
- 保持跨渠道、跨客服的一致销售沟通质量。
- 让客服、销售和运营之间的交接记录更清晰。

## 与其他 Agent 的关系

售中 Agent 接收售前 Agent 识别出的成交意图，并把服务问题转交给售后 Agent。人工客服在处理业务系统问题时，也可以通过客服助手 Agent 调用售中 Agent 的能力。
