# 微语软电话工具条

微语软电话工具条是一款紧凑型的网页端 SIP 软电话，专为嵌入到已有业务系统而设计。它以工具栏的形式横跨页面顶部，占用空间极小，不会遮挡您的主界面内容。支持独立使用或通过 iframe 嵌入到第三方应用中。

与完整版软电话相比，工具条版本更加轻便，适合客服坐席、销售团队在日常工作中随时发起和接听电话，无需切换页面。

## 适用场景

| 场景 | 说明 |
| ------ | ------ |
| 系统嵌入 | 嵌入到 CRM、工单系统、ERP 等业务系统顶部，坐席无需切换页面即可接打电话 |
| 客服工作台 | 客服人员处理在线咨询的同时，随时接听客户来电 |
| 销售外呼 | 销售人员快速拨号外呼，支持转接、咨询、会议等高级通话功能 |
| 呼叫中心轻量坐席 | 无需完整呼叫中心工作台，仅需基本的通话控制能力 |

## 主要功能

### 签入与签出

工具条左上角显示当前签入状态，点击可展开菜单：

- **自动签入中**（蓝色）：页面刷新后正在使用已保存的账号自动连接和签入
- **已签入**（绿色）：SIP 注册成功，可以正常拨打和接听电话
- **已连接**（蓝色）：WebSocket 已连接但尚未注册
- **待签入**（橙色）：配置已就绪，等待签入
- **配置异常**（红色）：SIP 服务器配置获取失败
- **未配置**（灰色）：尚未填写账号信息

点击菜单中的 **账号设置** 可打开配置界面，填写 SIP 账号信息后点击 **签入** 即可上线。

![softphonebar_account_settings](/img/callcenter/softphone/softphonebar_account_settings.png)

### 拨号外呼

在工具条中间的输入框输入目标号码，按回车或点击右侧 **外呼** 按钮即可呼出。号码框支持手机号、分机号和 IVR 号码。

### 通话控制

通话建立后，工具条右侧会显示一系列操作按钮。如果按钮较多超出屏幕宽度，多余的按钮会自动折叠到“**更多**”菜单中：

- **静音 / 取消静音**：控制您的话筒，让对方听不到您的声音
- **保持 / 取回**：暂时挂起通话，双方都听不到对方
- **内线咨询**：通话中拨打内部分机，不挂断当前通话
- **转接**：将当前通话转给另一个分机或坐席
- **转 IVR**：将通话转入 IVR 语音导航流程（如满意度回访、密码验证）
- **会议**：邀请更多分机加入当前通话，组成多方通话
- **挂断 / 取消**：结束通话或取消正在发起的呼叫

![softphonebar_calling](/img/callcenter/softphone/softphonebar_calling.png)

### 接听来电

当有客户来电时，工具条会：

1. 工具条右侧的按钮区域切换为 **拒接** 和 **接听**
2. 顶部状态栏显示醒目的“**来电待接听**”提示
3. 弹出来电通知窗口，显示主叫号码信息

![softphonebar_incoming_call](/img/callcenter/softphone/softphonebar_incoming_call.png)

### 记住账号

在账号设置界面勾选“记住账号和密码，并在刷新后自动签入”，系统会将您的 SIP 账号信息保存在浏览器本地。下次打开页面时，工具条会自动完成连接和签入，状态栏会短暂显示“自动签入中”。

清除自动登录：取消勾选后点击签出，本地保存的账号信息将被删除。

## 集成方式

微语软电话工具条通过 URL 参数控制，可直接以 iframe 方式嵌入到任何网页中。

### 基本链接格式

```bash
https://cdn.weiyuai.cn/call/phone-bar?lang=zh-cn&mode=light&org=组织ID&visitorUid=访客ID&nickname=昵称&avatar=头像地址
```

### 参数说明

| 参数 | 必填 | 说明 |
| ------ | ------ | ------ |
| `lang` | 否 | 界面语言，支持 `zh-cn`（简体中文）、`zh-tw`（繁体中文）、`en`（英文） |
| `mode` | 否 | 主题模式，`light` 为浅色，`dark` 为深色 |
| `org` | 是 | 组织 ID，用于自动获取 SIP 服务器配置 |
| `visitorUid` | 是 | 访客唯一标识，用于关联通话记录 |
| `nickname` | 否 | 坐席显示名称，会显示在来电通知中 |
| `avatar` | 否 | 坐席头像地址 |

### 嵌入示例

**iframe 嵌入（推荐宽度 ≥ 800px）：**

```html
<iframe
  src="https://cdn.weiyuai.cn/call/phone-bar?lang=zh-cn&mode=light&org=df_org_uid&visitorUid=agent_001&nickname=客服小王"
  width="100%"
  height="56"
  style="border: none"
/>
```

> ⚠️ 建议将 iframe 高度设置为 `56px` 以上，以保证工具栏内容完整显示。来电时高度会自动扩展以显示提示信息。

**新窗口打开：**

```html
<a href="https://cdn.weiyuai.cn/call/phone-bar?lang=zh-cn&mode=light&org=df_org_uid&visitorUid=agent_001&nickname=客服小王" target="_blank">
  打开软电话工具条
</a>
```

## 完整版 vs 工具条版

| 特性 | 微语软电话（完整版） | 微语软电话工具条 |
| ------ | ---------------------- | ------------------- |
| 形态 | 独立全页应用 | 紧凑工具栏，嵌入页面顶部 |
| 拨号方式 | 可视化数字键盘 + 输入框 | 输入框 + 回车 / 按钮外呼 |
| 通话控制 | 外呼、挂断 | 静音、保持、咨询、转接、转 IVR、会议、挂断 |
| 合适场景 | 独立使用、全屏嵌入 | 嵌入现有系统、不占主界面空间 |
| 推荐宽度 | ≥ 420px | ≥ 800px |
| DTMF 支持 | ✅ 通话中数字键盘 | ❌ |
| 高级通话动作 | ❌ | ✅ 内线咨询、转接、会议等 |

## 常见问题

### 工具条显示不全怎么办？

工具条支持自适应宽度。当浏览器窗口较窄时，右侧操作按钮会自动折叠到“更多”菜单中。建议 iframe 宽度不低于 800px 以获得最佳体验。

### 如何切换账号？

点击工具条左上角的状态按钮，选择“账号设置”，修改账号信息后点击“签入”即可。如果已签入，请先点击“签出”断开当前账号。

### 可以和完整版软电话同时登录吗？

工具条和完整版软电话使用独立的本地存储，互不影响。但如果 SIP 服务器不支持同一分机号多次注册，建议只在一个端上登录。
