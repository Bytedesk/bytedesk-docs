# 留言处理

## 概述

当客服不在线时，系统会自动显示留言表单，收集用户的留言信息和联系方式。通过配置 Webhook URL，可以将这些留言消息推送到多种平台，确保及时处理用户需求。

### 主要功能特性

- **自动留言收集**：客服离线时自动显示留言表单
- **自定义留言表单**：支持按组织配置发布后的自定义表单，访客端按表单 schema 动态渲染字段
- **多渠道通知**：支持企业微信、飞书、钉钉等多种通知方式
- **图片留言支持**：访客可发送图片进行留言
- **离线备援路由**：支持离线后按“备援客服 → 备援工作组 → 机器人”顺序继续承接会话
- **历史记录查看**：访客可查看历史留言及回复
- **实时回复**：客服可及时回复访客留言

### 使用场景

- 客服下班时间或节假日
- 客服繁忙无法及时回复
- 需要收集用户详细需求信息
- 跨时区客服服务

### 自定义留言表单

管理员可以在后台为留言场景绑定“自定义表单”。启用后，访客端不再固定显示默认的姓名、联系方式、留言内容等写死字段，而是根据已发布表单的 schema 动态渲染输入项。

典型配置步骤如下：

1. 在流程表单设计器中创建一个类型为 `MESSAGE_LEAVE` 的表单。
2. 将表单发布为 `PUBLISHED` 状态。
3. 在服务设置的“留言设置”中开启“启用留言表单”。
4. 如需使用自定义字段，再开启“使用自定义表单”，并选择刚刚发布的表单。

推荐在自定义表单中至少保留以下关键信息，便于后续处理：

- 联系人姓名或昵称
- 手机号、邮箱等至少一种联系方式
- 留言内容或问题描述
- 问题类型、来源、优先级等业务字段

### 留言开关行为说明

留言相关开关会直接影响访客端展示逻辑：

- 开启“启用留言表单”后，访客在离线留言消息中可以直接填写并提交留言。
- 关闭“启用留言表单”后，访客端不会再显示留言表单，也不会额外提供继续留言的按钮或抽屉入口。
- 开启“使用自定义表单”且已选择有效表单后，离线留言消息会展示自定义字段，而不是默认内置字段。
- 如果自定义表单未启用、未发布，或未选中有效表单，则系统回退为默认留言表单。

### 自定义字段保存说明

当前留言提交接口会优先提取并保存标准字段，例如姓名、联系方式、留言类型、留言内容和图片。

- 标准字段会作为独立字段存储，便于后台筛选和处理。
- 其余自定义字段会随留言正文一起保存，便于客服在留言详情中统一查看。

这意味着，即使自定义表单包含标题、回访方式、扩展备注等附加字段，客服端仍然可以在留言内容中看到这些值。

## 管理后台功能

### 留言管理

![leavemsg_admin](/img/develop/leavemsg/leavemsg_admin.png)

管理后台提供完整的留言管理功能：

- **留言统计**：查看留言数量、处理率等数据
- **分类管理**：按类型、状态、时间等分类查看
- **批量操作**：批量处理、删除、导出留言
- **权限控制**：设置不同角色的留言处理权限

### 留言设置配置项

在管理后台的服务设置中，可以为留言场景配置以下能力：

- **留言提示语**：用于离线时展示给访客的说明文案
- **启用留言表单**：控制访客端是否允许直接提交留言
- **使用自定义表单**：切换为发布后的 schema 表单
- **自定义表单选择**：绑定指定的留言表单
- **备援客服**：工作组离线时优先尝试转给指定客服
- **备援工作组**：备援客服不可用时继续尝试转给指定工作组

离线接待的优先顺序为：

1. 备援客服
2. 备援工作组
3. 机器人或系统默认离线处理逻辑

如果前一环节可正常接待，则不会继续进入下一环节。

## 常见问题

**Q: 如何设置留言自动通知？**
A: 在管理后台配置Webhook URL，选择对应的通知平台（企业微信、飞书、钉钉等），系统会在收到新留言时自动推送通知。

**Q: 访客可以删除自己的留言吗？**
A: 目前访客无法删除已发送的留言，如需删除请联系客服或管理员。

**Q: 留言有保存期限吗？**
A: 留言数据会永久保存，管理员可以在后台设置自动归档规则。

**Q: 支持多语言留言吗？**
A: 是的，系统支持多语言界面，访客可以使用不同语言进行留言。
