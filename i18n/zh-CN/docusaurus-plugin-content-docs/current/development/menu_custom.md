# 自定义左侧菜单

微语系统支持在管理后台为客服工作台自定义左侧菜单，并支持按组织套餐、菜单状态动态显示或隐藏。

这个能力适合以下场景：

- 为不同租户追加企业内部系统入口，例如 CRM、工单平台、知识库门户、BI 报表等。
- 统一控制客服工作台左侧菜单的显示范围，避免不同套餐看到相同功能。
- 将已有内置菜单按需隐藏，只保留当前组织真正使用的入口。

从实现上看，这套能力分成两部分：

- 管理后台超级管理员菜单页负责创建、编辑、删除、隐藏和重置菜单。
- 客服工作台启动后会拉取 DESKTOP 类型菜单，并根据组织会员等级和菜单启用状态决定最终是否展示。

![menu_super](/img/menu/menu_super.png)

## 功能说明

当前自定义菜单的核心规则如下：

1. 仅当菜单类型为 DESKTOP 时，才会进入客服工作台左侧菜单的加载逻辑。
2. 菜单启用状态为开启，且组织会员等级大于等于菜单配置的会员等级时，菜单才会显示。
3. 如果菜单链接以 / 开头，系统会把它当作工作台内部路由，用来控制内置菜单显示或隐藏。
4. 如果菜单链接不是以 / 开头，系统会把它当作外部地址，并在左侧新增一个自定义菜单入口。
5. 平台级默认菜单允许调整显示状态和会员等级，但不会开放所有基础字段的随意修改。

简单理解就是：

- 用内部路由可以“控制已有菜单是否显示”。
- 用外部链接可以“新增一个菜单入口”。

## 主要字段说明

创建或编辑菜单时，界面上实际参与生效的字段主要有：

- 名称：菜单的基础名称。
- 描述：菜单备注说明，便于后台维护。
- 上级菜单：支持建立一级、二级菜单关系，管理后台表格会按树形结构展示。
- 昵称：用于填写国际化 key。前端渲染时会优先使用昵称对应的国际化文案，未命中时再回退到名称。
- 级别：支持平台级和组织级。平台级更适合配置默认能力，组织级更适合租户个性化菜单。
- 类型：当前客服工作台自定义菜单主要使用 DESKTOP。
- 链接：决定菜单最终跳转到内部页面还是外部地址。
- 会员等级：组织会员等级大于等于该值时，菜单才显示。
- 启用：控制该菜单是否对前端生效。

另外，菜单模型中还预留了图标、颜色、排序、新窗口打开等字段，当前页面主要开放的是最常用配置项；其中外部链接在客服工作台默认以新窗口方式打开。

## 为客服工作台创建菜单

在管理后台创建菜单时，建议优先确认这是“新增外部入口”还是“控制内置菜单显示”：

- 如果要新增一个外部系统入口，链接填写完整 URL，例如 [https://crm.example.com](https://crm.example.com)。
- 如果要控制工作台原有菜单是否显示，链接填写对应内部路由，例如 /chat、/ticket、/data、/setting。
- 如果需要做套餐隔离，可以同时设置会员等级，结合 [SaaS多租户套餐设置](./menu_viplevel.md) 一起使用。

创建完成后，菜单数据会保存到菜单管理表中，后续可以继续修改启用状态、会员等级或上级菜单关系。

![menu_agent_create](/img/menu/menu_agent_create.png)

## 在管理后台查看已经创建的菜单

创建成功后，可以在菜单列表中统一查看和维护：

- 列表支持按树形结构展示父子菜单。
- 可以查看菜单名称、昵称、级别、会员等级、类型、链接、创建时间等信息。
- 可以直接在列表中切换“显示/隐藏”状态。
- 可以执行编辑、删除，以及恢复默认菜单。

其中“重置默认”会重新恢复系统默认菜单配置，适合在测试后快速回滚到初始状态。

![menu_agent_table](/img/menu/menu_agent_table.png)

## 在客服工作台查看新增菜单

客服工作台加载菜单时，会按下面的顺序处理：

1. 拉取当前组织下的 DESKTOP 菜单。
2. 读取当前组织的会员等级。
3. 过滤掉未启用或会员等级不满足的菜单。
4. 将内部路由映射为内置菜单显示控制。
5. 将外部链接追加到左侧导航，形成新的菜单入口。

因此，只要菜单状态开启、会员等级满足、链接配置正确，客服工作台左侧就会立即出现对应入口。

![menu_agent_show](/img/menu/menu_agent_show.png)

## 在管理后台隐藏已有菜单

如果某个菜单暂时不希望被租户看到，可以直接把“显示”开关关闭。关闭后：

- 对于内置菜单，对应左侧入口会被隐藏。
- 对于外部自定义菜单，对应新增入口不会再显示。

这种方式适合临时下线功能、灰度开放菜单，或者按组织套餐差异控制页面入口。

![menu_admin_hide](/img/menu/menu_admin_hide.png)

## 在管理后台显示已有菜单

重新打开“显示”开关后，只要当前组织满足会员等级条件，菜单就会再次出现在客服工作台左侧。

如果开关已打开但前端仍未显示，请重点检查下面几项：

1. 菜单类型是否为 DESKTOP。
2. 菜单链接是否正确，内部路由必须以 / 开头。
3. 组织会员等级是否达到菜单配置的会员等级。
4. 当前登录账号是否进入了正确的组织。

![menu_admin_show](/img/menu/menu_admin_show.png)

## 注意事项

1. 平台默认菜单不建议直接改动基础路由和类型，通常只调整显示状态和会员等级即可。
2. 菜单昵称建议填写已有国际化 key，这样在不同语言环境下可以自动翻译显示名称。
3. 外部链接默认作为新增菜单入口使用，更适合挂接第三方系统或企业内部地址。
4. 内部路由更适合控制系统原生菜单是否展示，不建议随意填写不存在的前端路由。
5. 如果你的目标是按租户套餐控制菜单显示，建议同时阅读 [SaaS多租户套餐设置](./menu_viplevel.md)。
