# 客服端/管理端工单

## 功能简介

工单管理是面向客服团队的核心工具，用于将"临时对话中的问题"沉淀为"可追踪的任务"，从创建到解决全流程可视化、可协作、可追溯。

### 核心价值

- **问题沉淀**：会话中的复杂问题不再丢失，自动转为可跟踪的工单
- **流程管理**：支持灵活的工单流程配置，适配不同业务场景
- **责任明确**：通过状态、优先级、负责人来量化进度与责任
- **多渠道通知**：工单状态变更时自动推送站内信、邮件、短信等通知

## 适用场景

- 会话中遇到复杂问题，需要跨部门配合处理
- 问题不能一次性解决，需要后续跟进与回访
- 需要 SLA 管控和超时提醒的工单场景
- 希望用状态、优先级、负责人来量化进度与责任

## 快速上手

### 1. 管理后台配置

在管理后台完成以下配置：

1. **启用工单功能**：进入「工单设置」，创建工单模板
2. **配置基础设置**：设置工单编号规则（前缀 + 长度）、默认优先级、联系方式字段显示/必填
3. **配置分类**：在「分类设置」中创建工单分类树，支持拖拽排序
4. **配置流程**：在「流程管理」中设计工单流程
5. **绑定工作组**：将设置模板绑定到对应的工作组

### 2. 客服端创建工单

在桌面客服端：

1. **从会话创建**：在聊天界面点击工单图标，一键带入会话信息和客户资料
2. **填写信息**：标题（必填）、描述、分类、优先级、负责人、附件等
3. **提交工单**：工单自动关联来源会话与客户

### 3. 跟进处理

1. 在「工单管理」页面查看待处理工单列表
2. 认领工单后开始处理，在工单详情中更新进展
3. 通过状态流转操作变更工单状态
4. 工单解决后通知客户验证

## 工单状态流转

工单支持完整的生命周期管理，状态流转由流程引擎驱动。

### 状态说明

| 状态 | 说明 |
| --- | --- |
| 新建 | 工单刚创建，等待分配 |
| 已分配 | 已分配给指定处理人 |
| 已认领 | 处理人已认领工单 |
| 已退回 | 处理人退回工单到工作组 |
| 处理中 | 处理人正在处理 |
| 已转派 | 已转派给其他处理人 |
| 待响应 | 等待客户响应或补充信息 |
| 挂起 | 暂时挂起 |
| 已恢复 | 从挂起恢复 |
| 已重开 | 已关闭工单重新打开 |
| 已解决 | 问题已解决 |
| 已升级 | 升级处理 |
| 已关闭 | 工单已关闭 |
| 已取消 | 工单已取消 |
| 验证通过 | 解决方案验证通过 |
| 验证失败 | 解决方案验证不通过 |

### 客服端常用操作

| 操作 | 说明 |
| --- | --- |
| 认领工单 | 将工单分配给自己处理 |
| 开始处理 | 标记开始处理工单 |
| 退回工单 | 退回工单到工作组 |
| 转派工单 | 将工单转派给其他客服 |
| 挂起工单 | 暂时挂起处理 |
| 恢复工单 | 从挂起恢复处理 |
| 待客户响应 | 标记为等待客户回复 |
| 解决工单 | 标记问题已解决 |
| 关闭工单 | 关闭已完成的工单 |
| 重开工单 | 重新打开已关闭的工单 |
| 委托工单 | 委托给其他成员协助处理 |

## 优先级

| 优先级 | 说明 |
| --- | --- |
| 最低 | 不紧急的问题 |
| 低 | 一般问题 |
| 中 | 普通问题 |
| 高 | 需要优先处理 |
| 紧急 | 需要尽快处理 |
| 严重 | 需要立即处理 |

## 工单类型

| 类型 | 说明 |
| --- | --- |
| 内部工单 | 组织内部成员创建的工单 |
| 外部工单 | 访客或客户通过客户端提交的工单 |

## 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 标题 | 是 | 简明描述问题核心 |
| 描述 | 否 | 补充复现步骤、期望结果、截图等 |
| 分类 | 否 | 按业务线或问题类型归类 |
| 优先级 | 否 | 从最低到严重六级可选 |
| 负责人 | 否 | 明确处理人，支持转派与协作 |
| 联系人 | 否 | 联系人姓名（外部工单） |
| 联系电话 | 否 | 用于通知推送 |
| 邮箱 | 否 | 用于邮件通知 |
| 关联会话 | 自动 | 自动关联来源会话，支持多工单关联同一会话 |
| 附件 | 否 | 上传日志、截图、文件（支持多附件） |

## 工单设置模板

管理后台支持创建多套工单模板，灵活适配不同业务场景。

### 模板配置能力

| 配置模块 | 说明 |
| --- | --- |
| 基础设置 | 编号规则、默认优先级、有效期、自动关闭、分配方式、联系方式字段 |
| 分类设置 | 多级分类树，支持增删改、拖拽排序、启用/禁用 |
| 通知设置 | 邮件/站内信通知模板，按状态变更触发 |
| 流程设置 | 关联工单流程定义，灵活配置流转规则 |
| 自定义表单 | 按需添加自定义字段，适配不同业务场景 |

### 草稿与发布

设置模板支持**草稿**和**正式版本**分离：

- 修改自动保存为草稿，不影响线上使用
- 点击「发布」将草稿发布为正式版本
- 支持按工作组维度独立发布

## 通知推送

工单状态变更时自动推送通知，支持多渠道：

| 通知渠道 | 触发场景 |
| --- | --- |
| 站内信 | 新工单、分配、状态变更、新回复 |
| 邮件 | 工单创建、状态变更 |
| 短信 | 重要工单状态变更 |
| 移动推送 | 推送至 iOS/Android 客服端 |
| 桌面通知 | 客服端实时弹窗提醒 |

## 小技巧

- 在会话侧边栏可快速查看该会话关联的所有工单
- 结合模板可提升登记效率与规范性
- 配合"会话小结"记录关键信息，便于交接与复盘
- 工单详情支持查看完整的状态流转轨迹（时间线展示）
