# 知识库多语言翻译

微语知识库支持将 FAQ、文本、切块、网页等知识内容一键翻译为多种语言，实现多语言知识检索与智能问答，帮助出海企业快速构建国际化知识服务体系。

## 功能概述

知识库翻译功能利用大模型（LLM）自动将知识库中的内容翻译为目标语言，翻译结果会自动纳入全文检索（Elasticsearch）和向量检索，使多语言用户能够用自己的母语搜索知识库并获得准确回答。

### 核心特性

- **一键翻译**：在 FAQ、文本、切块、网页等管理页面，点击翻译按钮即可触发大模型翻译
- **多语言支持**：支持中文、英文、日文、韩文、法文、德文、西班牙文等十余种语言
- **自动索引**：翻译成功后自动更新全文索引和向量索引，无需手动操作
- **翻译管理**：集中查看和管理所有翻译记录，支持编辑和重新翻译
- **多语言问答**：系统支持将翻译后的知识内容按目标语言建立全文和向量索引；在传入语言偏好时，可优先检索对应语言内容并返回该语言答案

## 使用流程

### 1. 配置目标语言

在知识库设置中，配置需要翻译的目标语言列表。

系统支持同时配置多种目标语言，翻译任务会为每种语言生成独立的翻译记录。

### 2. 触发翻译

在知识内容管理页面（FAQ、文本、切块、网页），每条记录的操作列都有翻译按钮，点击后系统会调用配置的翻译大模型，自动生成对应语言的翻译内容。

![kbase_translate](/img/kbase/translate/kbase_translate.png)

### 3. 查看翻译结果

翻译完成后，在翻译管理页面可以查看所有翻译记录。

翻译记录包含：

- **源语言/目标语言**：翻译的语言对
- **翻译状态**：NEW（待翻译）、PROCESSING（翻译中）、SUCCESS（成功）、ERROR（失败）
- **翻译内容**：标题、正文、摘要等翻译结果
- **翻译提供商**：使用的翻译模型名称

![kbase_translate_result](/img/kbase/translate/kbase_translate_result.png)

### 4. 搜索测试验证

在搜索测试页面，可以用目标语言进行搜索，验证翻译内容是否被正确索引和检索。

## 翻译内容检索

翻译成功的内容会自动纳入搜索体系：

### 全文检索（Elasticsearch）

每条成功的翻译会作为独立的 ES 文档存储，包含 `translated=true` 标记和目标语言字段。搜索时会同时匹配原文和所有翻译文档。

### 向量检索

翻译内容同样会被向量化存储，语义搜索时会自动匹配对应语言的内容向量。

### 机器人问答

系统支持将翻译后的知识内容按目标语言建立全文和向量索引；在传入语言偏好时，可优先检索对应语言内容并返回该语言答案。

## 翻译管理

### 翻译列表

翻译管理页面（`管理后台 → 知识库 → 大模型 → 翻译管理`）提供：

- 按知识库、源类型、状态、语言等筛选
- 支持编辑翻译内容
- 支持删除翻译记录
- 支持重新翻译

### 翻译内容编辑

点击编辑按钮可以手动修改翻译内容，修改后自动更新索引。

### 翻译状态跟踪

翻译状态说明：

- **NEW**：待翻译，翻译占位已创建但内容为空
- **PROCESSING**：大模型正在处理翻译
- **SUCCESS**：翻译成功，已自动索引
- **ERROR**：翻译失败，可查看错误信息后重试

## 技术实现

### 翻译流程

```bash
用户点击翻译 → 创建翻译记录(NEW) → 调用LLM翻译 → 更新状态(SUCCESS/ERROR)
                                                          ↓
                                                    自动更新ES索引
                                                    自动更新向量索引
```

### 自动索引

翻译状态变为 SUCCESS 后，系统自动触发：

1. 源实体（FAQ/Text/Chunk/Webpage）的 Elasticsearch 全文索引更新
2. 源实体的向量索引更新

翻译内容作为独立的索引文档存储，与原文共存，搜索时统一匹配。

## 常见问题

### 翻译支持哪些内容类型？

支持 FAQ（常见问题）、TEXT（文本）、CHUNK（文档切块）、WEBPAGE（网页）四种类型。

### 翻译使用哪个模型？

默认使用阿里百炼 Qwen-MT 翻译模型，支持在 Robot 设置中自定义翻译智能体的模型和提示词。

### 翻译内容会影响原文吗？

不会。翻译内容独立存储，原文保持不变。

### 如何验证翻译是否被正确索引？

在知识库搜索测试页面，选择目标语言进行搜索，如果翻译内容被召回且 score > 0，说明索引正常。
