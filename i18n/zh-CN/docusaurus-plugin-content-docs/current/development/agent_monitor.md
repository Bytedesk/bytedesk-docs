# 客服监控、强插 以及 接管

:::tip 提示
社区版暂不支持该功能，请升级到企业版或平台版后使用。
:::

## 概述

微语客服系统支持主管、班长、质检人员或资深客服对正在进行中的工作组会话进行实时协作管理。围绕这一能力，系统提供了三个核心动作：监控、强插、接管。

这三个动作对应三种不同的介入深度：

- 监控：只看不回，用于旁听、质检、培训和现场指导
- 强插：加入协作，可参与回复，但不替换当前主接待客服
- 接管：直接成为当前会话的主接待客服，接手后续服务

通过这套能力，团队可以在不打断客户沟通的前提下，完成服务监督、应急支援、带教培训和复杂问题升级处理。

### 界面说明

- 监控会话入口位于桌面客服端左侧会话分类区域
- 进入监控模式后，可查看已授权监控的工作组会话列表
- 顶部支持按一个或多个工作组筛选监控范围
- 选中会话后，可在会话头部执行监控、强插或接管操作

## 核心价值

- 服务质检：主管可实时查看一线接待情况，及时发现服务风险
- 带教培训：资深客服可先监控，再根据需要进入强插或接管
- 升级处理：遇到复杂问题时，可由更高权限或更高经验人员快速介入
- 风险兜底：面对投诉、危机客户或重大商机时，可即时接管避免失控

## 功能区别

### 监控

监控是最轻量的介入方式。进入监控后，客服可以实时查看当前会话内容和进展，但不直接作为当前接待人进行回复。

**适用场景：**

- 主管抽检服务质量
- 新人培训与现场带教
- 复杂问题先观察上下文再决定是否介入
- 重要客户会话旁路关注

**特点：**

- 不改变当前会话主接待客服
- 以观察为主，适合低干扰场景
- 是强插和接管前的常见准备动作

### 强插

强插表示当前人员正式加入会话协作，可以在会话中参与处理，但不会替换掉原本的主接待客服。

**适用场景：**

- 专家协助一线客服共同处理问题
- 资深客服边指导边参与回复
- 跨部门配合，需要多人共同服务同一客户

**特点：**

- 会话主接待客服不变
- 当前介入人员可以参与回复和协作
- 适合“协同处理”，不适合“彻底换人”

### 接管

接管表示当前人员直接成为该会话新的主接待客服，后续会话由接管人主导处理。

**适用场景：**

- 客户投诉升级，需要主管亲自处理
- 当前客服无法继续服务，需要立即换人
- 涉及高价值客户、重大商机或高风险情形
- 当前问题已超出一线客服能力范围

**特点：**

- 会替换当前主接待客服
- 接管后由新的主接待客服负责后续服务
- 属于最强介入方式，应谨慎使用

## 三者对比

| 功能 | 是否可查看会话 | 是否可参与回复 | 是否替换当前主接待客服 | 典型用途 |
| --- | --- | --- | --- | --- |
| 监控 | 是 | 否 | 否 | 质检、旁听、培训 |
| 强插 | 是 | 是 | 否 | 协同处理、专家支援 |
| 接管 | 是 | 是 | 是 | 升级处理、主管接手 |

## 使用前提

在使用客服监控能力前，需要先完成以下准备：

1. 系统版本为企业版或平台版。
2. 当前账号具备相应的客服或管理权限。
3. 已在客服资料中配置可监控的工作组。
4. 当前工作组中存在进行中的客户会话。

## 管理员配置建议

为了让监控、强插和接管功能真正可用，建议管理员按以下思路完成配置：

1. 先梳理哪些工作组需要被主管或质检人员监控。
2. 在客服资料中，仅为特定人员分配可监控工作组。
3. 优先将权限授予主管、组长、培训导师、质检专员等角色。
4. 避免将全部工作组一次性开放给所有客服，防止越权查看。
5. 对投诉升级、高价值客户、重大商机等场景，提前制定接管标准。

如果企业内部有多条业务线，建议按业务线、团队或区域分别配置监控范围，既能保证管理效率，也能减少无关会话干扰。

## 使用流程

### 第一步：配置可监控工作组

管理员需要先在客服资料中为对应客服配置可监控的工作组。只有被授权的工作组，其会话才会出现在监控列表中。

建议由管理员统一规划监控授权范围，优先按工作组、班组或业务线进行分配，避免监控范围过大影响管理效率。

建议将该权限授予以下角色：

- 主管
- 组长
- 质检人员
- 培训导师
- 需要进行跨组支援的高级客服

### 第二步：进入监控会话列表

在桌面客服端中，进入会话列表后点击“监控会话”菜单，系统会加载当前账号有权限监控的工作组以及这些工作组下的进行中会话。

如果配置了多个监控工作组，顶部会显示工作组下拉选择框，支持：

- 选择单个工作组，查看该组会话
- 同时选择多个工作组，合并查看多个组的会话
- 取消部分选择，快速缩小监控范围

这样可以避免在工作组较多时列表过长，便于主管按团队维度快速筛选。

如果当前账号未配置任何可监控工作组，则该列表不会显示可操作的监控对象。

### 第三步：选择需要介入的会话

在监控会话列表中点击目标会话，右侧会展示该会话的聊天详情。

如果当前会话满足监控条件，聊天头部会显示可操作按钮：

- 监控
- 强插
- 接管

系统会根据当前人员在该会话中的角色自动调整可见按钮。例如：

- 如果已经是主接待客服，则不会再显示这三个按钮
- 如果已经处于监控状态，则不会重复显示“监控”
- 如果已经作为协作者加入，则通常只保留“接管”这类仍有意义的动作

当前该能力仍处于测试阶段，系统仅在测试开关开启时显示相应按钮入口。

### 第四步：执行具体动作

#### 使用监控

适合先观察后决策。

操作方式：

1. 打开目标会话。
2. 点击“监控”。
3. 系统将当前账号加入该会话的监控角色。
4. 后续可持续查看会话进展，并根据情况决定是否升级为强插或接管。

#### 使用强插

适合需要立即参与协同处理，但不希望替换原客服的场景。

操作方式：

1. 打开目标会话。
2. 点击“强插”。
3. 系统将当前账号加入协作角色。
4. 当前主接待客服保持不变，双方可共同处理该客户问题。

#### 使用接管

适合需要彻底接手服务的场景。

操作方式：

1. 打开目标会话。
2. 点击“接管”。
3. 系统将当前账号设为新的主接待客服。
4. 后续该会话由接管人主导处理。

## 典型场景

### 场景一：新人接待，主管旁听

新人客服正在接待客户，主管先通过“监控”观察沟通情况。在确认客户问题较复杂后，主管可视情况使用“强插”协助处理。

### 场景二：复杂技术问题，专家协同

一线客服接待到复杂问题时，技术型客服或资深客服可以通过“强插”加入会话，在不打断原接待流程的情况下共同完成服务。

### 场景三：投诉升级，主管接手

当客户情绪激动或投诉升级时，主管可直接使用“接管”，迅速成为主接待客服，统一后续沟通口径和处理节奏。

## 使用建议

- 先监控，再决定是否需要强插或接管，避免过度干预一线客服
- 强插适合协同，接管适合升级，不建议混用概念
- 对高价值客户和投诉场景，建议建立明确的接管标准
- 在培训场景下，优先采用监控和强插，减少直接替换造成的学习中断
- 对主管和质检人员建议按工作组维度配置权限，避免监控范围过大

## 常见问题

### 为什么我看不到“监控会话”入口？

可能原因包括：

- 当前版本不是企业版或平台版
- 当前账号没有配置可监控工作组
- 当前账号不具备相应权限
- 当前工作组下没有正在进行中的可监控会话

### 为什么我看不到“监控 / 强插 / 接管”按钮？

可能原因包括：

- 当前会话不在监控上下文中
- 当前会话不是工作组会话
- 当前账号已经是该会话主接待客服
- 当前账号当前角色下没有可继续执行的动作

### 我应该优先用强插还是接管？

如果只是协助当前客服处理问题，优先使用强插；如果需要由你来主导后续服务，则使用接管。
