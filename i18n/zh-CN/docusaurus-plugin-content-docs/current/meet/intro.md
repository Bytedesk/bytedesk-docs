# 微语会议

微语会议（Bytedesk Meet）是微语生态中的开源会议系统：会议开在自己的服务器上，数据不经过第三方；用公司现有的微语账号登录即可，无需另外注册。打开浏览器就能开会，无需安装任何软件。

现在的会议是统一且音频优先的：**创建会议室、分享邀请链接、默认纯音频加入会议**——进入会议不会弹出摄像头授权。会议中任何人都可以随时开启摄像头或共享屏幕，主持人可以一键录制会议，参会记录继续自动留存。

:::tip 模块说明
微语会议正在持续完善中，能力会分阶段上线。统一会议（音频优先、按需摄像头与屏幕共享）和主持人录制已上线；服务端整场录制、主持人强控等能力在路线图中。
:::

## ✨ 主要功能

### 1. 会议室管理

- 每个会议室都有名称、会议号、类型和描述
- 首页列表清晰展示您的会议室，新建、删除一键完成
- 列表只显示自己创建和参与过的会议，不会混入别人的会议

![微语会议客户端：会议室列表](/img/meet/meet_room_list.png)

### 2. 一键邀请链接

- 每个会议室都有专属邀请链接，复制即可发送
- 同事打开链接、用微语账号登录后即可加入会议
- 会议室内自动显示大家的昵称，无需现场输入姓名

![加入会议](/img/meet/meet_room_join.png)

### 3. 统一会议：音频优先，视频按需

- 打开网页即可加入 / 退出会议，无需安装客户端；会议默认纯音频开始，进入时不弹摄像头授权
- 一键静音 / 取消静音麦克风
- 实时显示参会成员列表，谁在会、谁在发言一目了然
- **摄像头按需开关**：任何人可随时开关自己的摄像头，其他参与者在其头像旁的小视频窗中看到画面，不占用会议主区
- **屏幕共享**：任何人可共享屏幕或某个窗口，共享内容在独立浮层窗口中展示；关闭窗口仅隐藏，共享不中断
- 单个会议默认支持最多 24 路同时发布（音视频），创建会议时可选择 6/12/24 人容量档位（可扩展）

![会议主界面：参与者头像列表与底部工具栏](/img/meet/meet_room_meeting.png)

### 4. 主持人录制

- 录制按钮仅主持人（会议室创建者）可见，后端同样强制校验
- 主持人以本地视角通过浏览器（MediaRecorder）录制：自己的麦克风、摄像头或正在共享的屏幕
- 录制中切换视频源会自动分段；停止录制或离开会议时自动上传并建立录制索引
- 录制文件可在 meet 控制台的「录制」页面查询、回放和删除；管理员也可在 meetAdmin 管理后台按组织浏览、播放、下载录制文件

![会议录制管理](/img/meet/meet_recordings.png)

### 5. 参会记录

每次加入会议都会自动留下一条记录，无需手动登记：

- 谁参加了会议、何时加入、何时离开、参会了多久
- 是否为会议主持人
- 意外掉线也不会丢失记录，系统会自动补全

这些记录为考勤统计、会议复盘提供依据，管理员可在[管理后台](https://www.weiyuai.cn/meetadmin)中查询。

![参会记录管理](/img/meet/meet_participant.png)

### 6. 通讯录一键发起会议

通讯录页面（左侧分类 + 右侧列表）让发起会议更轻：

- **组织成员**：搜索、浏览成员，点击查看详情（职位/工号/联系方式），一键发起一对一会议
- **我的群组**：按群组一键发起会议，会议室自动以群组名命名
- 发起即创建会议室并自动复制邀请链接，可直接进入会议，也可把链接发给同事

![通讯录一键发起会议](/img/meet/meet_contact_invite.png)

### 7. [meetAdmin](https://www.weiyuai.cn/meetadmin) 管理后台

配套的[管理后台](https://www.weiyuai.cn/meetadmin)同步上线：

- **会议室管理**：新建、编辑、删除会议室
- **参会记录查询**：按会议室查看参会明细与记录详情
- **会议录制管理**：按组织浏览、播放、下载会议录制文件（按角色授权）
- **权限控制**：谁能管理会议室、谁能查看参会记录，都可以按角色分配
- **服务监控**：管理员可实时了解会议服务的运行情况

### 8. 贴心的设备引导

- 加入会议前自动检查麦克风是否可用
- 遇到权限被拒绝、找不到麦克风、浏览器不支持等情况，会给出明确的提示和解决办法，照着操作即可
- 摄像头与屏幕共享同样有可操作的指引（均要求 HTTPS 或 localhost）

### 9. 多语言支持

[会议客户端](https://www.weiyuai.cn/meet/)与[管理后台](https://www.weiyuai.cn/meetadmin)均支持简体中文、繁体中文、English 三种语言。

## 💡 为什么选择微语会议

- **开源自建**：系统跑在自己的服务器上，数据不出门，隐私可控
- **免安装**：浏览器直接开会，同事凭邀请链接即可加入
- **一号通行**：复用公司微语账号，无需重复注册
- **有据可查**：参会记录自动留存，考勤、复盘不靠人工
- **放心分享**：邀请链接需登录后才能进入；管理功能按角色授权

## 🚀 快速开始

### 方式一：直接使用在线演示

1. 打开[会议客户端演示](https://www.weiyuai.cn/meet/)并登录
2. 新建一个会议室，复制它的邀请链接发给同事
3. 同事打开链接、登录后点击「加入会议」，允许使用麦克风即可开始通话（默认纯音频；需要时从底部工具栏开启摄像头或共享屏幕）

### 方式二：部署到自己的服务器（管理员）

如果希望把微语会议部署到自己的服务器上，请参考项目部署文档，使用 Docker 即可快速启动。

:::info 设备使用要求
浏览器要求在 HTTPS 或 localhost 环境下才能使用麦克风、摄像头和屏幕共享。如果无法开启设备，按页面提示操作即可；正式使用建议为服务配置 HTTPS。
:::
