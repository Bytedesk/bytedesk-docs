# 設定

系統設定模組提供個人資料管理、基本設定與實名認證等功能，協助使用者個人化配置系統並維護帳號資訊。

## 個人資料

個人資料頁面允許使用者查看與修改基本資訊，包括：

- **頭像上傳**：點擊上傳按鈕即可更換個人頭像。
- **使用者名稱**：查看與修改使用者名稱。修改後需要重新登入。
- **暱稱**：修改顯示暱稱。
- **重設密碼**：點擊「重設密碼」按鈕修改登入密碼。
- **電子郵件管理**：查看目前電子郵件與驗證狀態，點擊「重設電子郵件」可更換綁定郵箱。
- **手機號碼管理**：查看目前手機號碼與驗證狀態，點擊「重設手機號碼」可更換綁定手機。
- **個人簡介**：修改個人介紹。

修改完成後，點擊提交按鈕即可儲存變更。

## 基本設定

基本設定頁面提供系統介面與語言相關配置。

### 顏色主題

選擇系統顯示主題：

- **明亮模式**：預設亮色主題。
- **深色模式**：較護眼的深色主題。
- **跟隨系統**：自動跟隨作業系統主題設定。

### 語言設定

選擇系統顯示語言：

- **English**：英文介面。
- **簡體中文**：簡體中文介面。
- **繁體中文**：繁體中文介面。

變更語言後，系統會立即切換至所選語言。

## 實名認證

實名認證模組協助使用者驗證個人身份資訊，提升帳號安全性。

### 個人認證

- **電子郵件驗證**：驗證電子郵件地址，完成後會標記為「已驗證」狀態。
  - 若電子郵件尚未驗證，可點擊「驗證電子郵件」按鈕開始驗證。
  - 驗證過程需輸入寄送到郵箱的驗證碼。

- **手機號碼驗證**：驗證手機號碼，完成後會標記為「已驗證」狀態。
  - 若手機號碼尚未驗證，可點擊「驗證手機號碼」按鈕開始驗證。
  - 驗證過程需要完成圖形驗證碼並輸入簡訊驗證碼。

完成電子郵件與手機號碼驗證後，帳號安全性將獲得提升，並可使用更多系統功能。

:::tip 提示

- 修改電子郵件或手機號碼時需要進行安全驗證。
- 驗證過程中請確認輸入正確的驗證碼。
- 修改密碼時請設定強度較高的安全密碼。

:::
