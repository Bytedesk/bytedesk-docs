# 快捷回覆管理

![快捷回覆頁面](/img/manual/admin/kb/quickreply.png)

快捷回覆是客服系統中的重要功能，能夠幫助客服人員高效地回答常見問題，提高工作效率和服務質量。本文件將指導您如何管理和使用快捷回覆功能。

## 功能概述

快捷回覆系統具有以下主要功能：

- **建立和編輯快捷回覆**：新增常用回覆內容，支援富文字格式
- **分類管理**：按照不同類別組織快捷回覆
- **狀態控制**：啟用或禁用特定的快捷回覆
- **批次操作**：支援批次刪除、批次啟用/禁用
- **匯入匯出**：支援Excel格式的匯入匯出功能
- **內容型別**：支援文字、圖片、影片、音訊和檔案等多種內容型別

## 快捷回覆列表

進入快捷回覆管理頁面後，您可以看到系統中所有的快捷回覆列表，包括以下資訊：

- **標題**：快捷回覆的名稱
- **內容**：快捷回覆的具體內容
- **型別**：內容型別（文字、圖片、影片、檔案等）
- **快捷鍵**：用於快速呼叫的快捷鍵
- **狀態**：是否啟用
- **分類**：所屬分類
- **標籤**：關聯的標籤
- **生效時間**：快捷回覆的生效和失效時間
- **更新時間**：最後更新的時間

## 建立快捷回覆

1. 點選頁面右上角的"新建快捷回覆"按鈕
2. 在彈出的表單中填寫以下資訊：
   - **分類**：選擇快捷回覆所屬的分類
   - **型別**：選擇回覆內容的型別（文字、圖片、影片、音訊、檔案）
   - **標題**：輸入快捷回覆的標題或名稱
   - **回覆**：使用富文字編輯器編寫回復內容
3. 點選"儲存"按鈕完成建立

## 編輯快捷回覆

1. 在列表中找到需要編輯的快捷回覆
2. 點選"編輯"按鈕
3. 在彈出的表單中修改相關資訊
4. 點選"儲存"按鈕儲存修改

## 刪除快捷回覆

1. 在列表中找到需要刪除的快捷回覆
2. 點選"刪除"按鈕
3. 在確認對話方塊中點選"確定"完成刪除

## 批次操作

系統支援對多個快捷回覆進行批次操作：

1. 在列表中選擇需要操作的快捷回覆（勾選核取方塊）
2. 點選相應的批次操作按鈕：
   - **批次刪除**：刪除所選擇的所有快捷回覆
   - **批次啟用**：將所選擇的快捷回覆狀態設定為啟用
   - **批次禁用**：將所選擇的快捷回覆狀態設定為禁用

## 匯入匯出功能

### 匯入快捷回覆

1. 點選"匯入快捷回覆"按鈕
2. 在彈出的視窗中，您可以拖拽或選擇Excel/CSV檔案進行上傳
3. 系統將自動處理匯入的資料並新增到快捷回覆列表中

### 匯出快捷回覆

1. 點選"匯出快捷回覆"按鈕
2. 系統將生成包含當前篩選條件下所有快捷回覆的Excel檔案
3. 瀏覽器會自動下載該檔案

### 下載模板

如果您需要批次匯入快捷回覆，可以：

1. 點選"下載模板"按鈕
2. 獲取標準格式的Excel模板
3. 按照模板格式填寫資料後匯入系統

## 搜尋和篩選

系統提供了強大的搜尋和篩選功能：

1. 使用搜尋框搜尋標題、內容或快捷鍵
2. 使用篩選功能按型別、分類或啟用狀態進行篩選
3. 可以儲存常用的篩選條件以便快速訪問

## 使用場景

快捷回覆適用於以下場景：

- 回答常見問題
- 統一回復口徑
- 傳送標準化的問候語和結束語
- 分享常用的連結或檔案

## 注意事項

- 定期更新快捷回覆內容，確保資訊的準確性和時效性
- 合理分類和標記快捷回覆，方便快速查詢
- 設定簡單易記的快捷鍵，提高使用效率
- 可以設定生效和失效時間，用於臨時性的活動或促銷資訊
