# 大模型知識庫

![大模型知識庫頁面](/img/manual/admin/kb/llm.png)

大模型知識庫為機器人提供基於向量檢索的問答能力。

## Q&A

在「Q&A」標籤中維護問答對（FAQ）。

## 企業版能力

企業版額外提供以下標籤：

- **文字錄入**：錄入知識文字
- **檔案上傳**：上傳知識檔案
- **檔案切塊**：檢視與管理切塊結果
- **網頁抓取**：抓取網頁知識
- **翻譯**：知識多語言翻譯
- **向量配置**：向量檢索配置
