# 工單資料

![工單資料頁面](/img/manual/admin/ticket/data.png)

工單資料頁面用於檢視與管理外部工單、內部工單。

## 頁面佈局

左側為工單分類樹，右側為工單列表，頂部可切換「外部工單 / 內部工單」。

## 工單欄位

工單列表顯示以下欄位：

| 欄位 | 說明 |
| --- | --- |
| 工單編號 / 描述 | 工單標識與摘要 |
| 狀態 / 優先順序 / SLA | 處理狀態與時效 |
| 型別 | 外部 / 內部 |
| 聯絡人 / 電話 / 郵箱 / 微信 | 訪客資訊 |
| 分類 / 部門 | 業務分類與歸屬 |
| 受理人 / 提交人 | 處理與建立人員 |
| 流程 | 關聯流程 |

## 工單操作

- **檢視詳情**：開啟工單詳情抽屜，檢視錶單與流轉記錄
- **編輯**：修改工單欄位
- **批次刪除**：勾選多個工單後批次刪除
