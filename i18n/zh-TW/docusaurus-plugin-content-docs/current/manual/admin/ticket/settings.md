# 工單設定

![工單設定頁面](/img/manual/admin/ticket/settings.png)

工單設定用於配置工單的基礎規則、分類、SLA 與可見性。

## 頁面佈局

左側為設定列表，右側為選中設定的配置標籤，並支援「外部 / 內部」範圍切換。

## 配置項

| 配置項 | 說明 |
| --- | --- |
| 基礎設定 | 工單基礎規則 |
| 分類設定 | 工單分類與欄位 |
| 流程與表單 | 繫結流程與表單 |
| SLA 設定 | 時效與服務等級 |
| 通知設定 | 狀態變動通知 |
| 自動建單 | 自動建立工單規則 |
| 可見性設定 | 部門與成員可見範圍 |

## 管理設定

1. 點選「建立」新建設定，或選擇已有設定「編輯」
2. 配置各標籤項
3. 繫結工作組
4. 「釋出」後生效
