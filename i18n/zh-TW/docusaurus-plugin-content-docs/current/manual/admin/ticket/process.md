# 工單流程

![工單流程頁面](/img/manual/admin/ticket/process.png)

工單流程用於定義工單的狀態流轉與處理節點。

## 頁面佈局

左側為流程型別樹，右側為流程列表。

## 管理流程

- **建立 / 編輯流程**：新建或修改流程定義
- **開啟流程編輯器**：在視覺化編輯器中進行流程編排
- **部署 / 取消部署**：釋出或下線流程
- **檢視部署資訊**：檢視部署 ID 與狀態

:::note 說明
部署後的流程才能被工單使用；修改流程後需重新部署生效。
:::
