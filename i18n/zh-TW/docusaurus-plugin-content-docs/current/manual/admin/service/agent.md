# 客服管理

![客服管理頁面](/img/manual/admin/service/agent-new.png)

客服管理用於維護客服帳號、接待配置與工作狀態。

## 客服帳號

在「客服帳號」標籤中檢視與維護客服帳號，可新增、編輯、禁用客服。

## 客服配置

在「客服配置」標籤中配置客服的接待行為，包含以下子項：

- **歡迎語 / 提示資訊**：訪客進入會話時的問候與提示
- **服務設定 / 展示設定**：接待能力與展示樣式
- **輸入聯想**：輸入框聯想設定
- **評價**：滿意度評價設定
- **詢前問卷 / 留言**：會話前問卷與離線留言
- **排隊設定**：排隊規則
- **自動已解決**：自動關閉會話規則
- **工作時間**：接待時間範圍
- **坐席狀態設定**：客服狀態與話後整理
- **音影片**：音影片會話能力
- **智慧體**：關聯機器人/智慧體
- **Toolbar / 快捷回覆按鈕 / 右側設定**：工作臺介面定製

## 客服狀態

企業版在「客服狀態」標籤中檢視客服狀態日誌。

## 客服席位

企業版在「客服席位」標籤中管理客服席位。
