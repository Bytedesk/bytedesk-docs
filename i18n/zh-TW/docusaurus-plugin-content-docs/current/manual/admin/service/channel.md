# 渠道管理

![渠道管理頁面](/img/manual/admin/service/channel.png)

渠道用於對接各類訪客接入來源。

## 頁面佈局

左側為渠道列表，右側為選中渠道的詳情配置。

## 支援渠道

系統支援多種接入渠道，包括：網頁、App、微信、企業微信、飛書、抖音、小紅書、微博、京東、拼多多、Messenger、WhatsApp、Telegram、Line、Email、Shopify、Lazada 等。

## 配置渠道

1. 在左側選擇渠道
2. 填寫渠道對接引數
3. 儲存並啟用
