# 會話管理

![會話管理頁面](/img/manual/admin/service/thread.png)

會話管理用於檢視與管理全部會話。

## 全部會話

檢視所有會話記錄與詳情。

## 企業版標籤

企業版額外提供以下標籤：

| 標籤 | 說明 |
| --- | --- |
| 佇列 | 排隊佇列與統計 |
| 佇列成員 | 佇列成員與 AI 意圖/情緒識別 |
| 評價 | 會話評價記錄 |
| 轉接 / 邀請 | 轉接與邀請記錄 |
| 總結 | 會話總結 |
| 意圖 / 情緒 | AI 意圖與情緒分析 |
