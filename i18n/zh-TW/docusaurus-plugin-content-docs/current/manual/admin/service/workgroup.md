# 工作組管理

![工作組管理頁面](/img/manual/admin/service/workgroup.png)

工作組將客服組織為接待團隊，並配置路由規則。

## 工作組

在「工作組」標籤中建立與維護工作組。

## 工作組配置

在「工作組配置」標籤中配置工作組的接待行為，子項與客服配置類似，並額外包含：

- **機器人 / 智慧體**：工作組機器人
- **轉人工**：機器人轉人工規則
- **觸發器**：自動觸發規則

## 工作組路由

在「工作組路由」標籤中配置訪客分配到工作組的路由規則。

## 手動接入路由

在「手動接入路由」標籤中檢視等待手動接入的路由池會話。
