# 設定

![系統設定頁面](/img/manual/admin/setting.png)

系統設定模組提供了個人資料管理、基本設定和實名認證等功能，幫助使用者個性化配置系統和維護個人資訊。

## 個人資料

個人資料頁面允許使用者檢視和修改基本資訊，包括：

- **頭像上傳**：點選上傳按鈕可以更換個人頭像
- **使用者名稱**：檢視和修改使用者名稱（注意：修改使用者名稱後需要重新登入）
- **暱稱**：修改您的顯示暱稱
- **重置密碼**：點選"重置密碼"按鈕修改登入密碼
- **郵箱管理**：檢視當前郵箱和驗證狀態，點選"重置郵箱"可以更換繫結郵箱
- **手機號管理**：檢視當前手機號和驗證狀態，點選"重置手機號"可以更換繫結手機號
- **個人簡介**：修改您的個人介紹

修改個人資料後，點選提交按鈕儲存更改。

## 基本設定

基本設定頁面提供系統介面和語言的相關配置：

### 顏色主題

選擇系統的顯示主題：
- **明亮模式**：預設亮色主題
- **黑暗模式**：護眼暗色主題
- **跟隨系統**：自動跟隨系統主題設定

### 語言設定

選擇系統顯示語言：
- **English**：英文介面
- **簡體中文**：簡體中文介面
- **繁體中文**：繁體中文介面

更改語言後系統會立即切換到所選語言。

## 實名認證

實名認證模組幫助使用者驗證個人身份資訊，提高帳號安全性：

### 個人認證

- **郵箱驗證**：驗證您的郵箱地址，驗證後將標記為"已驗證"狀態
  - 若郵箱未驗證，可點選"驗證郵箱"按鈕進行驗證
  - 驗證過程需要輸入傳送到郵箱的驗證碼

- **手機號驗證**：驗證您的手機號，驗證後將標記為"已驗證"狀態
  - 若手機號未驗證，可點選"驗證手機號"按鈕進行驗證
  - 驗證過程需要完成圖形驗證碼並輸入簡訊驗證碼

完成郵箱和手機號驗證後，您的帳號安全性將得到提升，並可以使用更多系統功能。

:::tip 提示
- 郵箱和手機號修改操作需要進行安全驗證
- 驗證過程中請確保輸入正確的驗證碼
- 密碼修改時請設定安全強度較高的密碼
:::
