# 工作臺首頁

![工作臺首頁](/img/manual/admin/welcome-new.png)

工作臺是登入後的預設首頁，承載組織初始化與帳號安全相關引導。

## 組織選擇與建立

- **建立組織**：首次使用時可建立組織，填寫組織資訊
- **選擇組織**：加入多個組織時切換當前組織

## 帳號驗證

透過驗證郵箱與手機號提升帳號安全性：

1. 在工作臺點選「帳號驗證」
2. 驗證郵箱：輸入傳送到郵箱的驗證碼
3. 驗證手機號：完成圖形驗證並輸入簡訊驗證碼

## 微信公眾號訂閱引導

可掃碼訂閱微信公眾號，接收系統通知。

## 統計資料

企業版與平臺版在工作臺展示關鍵統計資料；普通版顯示空態提示。
