# 機器人管理

![機器人管理頁面](/img/manual/admin/ai/robot-new.png)

機器人用於自動接待訪客、回答常見問題並支援轉人工。

## 機器人帳號

在「機器人帳號」標籤中建立與維護機器人帳號。

## 機器人配置

在「機器人配置」標籤中配置機器人的接待行為：

- **歡迎語 / 提示資訊**：機器人問候
- **服務 / 展示設定**：接待能力與樣式
- **智慧體**：繫結大模型智慧體
- **右側設定**：對話介面定製
- **觸發器**：自動觸發規則
- **工具**：機器人可呼叫的工具

## 關聯知識庫

機器人需關聯知識庫才能回答業務問題：

1. 在機器人配置中選擇知識庫
2. 設定檢索型別
3. 儲存後機器人即可基於知識庫回答

:::note 說明
機器人回答不了或訪客要求人工時，可自動或手動轉接到人工客服。
:::
