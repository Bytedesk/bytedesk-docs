# 大模型管理

![大模型管理頁面](/img/manual/admin/ai/model-new.png)

大模型管理用於配置 AI 供應商與模型。

## 頁面佈局

左側為模型供應商列表，右側為選中供應商的配置標籤。

## 支援供應商

系統支援多種模型供應商，包括：Ollama、智譜 AI、DeepSeek、通義（DashScope）、矽基流動、騰訊、百度、火山引擎、MiniMax、訊飛星火、月之暗面、百川、零一萬物、階躍星辰、OpenRouter、Groq、Anthropic、OpenAI、Gemini、Coze、Dify、n8n、MaxKB、RagFlow 等。

## 配置供應商

1. 在左側選擇供應商
2. 填寫該供應商的 API Key 等配置
3. 測試連線後儲存

:::tip 提示
不同的模型供應商需單獨配置金鑰；配置完成後可在機器人或智慧體中選用。
:::
