# 角色管理

![角色與權限頁面](/img/manual/admin/team/role.png)

角色用於控制成員的權限範圍。

## 頁面佈局

左側為角色列表，右側為選中角色的權限配置。

## 建立角色

1. 點選「新建角色」
2. 填寫角色名稱
3. 配置該角色的權限項
4. 儲存

## 配置權限

1. 在左側選擇角色
2. 在右側勾選或取消權限項
3. 儲存後該角色下的成員權限即時生效

:::tip 提示
建議按崗位劃分角色（如管理員、客服主管、質檢員），便於統一授權與審計。
:::
