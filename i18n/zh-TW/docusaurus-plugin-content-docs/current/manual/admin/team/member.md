# 成員管理

![成員管理頁面](/img/manual/admin/team/member-new.png)

成員管理用於維護組織內成員及其部門、角色與狀態。

## 頁面佈局

左側為部門樹，右側為成員列表。可按部門篩選成員。

## 成員欄位

成員列表顯示以下欄位：

| 欄位 | 說明 |
| --- | --- |
| 暱稱 / Uid / 使用者名稱 | 成員標識 |
| 手機 / 郵箱 / 電話 | 聯絡方式 |
| 部門 / 所屬組織 | 組織歸屬 |
| 角色 | 成員角色 |
| 禁用狀態 | 是否強制下線 |
| 可登入平臺 | 允許登入的平臺 |
| 建立 / 更新時間 | 時間資訊 |

## 新增成員

1. 點選「新增成員」按鈕
2. 填寫成員帳號、聯絡方式、部門與角色等資訊
3. 設定可登入平臺
4. 儲存

## 管理成員

- **編輯**：修改成員資訊
- **分配角色**：調整成員角色
- **禁用 / 啟用**：禁用後成員強制下線，無法登入
- **調整部門**：將成員移動到其他部門

:::note 說明
成員的“可登入平臺”決定其能訪問的子系統，如管理後臺、客服工作臺、訪客端等。
:::
