# 管理後臺快速開始

![管理後臺工作臺首頁](/img/manual/admin/welcome-new.png)

管理後臺（Admin）用於組織與成員管理、客服與工作組配置、知識庫與 AI 配置、工單與資料分析等。本文件幫助你完成從登入到上線接待的首日配置。

## 登入

1. 使用管理員帳號登入管理後臺
2. 登入後預設進入「工作臺」首頁

預設管理員帳號由系統初始化時建立，正式使用前請儘快修改密碼並繫結郵箱/手機號。

## 介面導航

左側主導航包含以下模組（按版本與權限顯示）：

| 模組 | 說明 |
| --- | --- |
| 工作臺 | 組織選擇、帳號驗證、統計資料 |
| 組織管理 | 成員、組織、角色、通知、郵件、簡訊、日誌、任務 |
| 線上客服 | 客服、工作組、統一入口、會話、訊息、標籤、渠道等 |
| 知識庫 | 文章、大模型、自動回覆、快捷回覆、敏感詞、上傳記錄 |
| 智慧助手 | 機器人、智慧體、提示詞、大模型、工具、技能 |
| 工單管理 | 工單、流程、設定 |
| 資料分析 | 線上客服、工單、機器人 |
| 設定 | 個人資料、系統設定 |

## 推薦初始化順序

1. **組織與成員**：完善組織資訊，新增成員並分配角色
2. **客服與工作組**：建立客服帳號、工作組與路由規則
3. **渠道**：配置網頁、微信等接入渠道
4. **知識庫 / 機器人**：上傳知識、配置自動回覆與機器人
5. **工單**：配置工單分類、流程與 SLA
6. **統計與質檢**：配置質檢規則，檢視資料分析
