# 服務質檢

![服務質檢頁面](/img/manual/admin/quality.png)

服務質檢用於對會話進行質量檢查與評分。

## 會話質檢

包含以下子項：

| 子項 | 說明 |
| --- | --- |
| 質檢 | 對會話執行質檢與評分 |
| 質檢結果 | 檢視質檢結果 |
| 申訴 | 處理質檢申訴 |
| 質檢統計 | 質檢資料統計 |

## 人工質檢配置

包含質檢方案、質檢任務、質檢規則三部分，用於定義質檢標準與任務分配。

## 智慧質檢

基於規則的自動質檢（智慧質檢結果與統計），用於批次自動評分。

:::note 說明
智慧質檢按版本開放；質檢項與規則由管理員在質檢配置中定義。
:::
