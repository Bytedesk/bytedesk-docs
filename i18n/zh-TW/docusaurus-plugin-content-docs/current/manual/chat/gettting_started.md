# 訪客端快速開始

微語訪客端用於網站、應用或業務系統中的線上諮詢。您可以直接以匿名訪客身份發起會話，也可以登入後檢視歷史會話和工單。頁面中實際顯示的按鈕由企業管理員配置，不同諮詢入口可能略有差異。

## 開啟諮詢視窗

訪客端通常透過以下方式開啟：

- 點選網站右下角的線上諮詢圖示，在懸浮視窗中開始對話；
- 點選企業提供的客服連結，在獨立頁面中開啟對話；
- 從業務系統、公眾號或其他頁面進入嵌入式客服視窗；
- 點選通知或歷史記錄中的工單入口，進入“我的工單”。

開啟頁面後，系統會根據諮詢入口自動連線對應的企業、客服工作組或機器人。請不要隨意修改位址列中的引數，否則可能無法找到正確的服務入口。

## 認識聊天介面

![訪客端聊天介面](/img/manual/chat/gettting_started.png)

聊天頁面主要包含以下區域：

1. **頂部欄**：顯示客服或機器人名稱，並提供返回、歷史記錄等入口。
2. **訊息區**：顯示歡迎語、快捷問題、排隊提示以及雙方的聊天記錄。
3. **輸入區**：輸入併傳送文字；根據配置還可傳送表情、圖片、檔案或語音。
4. **擴充套件工具欄**：可能包含評價、留言、商品、訂單、工單、平臺客服和音視訊通話等入口。

## 完成第一次諮詢

1. 等待歡迎語和快捷問題載入完成。
2. 在輸入框中描述問題，儘量同時說明使用場景、出現的現象和期望結果。
3. 點選傳送按鈕，等待機器人或人工客服回覆。
4. 如果機器人未解決問題，點選“轉人工”；人工繁忙時，頁面會顯示排隊狀態。
5. 客服離線或當前不在服務時間時，根據頁面提示提交留言並填寫可聯絡到您的方式。
6. 服務結束後，如頁面出現評價邀請，可提交星級、解決情況和意見。

## 使用機器人與人工客服

機器人可能先透過歡迎語、熱門問題或“猜你想問”幫助您快速定位答案。機器人回覆下方可能顯示“有幫助”“沒幫助”或“轉人工”：

- 問題已解決時，可點選“有幫助”；
- 答案不準確時，可點選“沒幫助”並繼續補充問題；
- 需要人工處理帳號、訂單或複雜業務時，點選“轉人工”。

轉人工後請留意排隊提示。進入人工會話前重複重新整理頁面，可能影響當前排隊和會話狀態。

## 提交和跟蹤工單

當問題需要後續處理時，可從工具欄進入“工單”或“我的工單”：

1. 建立工單並填寫標題、問題描述、緊急程度和聯絡方式；
2. 根據頁面要求選擇問題分類、填寫補充欄位或上傳附件；
3. 提交後在工單列表檢視狀態；
4. 開啟詳情檢視處理資訊和處理流程；
5. 工單解決後，根據提示確認“已解決”或“未解決”。

工單功能由企業配置。若當前入口沒有顯示工單按鈕，可聯絡人工客服代為建立。

## 使用建議

- 不要在聊天內容或附件中傳送密碼、驗證碼、銀行卡號等敏感資訊；
- 上傳圖片或檔案前，確認其中不包含無關的個人資訊；
- 網路中斷後先等待頁面自動恢復，再檢查訊息是否傳送成功；
- 需要長期跟蹤的問題建議登入後提交工單，避免清理瀏覽器資料後無法繼續檢視；
- 頁面功能或名稱與本文不一致時，以企業當前啟用的配置為準。
