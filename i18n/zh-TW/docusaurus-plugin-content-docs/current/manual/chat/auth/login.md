# 登入與匿名訪問

訪客可以直接匿名諮詢，也可以使用企業提供的帳號登入。是否顯示帳號、手機號或掃碼登入，由當前部署和管理員配置決定。

## 匿名訪問

從企業提供的客服連結開啟聊天頁後，系統會自動建立匿名訪客身份。匿名訪問無需輸入帳號，適合一次性諮詢。

匿名身份通常儲存在當前瀏覽器中。清理瀏覽器資料、更換瀏覽器或裝置後，系統可能無法繼續識別原身份，因此重要問題建議登入後再提交工單。

## 帳號密碼登入

![訪客端登入視窗](/img/manual/chat/auth/login.png)

1. 開啟登入頁面。
2. 輸入帳號和密碼。
3. 根據頁面提示完成驗證碼或隱私協議確認。
4. 點選“登入”。

登入成功後，系統返回聊天頁。連續多次輸入錯誤密碼可能觸發剩餘次數提示或臨時鎖定，請等待鎖定時間結束或聯絡管理員。

:::warning 帳號安全
僅在可信裝置上使用“記住密碼”。公共電腦使用完畢後應退出帳號，並清理瀏覽器儲存的登入資訊。
:::

## 手機號登入

1. 切換到手機號登入。
2. 輸入手機號並獲取驗證碼。
3. 輸入有效驗證碼，確認隱私協議後登入。

收不到驗證碼時，請檢查手機號、傳送間隔和網路狀態。簡訊服務未配置或帳號未繫結手機號時，需要聯絡服務提供方處理。

## 掃碼登入

當頁面顯示掃碼登入入口時：

1. 使用頁面指定的移動端掃描二維碼；
2. 移動端確認登入；
3. 等待網頁自動進入聊天頁。

二維碼會過期。頁面提示已過期時，請重新整理二維碼後重新掃碼。部分部署會關閉掃碼登入，此時使用帳號或手機號登入。

## 註冊與伺服器切換

- 如果登入頁提供“註冊”入口，可按頁面要求建立帳號；是否允許註冊由部署方決定。
- 私有部署環境可能提供伺服器切換入口，用於配置 API 和 WebSocket 服務地址。普通使用者不要修改；地址錯誤會導致無法登入或收發訊息。

## 登入失敗排查

| 現象 | 處理建議 |
| --- | --- |
| 使用者名稱或密碼錯誤 | 檢查大小寫和輸入法，不要連續反覆嘗試 |
| 驗證碼錯誤或過期 | 重新整理驗證碼後重新輸入 |
| 帳號被鎖定 | 等待提示的時間結束，或聯絡管理員解鎖 |
| 頁面一直載入 | 檢查網路並重新整理；私有部署使用者確認伺服器地址 |
| 登入後沒有歷史記錄 | 確認使用的是同一帳號、組織和伺服器 |

登入並不是發起諮詢的必要條件。若企業允許匿名訪問，可返回[快速開始](../gettting_started.md)直接諮詢。
