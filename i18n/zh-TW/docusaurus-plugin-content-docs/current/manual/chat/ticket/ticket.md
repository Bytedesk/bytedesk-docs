# 我的工單

“我的工單”用於提交需要持續跟蹤的服務請求，並檢視客服或處理部門的進度。訪客工單與聊天應用獨立執行，但會共享當前企業和訪客身份。

## 開啟工單中心

![訪客工單中心](/img/manual/ticket/gettting_started.png)

您可以從聊天工具欄點選“工單”，也可以開啟企業提供的工單連結。進入後，頁面會顯示當前訪客在該企業下提交的工單，不按聊天工作組拆分。

匿名訪客的工單身份依賴當前瀏覽器儲存的資訊。若需要跨裝置長期檢視，建議先登入。

## 檢視和搜尋工單

![工單列表](/img/manual/ticket/list.png)

工單列表通常顯示工單編號、標題、狀態、緊急程度、問題分類和更新時間。可按頁面提供的條件搜尋：

- 輸入完整或部分工單編號；編號前帶 `#` 時系統也會嘗試識別；
- 按問題描述中的關鍵詞搜尋；
- 按狀態或問題分類篩選。

## 建立工單

![建立工單表單](/img/manual/ticket/create-filled.png)

1. 點選“建立工單”。
2. 填寫問題描述，必要時調整自動生成的標題。
3. 選擇緊急程度和問題分類。
4. 填寫稱呼、手機號、郵箱或微信等頁面要求的聯絡方式。
5. 按動態表單補充業務欄位，並上傳必要附件。
6. 檢查資訊後提交。

部分環境提供“智慧填寫”，可根據描述輔助填寫欄位。提交前仍需自行核對內容。未完成的聯絡方式可能儲存在當前瀏覽器草稿中，公共裝置使用後請及時清理。

## 檢視詳情與處理流程

點選列表中的“檢視”，詳情抽屜包含兩個頁籤：

![工單詳情](/img/manual/ticket/detail.png)

- **工單詳情**：編號、狀態、緊急程度、描述、分類、提交人、處理人、聯絡方式、時間、渠道、自定義欄位和附件；
- **處理流程**：按時間顯示工單活動、處理人、處理時間和備註。

![工單處理流程時間線](/img/manual/ticket/detail-timeline.png)

## 與處理人員溝通

頁面提供工單會話入口時，可開啟工單聊天繼續補充資訊。請圍繞當前工單回覆，新的獨立問題建議建立新工單，避免處理記錄混雜。

## 確認解決或未解決

處理人員將工單標記為“已解決”後，符合條件的訪客會看到驗證操作：

- 點選“確認解決”，工單進入驗證透過後的結束狀態；
- 點選“未解決”，工單退回繼續處理。

提交驗證前請確認問題現狀。操作成功後按鈕可能消失或禁用，避免重複提交。

## 工單通知

通知頁面用於檢視工單建立、狀態變化和處理進度等訊息。開啟通知後，可按頁面提供的入口進入對應工單。

## 常見問題

| 現象 | 處理建議 |
| --- | --- |
| 列表為空 | 確認當前組織、帳號或匿名訪客身份與提交時一致 |
| 搜尋不到編號 | 嘗試去掉空格，僅輸入編號主體或部分編號 |
| 無法提交 | 檢查必填欄位、聯絡方式、附件大小和網路狀態 |
| 沒有驗證按鈕 | 僅已進入訪客驗證階段且當前訪客有權限時顯示 |
| 無法繼續發訊息 | 工單可能已關閉或當前狀態不允許繼續回覆 |
