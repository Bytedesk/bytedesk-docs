# 帳號與密碼安全

當前訪客端程式碼已提供密碼修改服務介面，但沒有面向訪客公開的獨立“修改密碼”頁面或路由。因此，本頁不提供不存在的介面操作步驟。

## 需要修改或重置密碼時

1. 先檢查登入頁是否提供部署方定製的“忘記密碼”或帳號管理入口；
2. 若沒有可用入口，請聯絡企業管理員或客服核驗身份；
3. 由管理員按當前部署的帳號策略協助重置；
4. 重置後使用新密碼登入，並確認舊密碼已經失效。

:::warning 注意
不要透過聊天訊息傳送原密碼、簡訊驗證碼或其他登入憑據。客服人員也不應索要完整密碼。
:::

## 保護帳號

- 為不同系統使用不同密碼，並定期更新重要帳號密碼；
- 不在公共裝置上儲存密碼；
- 使用完成後退出帳號，尤其是在共享裝置上；
- 收到陌生登入通知時，及時聯絡管理員並修改密碼；
- 私有部署使用者應確認當前連線的是可信伺服器地址。

## 登入異常

連續多次輸入錯誤密碼後，帳號可能被臨時鎖定。請按照頁面提示等待，不要反覆嘗試。無法恢復時，請向管理員提供帳號和發生時間，不要提供密碼。
