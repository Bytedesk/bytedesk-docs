# 聊天會話

聊天會話用於與機器人或人工客服溝通。頁面按鈕會根據企業配置、會話型別、客服狀態和當前版本動態顯示。

## 傳送訊息

1. 在底部輸入框中輸入內容。
2. 點選傳送按鈕或使用頁面支援的傳送快捷鍵。
3. 等待訊息狀態更新並檢視對方回覆。

![傳送訊息與機器人回覆](/img/manual/chat/thread/thread.png)

訊息仍在傳送時不要重複提交。若提示傳送失敗，請檢查網路後重試。

## 使用工具欄

![聊天工具欄](/img/manual/chat/thread/toolbar.png)

工具欄可能包含以下功能：

| 功能 | 用途 |
| --- | --- |
| 表情 | 選擇併傳送表情 |
| 上傳 | 傳送圖片、檔案或其他允許的附件 |
| 語音轉文字輸入 | 使用麥克風識別語音並填入輸入框，僅在瀏覽器和配置支援時顯示 |
| 評價 | 對當前服務發起評價；聊天記錄不足時可能不可用 |
| 留言 | 客服離線或需要後續聯絡時提交留言 |
| 商品 / 訂單 | 選擇業務系統提供的商品或訂單併傳送給客服 |
| 工單 | 開啟“我的工單”，建立或跟蹤服務請求 |
| 平臺客服 | 聯絡平臺客服，僅在平臺開啟時顯示 |

上傳檔案時請等待進度完成。檔案型別和大小由企業配置，超出限制時頁面會給出提示。

## 轉人工與排隊

機器人接待過程中，可點選“轉人工”。系統轉接成功後會提示客服即將為您服務；人工繁忙時會進入排隊，並透過排隊訊息更新狀態。

- 排隊期間保持頁面開啟，避免反覆發起轉人工；
- 如需補充問題，可繼續傳送必要資訊；
- 長時間未接入時，可按頁面提示改為留言；
- 轉接按鈕是否出現取決於機器人和工作組配置。

## 提交留言

![留言表單](/img/manual/chat/thread/thread-2.png)

點選“留言”後，按頁面要求填寫姓名、聯絡方式、留言型別和內容。常見留言型別包括諮詢、投訴、建議、技術支援、銷售諮詢和故障反饋等，實際選項以頁面為準。

提交前請確認聯絡方式準確。留言提交後，服務人員會透過配置的渠道跟進；留言不等同於實時聊天回覆。

## 服務評價

![滿意度評價](/img/manual/chat/thread/rate.png)

當客服邀請評價或工具欄允許主動評價時：

1. 選擇星級或滿意程度；
2. 選擇問題是否解決；
3. 輸入意見後提交。

已經提交的評價可能摺疊顯示，避免重複操作。若聊天記錄數量不足，系統可能暫不允許評價。

## 歷史記錄與會話結束

![歷史會話列表](/img/manual/chat/thread/history.png)

登入使用者可透過頁面提供的歷史入口檢視相關記錄。匿名訪客的歷史記錄依賴當前瀏覽器儲存的身份，清理瀏覽器資料後可能無法恢復。

會話結束後仍需持續跟蹤的問題，可進入[我的工單](../ticket/ticket.md)檢視處理進度。
