# 登入客服工作臺

![客服工作臺登入頁](/img/manual/agent/auth/login.png)

## 登入方式

客服工作臺支援三種登入方式，可在登入頁頂部切換。

### 帳號密碼登入

1. 輸入管理員分配的帳號與密碼
2. 勾選隱私協議與服務條款
3. 點選「登入」

### 手機號驗證碼登入

1. 輸入手機號
2. 點選「獲取驗證碼」，完成圖形驗證並輸入簡訊驗證碼
3. 點選「登入」

### 掃碼登入

1. 在已登入的手機端或授權應用中開啟掃碼入口
2. 掃描登入頁二維碼完成登入

## 註冊與忘記密碼

- **註冊**：未註冊使用者可點選「註冊」按引導建立帳號
- **忘記密碼**：點選「忘記密碼」，透過手機號或郵箱驗證後重置密碼

## 伺服器切換

如需登入私有部署或其他伺服器：

1. 點選登入頁的「伺服器切換」入口
2. 輸入或選擇目標伺服器地址
3. 儲存後重新登入

:::note 說明
伺服器地址通常由管理員提供；連線失敗時請檢查網路與伺服器地址是否正確。
:::

## 登入後

登入成功後系統進入「聊天」工作臺，並顯示當前帳號的選單與權限。若部分選單不可見，說明當前帳號未開通對應權限，請聯絡管理員。
