# 待辦與日曆

待辦頁面包含日曆與待辦清單，幫助客服安排與跟蹤任務。

![待辦頁面](/img/manual/agent/todo.png)

## 日曆

日曆以月檢視展示日程與任務分佈：

- 點選日期可快速檢視當天安排
- 日程條目按型別著色區分
- 可在日曆中直接建立新的日程或任務

## 待辦

待辦清單集中展示需要處理的任務：

- **待處理**：新建或分配給自己、尚未開始的任務
- **進行中**：正在處理的任務
- **已完成**：已完成的任務

對待辦任務可執行：檢視詳情、標記完成、更新進度、刪除等操作。

## 典型用法

1. 上班後開啟「待辦」檢視當日待處理任務，按優先順序安排工作
2. 接待過程中答應訪客的跟進事項，及時建立為待辦
3. 完成後勾選標記，保持任務閉環

:::note 說明
待辦與日曆分別需要相應權限；無權限時頁面顯示提示，請聯絡管理員開通。
:::
