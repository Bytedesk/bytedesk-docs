# AI 客服助手與機器人

客服工作臺內建 AI 能力，幫助客服提升回覆效率與服務質量。

![AI 客服助手面板](/img/manual/agent/agent_preview.png)

## 客服助手

客服助手位於會話右側面板，提供三個能力：

| 能力 | 說明 |
| --- | --- |
| 生成回覆 | 根據當前對話生成回覆建議 |
| 總結問題 | 生成會話小結 |
| 下一步 | 給出後續處理建議 |

使用方式：

1. 在會話右側面板開啟「客服助手」標籤
2. 點選對應能力按鈕
3. 檢視生成結果，可點選「填入輸入框」將建議回覆帶入輸入框
4. 確認後傳送

:::tip 提示
客服助手需在設定中開啟「客服助手」開關，並配置相應的大模型。
:::

## 機器人協同

機器人可在客服離線或繁忙時自動接待訪客，並可隨時轉人工：

- **機器人接待**：訪客進入「機器人會話」分類，由機器人自動回覆
- **轉人工**：機器人無法解決或訪客要求人工時，會話轉入「排隊中」等待客服接入
- **客服接管**：客服可從機器人會話直接接管，繼續與訪客對話

## 機器人管理

工作臺的「機器人」頁面可檢視與管理機器人帳號：

1. 左側選擇機器人分類，右側檢視機器人列表
2. 支援新增、編輯、刪除機器人
3. 每個機器人可配置：
   - **大模型**：供應商、模型、溫度、Top P、Top K、上下文訊息數、最大 Tokens
   - **知識庫**：啟用與檢索型別、知識庫選擇
   - **提示詞**：機器人人設與回覆規則
   - **預設回覆**：未命中知識庫時的兜底回覆

:::note 說明
機器人的完整配置通常在管理後臺「智慧助手」模組進行，工作臺側側重日常使用與快速調整。
:::
