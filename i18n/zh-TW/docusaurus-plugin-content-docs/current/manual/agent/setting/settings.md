# 設定

設定頁面用於維護個人資料、調整介面與通知偏好。

![設定頁面](/img/manual/agent/setting.png)

## 個人資訊

在「個人資訊」中可維護：

- **頭像**：上傳個人頭像
- **暱稱**：顯示暱稱
- **郵箱 / 手機號**：帳號繫結資訊
- **簡介**：個人介紹

## 客服設定

客服角色帳號可在「客服設定」中維護客服資料：頭像、暱稱、郵箱、手機號、描述等。

## 基本設定

基本設定提供以下選項：

| 設定項 | 說明 |
| --- | --- |
| 訊息提示音 | 新訊息聲音提醒 |
| 網路狀態通知 | 斷線重連提醒 |
| 訊息通知 | 桌面通知 |
| 客服助手開關 | 開啟/關閉 AI 客服助手 |
| 訂單資訊開關 | 會話中顯示訂單資訊 |
| 主題 | 明亮 / 黑暗 / 跟隨系統 |
| 語言 | 介面語言 |
| 翻譯設定 | 翻譯提供商與目標語言 |
| 模式 | 團隊 / 客服 / 個人模式 |

其中幾個常用選項說明：

- **自動接入下一位排隊訪客**：開啟後結束當前會話時自動接入排隊中的下一位訪客，減少手動操作
- **主題**：切換明亮/黑暗模式，或跟隨系統自動切換
- **翻譯設定**：配置翻譯提供商與目標語言後，可在訊息右鍵選單中使用訊息翻譯

:::tip 提示
建議開啟「訊息通知」與「訊息提示音」，避免漏接新會話；夜間值班可切換黑暗模式。
:::

## 通知

「通知」標籤顯示系統通知列表，包括：

- **轉接/邀請請求**：同事發起的轉接或邀請
- **轉接/邀請結果**：成功、拒絕、超時、取消
- **新工單通知**：工單編號、優先順序、狀態

支援檢視、標記已讀、全部標為已讀、重新整理。

## 收藏

「收藏」標籤聚合你在對話中收藏的訊息，便於快速回顧與複用。
