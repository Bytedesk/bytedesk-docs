# 客服工作臺快速開始

客服工作臺（Agent Desktop）是客服人員日常接待客戶、處理工單、協同解決問題的統一入口。本文件幫助你快速瞭解工作臺的組成，並完成從登入到接待第一位訪客的完整流程。

## 什麼是客服工作臺

客服工作臺提供以下核心能力：

- **會話接待**：接入並透過文字、圖片、檔案、語音與訪客溝通
- **工單處理**：從會話建立工單，跟蹤處理、轉派、解決與驗證
- **AI 客服助手**：生成回覆建議、會話總結與下一步建議
- **資料與記錄**：檢視會話記錄、客戶資訊與留言

## 獲取與登入

1. 向管理員獲取客服帳號（使用者名稱/密碼或手機號）
2. 開啟客服工作臺客戶端或網頁入口
3. 選擇登入方式：帳號密碼、手機號驗證碼或掃碼登入
4. 登入後系統預設進入「聊天」工作臺

:::tip 提示
首次使用如遇到“無權限訪問”提示，通常是帳號未分配客服角色或權限，請聯絡管理員確認。
:::

「聊天」頁面採用四欄佈局：**會話分類列表、會話列表、對話視窗、右側面板**。視窗變窄時右側面板、分類列表會依次收起。

## 切換接待狀態

點選左下角頭像，可在下拉中切換接待狀態：

![接待狀態切換](/img/manual/agent/status.png)

| 狀態 | 說明 |
| --- | --- |
| 線上 | 接收新會話，系統繼續分配新訪客 |
| 小休 | 暫時休息，不再分配新訪客（可選擇小休原因，如會議、培訓） |
| 忙碌 | 僅處理當前會話，不再分配新訪客 |
| 離線 | 不接收新會話和訊息 |

:::warning 注意
離線或退出前，如仍有進行中會話，系統會彈出確認提示，避免誤操作丟失接待中的訪客。
:::

## 一天工作流

1. **上線**：登入並將狀態切換為「線上」
2. **接待**：在「排隊中」會話分類接入訪客，開始對話
3. **回覆**：使用文字、圖片、快捷回覆或 AI 客服助手回覆
4. **協同**：需要協助時將會話轉接或邀請同事
5. **建單**：複雜問題從會話建立工單，跟蹤處理
6. **結束**：問題解決後結束會話，邀請訪客評價
7. **下線**：處理完進行中會話後切換為「離線」
