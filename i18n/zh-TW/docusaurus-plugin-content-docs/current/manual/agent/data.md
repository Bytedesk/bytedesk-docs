# 資料看板

資料看板用於檢視會話記錄、客戶資訊與留言。

![資料看板](/img/manual/agent/data.png)

## 會話記錄

預設顯示會話記錄列表：

- 支援按時間範圍、會話狀態、客服、關鍵詞等條件檢索歷史會話
- 點選會話可檢視完整訊息內容與雙方資訊
- 可將會話匯出備份

## 客戶管理

檢視與維護客戶資訊：

- **客戶資料**：暱稱、聯絡方式、來源渠道、標籤等
- **歷史會話**：該客戶的歷史會話列表
- **歷史工單**：該客戶的歷史工單列表

## 留言管理

檢視訪客在客服離線或非工作時間留下的留言，可逐條跟進處理，處理完成後可標記已處理或轉化為工單。

:::note 說明
不同帳號按權限可見的資料範圍不同；線上客服統計、工單統計等高階報表按版本與權限顯示。
:::
