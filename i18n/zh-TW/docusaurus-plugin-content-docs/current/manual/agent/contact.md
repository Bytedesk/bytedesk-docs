# 通訊錄

通訊錄用於管理組織內成員與外部聯絡人，便於發起會話與查詢客戶。

![通訊錄](/img/manual/agent/contact.png)

## 聯絡人分類

左側按以下分類組織聯絡人：

| 分類 | 說明 |
| --- | --- |
| 組織內聯絡人 | 組織內的成員 |
| 外部聯絡人 | 訪客與外部客戶 |
| 新的聯絡人 | 最近新增的聯絡人 |
| 星標聯絡人 | 已收藏的聯絡人 |
| 郵箱聯絡人 | 透過郵箱匯入的聯絡人 |
| 我的群組 | 我加入的群組 |
| 服務檯 | 服務檯相關聯絡人 |

## 查詢與發起會話

1. 在左側選擇聯絡人分類
2. 在列表中找到目標聯絡人
3. 點選聯絡人可檢視資料併發起會話

頂部搜尋框支援按暱稱、手機號、郵箱等關鍵詞檢索聯絡人。
