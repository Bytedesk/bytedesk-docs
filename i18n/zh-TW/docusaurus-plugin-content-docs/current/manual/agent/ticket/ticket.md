# 工單管理

工單用於記錄需要跟進處理的問題，支援從會話直接建立，並在客服之間流轉、轉派直至解決與驗證。

## 工單列表

工單頁面左側為篩選區，右側為工單列表。

![工單工作臺](/img/manual/agent/ticket.png)

寬屏下工單工作臺完整展示篩選區與列表：

![工單工作臺寬屏佈局](/img/manual/agent/ticket-wide.png)

### 篩選

可按以下維度篩選工單：

| 維度 | 可選值 |
| --- | --- |
| 狀態 | 全部狀態、新建立、處理中、掛起、重新開啟、已解決、已關閉、已驗證 |
| 優先順序 | 最低、低、中、高、緊急、嚴重 |
| 分配 | 全部、我建立的、分配給我的、未分配 |
| 時間 | 全部、今日、昨日、本週、上週、本月、上月 |

### 列表欄位

工單列表顯示：工單編號、描述摘要、型別標籤、狀態標籤、優先順序標籤、更新時間。頂部提供搜尋框、重新整理按鈕、建立工單按鈕與工單總數。

## 建立工單

1. 點選工單頁面頂部的「建立工單」按鈕，或在會話視窗頂部點選「建立工單」
2. 填寫工單資訊：
   - **標題、問題摘要、描述**：說明問題
   - **緊急程度、分類**：選擇優先順序與業務分類
   - **客戶、處理人、報告人、工作組、部門**：關聯人員與組織
   - **聯絡稱呼、聯絡電話、聯絡郵箱、聯絡微信**：訪客聯絡方式
   - **渠道來源**：工單來源渠道
3. 可選擇「關聯訪客會話」，將工單與當前會話繫結
4. 上傳必要附件後儲存

## 工單詳情

點選工單進入詳情，包含對話視窗與右側「工單詳情」「流轉過程」標籤：

![工單詳情與認領指派](/img/manual/agent/ticket-detail.png)

- **工單詳情**：檢視與編輯工單欄位
- **流轉過程**：檢視工單的狀態流轉與處理記錄

## 處理工單

工單支援以下操作（按狀態與權限顯示）：

| 操作 | 說明 |
| --- | --- |
| 編輯 | 修改工單欄位 |
| 指派 | 指定處理人 |
| 關閉 | 關閉工單 |
| 重新開啟 | 重新開啟已關閉工單 |
| 驗證 | 驗證工單處理結果 |
| 邀請 | 邀請其他成員參與處理 |
| 委託 | 委託他人處理 |
| 抄送 | 抄送給相關人員 |
| 加簽 | 增加處理意見 |
| 退回 | 退回上一環節 |
| 撤銷 | 撤銷操作 |

## 工單狀態

工單狀態全集如下：

- **新建立**：工單剛建立
- **已分配**：已指定處理人
- **已認領**：處理人已認領
- **處理中**：正在處理
- **掛起**：暫時掛起
- **重新開啟**：已解決或關閉後重新開啟
- **已轉派**：已轉派給他人
- **已解決**：處理完成，等待驗證
- **已關閉**：工單關閉
- **已取消**：工單取消
- **驗證透過 / 驗證失敗**：訪客或報告人對解決結果的確認

:::note 說明
工單狀態與流程由管理員在管理後臺配置，不同組織的狀態流轉可能不同。
:::
