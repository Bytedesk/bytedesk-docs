# 會話工作臺

會話工作臺是客服日常接待的核心頁面，包含會話分類、會話列表、對話視窗與右側面板四部分。

![會話工作臺佈局](/img/manual/agent/chat.png)

## 頁面佈局

| 區域 | 說明 |
| --- | --- |
| 會話分類 | 按型別與狀態對會話分組，快速定位待處理會話 |
| 會話列表 | 當前分類下的會話清單 |
| 對話視窗 | 與訪客的訊息往來與輸入區 |
| 右側面板 | 客服助手、快捷回覆、訪客資訊、工單詳情等 |

## 會話分類

常見會話分類及含義：

| 分類 | 說明 |
| --- | --- |
| 進行中會話 | 正在接待的會話 |
| 排隊中 | 等待客服接入的訪客 |
| 歷史會話 | 已結束的會話 |
| 待處理留言 | 訪客離線的留言 |
| 待處理工單 | 關聯的待處理工單會話 |
| 手動接入路由 | 等待手動接入的路由池會話 |
| 機器人會話 | 機器人正在接待的會話 |
| 摺疊的會話 | 摺疊收納的會話 |

預設顯示：進行中會話、歷史會話、排隊中、全部會話、摺疊的會話。

## 接入訪客

訪客發起諮詢後會進入「排隊中」會話分類。

1. 開啟「排隊中」分類
2. 點選目標訪客右側的「接入」按鈕
3. 接入後會話進入「進行中會話」，即可開始回覆

:::tip 提示
可在設定中開啟「自動接入下一位排隊訪客」，系統會按順序自動接入，減少手動操作。
:::

## 回覆訪客

在對話視窗底部輸入區可傳送以下內容：

- **文字**：直接輸入並回車（或 Ctrl/Enter）傳送
- **表情**：點選表情按鈕選擇
- **圖片/檔案**：點選上傳按鈕選擇圖片或檔案
- **語音**：切換到語音輸入錄製併傳送
- **快捷短語**：輸入時自動聯想快捷回覆，或輸入 `/` 觸發快捷指令

訊息傳送後支援右鍵操作：複製、翻譯、語音播放、撤回、放大閱讀、新增快捷回覆、下載、語音轉文字、轉發、收藏、多選、提醒、置頂等。

## 使用快捷回覆

1. 在右側面板開啟「快捷回覆」標籤
2. 點選或搜尋目標快捷回覆
3. 內容自動填入輸入框，確認後傳送

快捷回覆由管理員在管理後臺維護，可顯著提升常見問題的回覆效率。

## 轉接會話

需要將訪客轉給其他客服或工作組時：

1. 點選對話視窗頂部的「轉接」按鈕
2. 選擇目標客服或工作組
3. 確認轉接

轉接後訪客會話會轉移到目標客服，由對方繼續接待。

## 邀請同事

如需同事加入當前會話共同處理：

1. 點選對話視窗頂部的「邀請」按鈕
2. 選擇要邀請的同事
3. 對方接受後即可加入會話

邀請請求會在對方工作臺彈出應答視窗，可選擇同意或拒絕。

## 建立工單

1. 點選對話視窗頂部的「建立工單」按鈕
2. 填寫工單標題、問題摘要、分類、優先順序、處理人等資訊
3. 可選擇關聯當前訪客會話
4. 儲存後生成工單，並可在右側面板「工單詳情」中跟蹤

## 會話總結

點選對話視窗頂部的「會話總結」，系統會根據對話內容生成會話小結，便於記錄與交接。

## 結束會話與邀請評價

1. 點選對話視窗頂部的「結束會話」按鈕
2. 確認結束
3. 可選擇「邀請評價」，向訪客傳送滿意度評價邀請

結束後會話進入「歷史會話」，可隨時檢視歷史訊息。

## 右側面板

右側面板提供多個標籤頁，按需切換：

| 標籤 | 說明 |
| --- | --- |
| 客服助手 | AI 回覆建議、會話總結與下一步建議 |
| 快捷回覆 | 快捷回覆庫 |
| 工單詳情 | 當前會話關聯的工單 |
| 流轉過程 | 工單流轉記錄 |
| 訪客資訊 | 訪客資料 |
| 會話資訊 | 當前會話屬性 |
| 歷史會話 | 該訪客的歷史會話 |
| 歷史工單 | 該訪客的歷史工單 |

## AI 客服助手

右側面板的「客服助手」標籤可在接待過程中實時輔助客服：

![AI 客服助手](/img/manual/agent/agent_assistant.png)

- **生成回覆**：根據對話上下文生成建議回覆，一鍵填入輸入框
- **總結問題**：自動生成會話小結，便於交接與記錄
- **下一步**：給出後續處理建議（如轉接、建單、結束會話）

## 訊息未讀提醒

存在未讀訊息時，會話列表與導航選單會顯示未讀角標，長時間未處理會彈出提醒：

![未讀訊息提醒](/img/manual/agent/agent_thread_unread_tip.png)

## 監控、強插與接管

企業版中，主管可對工作組會話進行監控、強插或接管：

- **監控**：旁觀會話過程
- **強插**：加入會話參與回覆
- **接管**：接管會話處理權

相關按鈕在對話視窗頂部顯示，退出後恢復。
