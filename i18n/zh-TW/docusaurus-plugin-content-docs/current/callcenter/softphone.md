# Softphone

微語呼叫中心軟電話工具列，是坐席在桌面工作台中完成電話簽入、外呼與通話控制的核心入口。它把傳統話機、SIP 分機與線上客服工作台整合到同一個操作介面中，讓坐席不必頻繁切換系統，就可以完成從上線接線到通話結束的整個流程。

對企業來說，這不只是簡單的「撥號列」，而是一套面向客服、銷售、電銷與服務團隊的電話工作台能力。透過微語軟電話工具列，企業可以把電話接待、客戶資料處理、工單記錄與線上會話統一到同一坐席桌面，提升接通效率、縮短操作路徑，並讓電話服務更標準化。

![softphone](/img/callcenter/softphone.png)

## 功能亮點

- **一鍵簽入簽出**：坐席可直接在工作台完成 SIP 分機簽入與簽出，快速切換在線接線狀態。
- **即時狀態可視**：工具列會顯示目前簽入狀態，例如未啟用、已簽出、簽入中、已簽入、簽入失敗，方便主管與坐席快速判斷分機是否可用。
- **快速外呼**：支援輸入手機號碼、分機號或 IVR 目標後直接發起呼叫，適合客服回訪、銷售外呼與內部協作聯絡。
- **通話時長顯示**：通話建立後自動顯示通話時長，幫助坐席掌握當前溝通節奏，也便於後續服務質檢與營運分析。
- **通話中控制**：支援保持/取回、轉接、轉 IVR、邀請會議、掛斷等常用通話控制操作，滿足電話客服的高頻業務需求。
- **自適應收納更多操作**：當工具列空間不足時，系統會自動把部分操作收納到「更多」選單中，兼顧完整功能與介面整潔。

## 工具列包含哪些能力

### 簽入與簽出

簽入表示當前坐席的 SIP 分機註冊上線，能夠參與呼入接聽、桌面彈屏與軟電話控制；簽出則表示當前坐席主動註銷自己的 WebRTC 軟電話註冊。

這讓企業可以靈活管理坐席在線狀態，例如：

- 上班後快速簽入，立即進入接線狀態。
- 臨時離崗時簽出，避免呼叫繼續分配到當前坐席。
- 固定話機與桌面軟電話共號時，單獨控制桌面端在線狀態，不影響其他終端。

### 外呼撥號

坐席可以在輸入框中直接輸入目標號碼、內部短號、分機號或 IVR 目標，點擊「外呼」後立即發起呼叫。對於需要高頻主動聯絡客戶的場景，這種方式比在多個系統之間切換、複製號碼再撥號更高效。

微語呼叫中心特別適合以下外呼場景：

- 售後回訪
- 線索跟進
- 催辦提醒
- 訂單確認
- 內部分機呼叫

### 通話中控制

當通話建立後，坐席可以在工具列中繼續完成關鍵控制動作：

- **保持/取回**：適合坐席需要短暫查詢資訊、內部確認或暫停溝通的場景。
- **轉接**：把當前通話轉給其他坐席、分機或處理目標，減少人工重複說明。
- **轉 IVR**：把客戶重新轉回語音導航流程，適合回到選單選擇或進入特定自助服務入口。
- **會議邀請**：邀請其他坐席或目標分機加入當前通話，適合協同服務、升級支援與內部會商。
- **掛斷**：快速結束當前通話。

這些能力構成了電話客服日常最核心的操作閉環，讓坐席不需要依賴獨立話機面板，也不需要額外培訓複雜的通信系統介面。

## 對企業的業務價值

### 統一電話與客服工作台

微語把軟電話工具列直接嵌入坐席桌面工作台。坐席在接打電話的同時，可以繼續查看客戶資料、訪客來源、歷史會話、工單、標籤與備註，避免電話系統與客服系統割裂。

### 降低坐席操作成本

常見電話動作集中在一個固定區域，坐席學習成本更低，培訓週期更短。對於呼叫中心新團隊、業務外包團隊與高流動性崗位，這一點非常重要。

### 提升接待與協作效率

從簽入上線、快速外呼，到轉接、轉 IVR、會議協同，工具列覆蓋了電話服務中最常見的高頻動作。坐席無需跳轉多個頁面，就能完成一次電話服務的主要操作鏈路。

### 支援漸進式替代傳統話機

企業可以繼續保留傳統固定話機，也可以逐步將電話控制遷移到 WebRTC 坐席桌面。微語支援兩種模式協同演進，既滿足既有通信資產的延續，也降低新系統切換門檻。

## 典型使用流程

1. 管理員為坐席配置呼叫能力，並綁定對應 SIP 分機。
2. 坐席登入微語桌面工作台，在軟電話工具列中點擊「簽入」。
3. 坐席輸入客戶號碼、內部短號或業務目標，直接發起外呼；或者等待系統分配來電。
4. 通話建立後，坐席可根據業務需要執行保持、轉接、轉 IVR 或邀請其他坐席加入會議。
5. 通話結束後，坐席可繼續處理客戶資料、跟進記錄或工單。

## 適用場景

- 客服中心統一接聽與回訪
- 銷售團隊主動外呼與線索跟進
- 售後服務協同處理與升級轉接
- 總機、IVR 與人工坐席聯動
- 固定話機與桌面軟電話混合辦公

## 為什麼選擇微語呼叫中心

微語呼叫中心不只提供電話能力，更強調「通信能力與客戶服務場景的一體化」。軟電話工具列看似只是一個小入口，實際上承接的是坐席上線、電話溝通、客戶處理與團隊協作的整條業務鏈路。

如果企業希望把電話客服從傳統設備時代升級為線上化、可視化、協同化的現代服務方式，微語軟電話工具列可以成為非常直接的一步。它讓坐席更快上手，讓管理者更容易標準化流程，也讓客戶在每一次呼叫中獲得更穩定、更高效的服務體驗。
