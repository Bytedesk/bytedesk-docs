# 微語文件

微語文件是微語協作平台中的辦公文件模組，把**文字文件、電子試算表、簡報、PDF 和 Markdown** 五類常用文件裝進同一個工作台：建立、編輯、儲存都和平時一樣，同時還內建一位「隨叫隨到」的 AI 助理——從零起草初稿、潤飾文字、美化排版，一句話就能完成。

簡單來說：**像使用微軟 Office 一樣編輯文件，像擁有秘書一樣使用 AI。**

:::tip 模組說明
微語文件正在持續完善中，部分能力會分階段上線。
:::

## 📄 支援的文件類型

| 類型 | 常見格式 | 能做什麼 |
| ---- | -------- | -------- |
| 文字文件 | Word（.docx） | 撰寫通知、方案、報告、週報等，支援樣式、目錄、圖表、公式、修訂與註解 |
| 電子試算表 | Excel（.xlsx） | 資料記錄與計算，支援公式、圖表、樞紐分析表、條件格式 |
| 簡報 | PowerPoint（.pptx） | 製作匯報、教育訓練、宣講簡報，支援母片、版面配置、智慧參考線 |
| PDF | .pdf | 直接修改文字與圖片、新增註解、填寫表單、頁面增刪，還能把 PDF 轉成 Word/Excel/PowerPoint |
| Markdown | .md | 輕量筆記與文件，適合寫說明、README 等 |

## 🤖 AI 助理能幫您做什麼

開啟任一文件右側的「AI 助理」面板，用日常用語下達指令即可。

### 產生文件內容

- **從零起草**：說一句「幫我寫一份專案週報」「寫一篇產品發布公告」「列一個活動策劃提綱」，AI 直接為您寫出初稿
- **續寫**：接著現有內容往下寫
- **填寫範本**：自動找出文件中的佔位符並填寫

### 完善和美化文件格式

- **潤飾全文**：使語氣更專業、表達更清晰流暢
- **AI 排版**：自動修正標題層級、統一清單格式、去除多餘的粗體和斜體、補齊首行縮排——只調整格式，不改動任何文字內容
- **修改選取內容**：選取一段文字後，可一鍵潤飾、精簡、擴寫、修正語法和錯別字
- **批次修改**：將多處修改意見加入佇列，一次送出，AI 統一處理

### 更多能力

- **總結要點**：長文件一鍵總結
- **產生配圖 / 網路搜尋 / 圖片搜尋**：為文件配圖、查資料、插入網路圖片
- **修訂追蹤**：AI 的修改以「修訂」形式標記，可在審閱中逐一接受或拒絕
- **版本快照**：每輪 AI 修改前自動儲存快照，不滿意可一鍵回復

## �💼 和微軟 Office / WPS 相容嗎

相容。微語文件直接使用微軟 Office 的真實格式（.docx/.xlsx/.pptx），不經過中間轉換：

- 用 Word/Excel/PowerPoint 開啟微語文件編輯過的檔案，格式不會亂
- Word 文件採用「改了什麼就只重寫什麼」的儲存方式，未修改的內容原樣保留
- 分頁位置與 Word 保持一致，所見即所得

同樣相容 WPS Office：

- 用 WPS 文字 / WPS 表格 / WPS 演示開啟微語文件編輯過的檔案，格式不會亂
- 在 WPS 中編輯儲存的文件，也可以直接在微語文件中開啟並繼續編輯

## ❓ 常見問題

**AI 功能需要額外設定嗎？**

需要在 AI 設定中設定大型語言模型服務。支援主流模型（OpenAI、Claude、Gemini、DeepSeek、Kimi、GLM、通義千問等），也支援自訂 OpenAI 相容介面接入。

**我的文件會上傳到雲端嗎？**

文件要嘛保存在本機，編輯和儲存均在您自己的電腦上完成；要嘛同步到您私有部署的微語伺服器，方便團隊協作與共享。只有使用 AI 功能時，相關內容才會傳送給您設定的模型服務。

**PDF 轉換支援掃描件嗎？**

支援。在 macOS 和 Windows 上可透過系統 OCR 辨識掃描件，並轉換為可編輯的 Word/Excel/PowerPoint。

**有哪些平台？**

提供 macOS、Windows、Linux 桌面用戶端，支援淺色/深色主題。

## 📌 小秘訣

- AI 修改前會自動產生版本快照，大膽嘗試也不用擔心改壞文件
- 開啟「修訂追蹤」後，AI 的所有修改都會留痕，適合對文件品質要求高的場景
- 選取文字後再下指令，改寫預設只作用於選取部分
