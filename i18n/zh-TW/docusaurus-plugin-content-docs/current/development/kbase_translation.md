# 知識庫多語言翻譯

微語知識庫支援將 FAQ、文字、切塊、網頁等知識內容一鍵翻譯為多種語言，實現多語言知識檢索與智慧問答，幫助出海企業快速建構國際化知識服務體系。

:::tip 提示
社群版不支援，請升級到企業版或平台版。
:::

## 功能概述

知識庫翻譯功能利用大模型（LLM）自動將知識庫中的內容翻譯為目標語言，翻譯結果會自動納入全文檢索（Elasticsearch）和向量檢索，使多語言使用者能夠用自己的母語搜尋知識庫並獲得準確回答。

### 核心特性

- **一鍵翻譯**：在 FAQ、文字、切塊、網頁等管理頁面，點擊翻譯按鈕即可觸發大模型翻譯
- **多語言支援**：支援中文、英文、日文、韓文、法文、德文、西班牙文等十餘種語言
- **自動索引**：翻譯成功後自動更新全文索引和向量索引，無需手動操作
- **翻譯管理**：集中檢視和管理所有翻譯紀錄，支援編輯和重新翻譯
- **多語言問答**：機器人會自動根據使用者語言匹配對應的翻譯內容進行回答

## 使用流程

### 1. 配置目標語言

在知識庫設定中，配置需要翻譯的目標語言清單。

系統支援同時配置多種目標語言，翻譯任務會為每種語言生成獨立的翻譯紀錄。

### 2. 觸發翻譯

在知識內容管理頁面（FAQ、文字、切塊、網頁），每筆記錄的操作欄都有翻譯按鈕，點擊後系統會呼叫已配置的翻譯大模型，自動生成對應語言的翻譯內容。

![kbase_translate](/img/kbase/translate/kbase_translate.png)

### 3. 查看翻譯結果

翻譯完成後，在翻譯管理頁面可以查看所有翻譯紀錄。

翻譯紀錄包含：

- **源語言/目標語言**：翻譯的語言對
- **翻譯狀態**：NEW（待翻譯）、PROCESSING（翻譯中）、SUCCESS（成功）、ERROR（失敗）
- **翻譯內容**：標題、正文、摘要等翻譯結果
- **翻譯提供商**：使用的翻譯模型名稱

![kbase_translate_result](/img/kbase/translate/kbase_translate_result.png)

### 4. 搜尋測試驗證

在搜尋測試頁面，可以用目標語言進行搜尋，驗證翻譯內容是否被正確索引和檢索。

## 翻譯內容檢索

翻譯成功的內容會自動納入搜尋體系：

### 全文檢索（Elasticsearch）

每筆成功的翻譯會作為獨立的 ES 文件儲存，包含 `translated=true` 標記和目標語言欄位。搜尋時會同時匹配原文和所有翻譯文件。

### 向量檢索

翻譯內容同樣會被向量化儲存，語義搜尋時會自動匹配對應語言的內容向量。

### 機器人問答

當訪客使用非源語言提問時，機器人會：

1. 偵測使用者語言
2. 優先檢索符合使用者語言的知識內容（含翻譯）
3. 回傳對應語言的答案

## 翻譯管理

### 翻譯列表

翻譯管理頁面（`管理後台 → 知識庫 → 大模型 → 翻譯管理`）提供：

- 依知識庫、源類型、狀態、語言等篩選
- 支援編輯翻譯內容
- 支援刪除翻譯紀錄
- 支援重新翻譯

### 翻譯內容編輯

點擊編輯按鈕可以手動修改翻譯內容，修改後自動更新索引。

### 翻譯狀態追蹤

翻譯狀態說明：

- **NEW**：待翻譯，翻譯佔位已建立但內容為空
- **PROCESSING**：大模型正在處理翻譯
- **SUCCESS**：翻譯成功，已自動索引
- **ERROR**：翻譯失敗，可查看錯誤資訊後重試

## 技術實作

### 翻譯流程

```bash
使用者點擊翻譯 → 建立翻譯紀錄(NEW) → 呼叫 LLM 翻譯 → 更新狀態(SUCCESS/ERROR)
                                                          ↓
                                                    自動更新 ES 索引
                                                    自動更新向量索引
```

### 自動索引

翻譯狀態變為 SUCCESS 後，系統自動觸發：

1. 源實體（FAQ/Text/Chunk/Webpage）的 Elasticsearch 全文索引更新
2. 源實體的向量索引更新

翻譯內容作為獨立的索引文件儲存，與原文共存，搜尋時統一匹配。

## 常見問題

### 翻譯支援哪些內容類型？

支援 FAQ（常見問題）、TEXT（文字）、CHUNK（文件切塊）、WEBPAGE（網頁）四種類型。

### 翻譯使用哪個模型？

預設使用阿里百煉 Qwen-MT 翻譯模型，支援在 Robot 設定中自訂翻譯智慧體的模型和提示詞。

### 翻譯內容會影響原文嗎？

不會。翻譯內容獨立儲存，原文保持不變。

### 如何驗證翻譯是否被正確索引？

在知識庫搜尋測試頁面，選擇目標語言進行搜尋，如果翻譯內容被召回且 score > 0，表示索引正常。
