# 平台客服（Platform Service）

「平台客服」為多租戶/平台版部署提供一條**用戶與商戶之間的糾紛處理通道**：當訪客（用戶）與某個商戶的客服溝通中產生糾紛時，訪客可以在聊天視窗直接聯繫平台方客服介入；平台客服也可以在工作台中有邊界地跨組織回查相關資料。

該功能預設關閉，僅**超級管理員**可以開啟和配置，租戶管理員無法修改。

## 這是什麼功能

平台客服包含兩個互相配合的能力：

1. **訪客端「平台客服」按鈕**：訪客與商戶客服聊天時，如果遇到糾紛，可點擊工具欄中的「平台客服」按鈕，在目前視窗內直接開啟與平台官方客服的對話，無需跳轉或另開頁面。
2. **客服工作台「平台查詢」**：平台組織的客服在桌面端工作台左側分類中選擇「平台查詢」，先選擇一個目標組織（商戶），即可唯讀查看該組織的會話列表、聊天記錄和訂單，用於了解糾紛的來龍去脈。
3. **客服端平台會話標識**：平台客服的會話列表中，平台會話帶有醒目的紫色「平台會話」標籤；選中會話後，右側面板出現專屬的「平台會話」標籤頁，可集中查看關聯的原商戶會話與發起訪客資訊。

## 什麼情況下使用「平台客服」按鈕

- 訪客認為商戶客服的處理結果不合理，希望平台介入評判；
- 訪客與商戶之間出現售後爭議、承諾不符等糾紛，需要更高一級的協調；
- 訪客遇到商戶客服無法解決的技術或服務問題，需要平台技術支援。

訪客側使用步驟：

1. 訪客在商戶的聊天視窗中，點擊工具欄的「平台客服」按鈕；
2. 視窗右側會開啟一個平台客服對話抽屜；
3. 訪客在抽屜內描述糾紛情況並傳送；
4. 平台客服在桌面端工作台的會話列表中，可一眼識別帶紫色「平台會話」標籤的會話；選中後右側出現「平台會話」標籤頁，點擊「查看聊天記錄」即可完整查看該訪客與商戶客服的原始對話（唯讀），作為評判依據。

## 如何開啟（超級管理員）

1. 使用超級管理員帳號登入管理後台；
2. 進入「系統設定」中的**平台客服**分組（`/super/system-config`）；
3. 開啟「啟用平台客服入口」開關；
4. 按需調整平台客服所屬的組織與工作組（預設為系統預設組織下的預設工作組，通常無需修改）；
5. 儲存後，重新整理任意租戶的訪客聊天頁面，工具欄即出現「平台客服」按鈕；關閉開關後按鈕消失。

注意：租戶管理員的後台中沒有任何與此功能相關的配置入口。

## 客服工作台如何識別平台會話

為方便平台客服快速定位糾紛介入會話，桌面端工作台提供了以下入口：

1. **會話列表「平台會話」標籤**：凡是訪客從商戶會話發起平台介入的會話，在左側會話列表中都會顯示紫色「平台會話」標籤，與普通會話一眼區分；
2. **右側「平台會話」標籤頁**：選中平台會話後，右側面板會出現「平台會話」標籤頁，集中展示：
   - **關聯原會話**：原會話編號、原組織編號、原會話類型 / 狀態 / 更新時間、原會話訪客暱稱；點擊「查看聊天記錄」可唯讀查看該訪客與商戶客服的原始對話；
   - **發起訪客**：目前平台會話訪客的頭像、暱稱與編號，點擊「查看完整訪客資料」可跳轉到訪客資訊標籤頁；
3. **會話詳情中的來源會話區塊**：在「會話詳情」標籤頁中同樣保留來源會話資訊，兩處入口內容一致。

注意：「平台會話」標籤頁僅平台組織的客服可見；查看原始會話聊天記錄為唯讀，不會切換您目前正在處理的會話，也不會向對方傳送任何回執。

## 客服工作台如何先選組織再查詢

平台組織的客服（帳號屬於平台預設組織）可以使用「平台查詢」：

1. 在桌面端工作台左側「分類」中找到「平台查詢」（如未顯示，可在分類設定「顯示選項」中勾選）；
2. 進入後頁面頂部有明確說明：您正在以平台客服身份查看所選組織的資料，僅用於處理糾紛與技術支援，資料唯讀且查詢會記錄稽核日誌；
3. **第一步：在頂部組織選擇器中搜尋並選擇要查詢的組織**——未選擇組織時，查詢區域為停用狀態；
4. **第二步：查詢資料**——選擇組織後，可以：
   - 在「會話」標籤中查看該組織的會話列表，點擊任一會話即可開啟唯讀的聊天記錄抽屜；
   - 在「訂單」標籤中查看該組織的訂單列表（僅企業版/平台版可見，社區版無此標籤）；
5. 切換組織或重新整理頁面後，會回到「未選組織」的初始狀態，需要重新選擇組織才能繼續查詢。

## 平台查詢能看什麼、不能做什麼

**能看（唯讀）：**

- 所選組織的會話列表（訪客、類型、狀態、時間）；
- 所選組織任一會話的完整聊天記錄（含圖片、檔案等分類瀏覽）；
- 所選組織的訂單列表（企業版/平台版）。

**不能做：**

- 不能跨組織回覆、接管、轉派、修改、刪除任何資料；
- 查看聊天記錄時不會切換您目前正在處理的會話，也不會向對方傳送任何已讀回執；
- 普通租戶的客服沒有「平台查詢」入口，即使直接呼叫介面傳入其他組織的標識也會被系統拒絕。

## 常見問題

**為什麼必須先選組織？**
平台查詢面向處理具體糾紛場景，強制先選定組織可以避免誤查其他組織資料，也讓每次查詢的範圍清晰、可稽核。

**為什麼有些環境看不到「訂單」標籤？**
訂單資料屬於企業版功能。社區版部署沒有訂單模組，標籤會自動隱藏，只保留會話查詢。

**為什麼我的「分類」裡沒有「平台查詢」？**
僅平台組織（系統預設組織）的客服帳號可見該分類；租戶組織的客服不可見。如果確認是平台組織帳號仍看不到，請在分類上方的「顯示選項」中勾選「平台查詢」。

**會話列表中的紫色「平台會話」標籤是什麼意思？**
表示該會話是訪客從某個商戶會話發起平台介入產生的糾紛會話。僅平台組織的客服可以看到配套的「平台會話」標籤頁；普通商戶會話不會帶有此標籤。

**訪客端按鈕開了但不顯示？**
請確認：訪客聊天的會話已初始化（按鈕點擊要求會話存在）；開關儲存後已重新整理頁面；配置中的組織與工作組 UID 正確無誤。預設配置（預設組織 + 預設工作組）在標準部署下開箱即用。
