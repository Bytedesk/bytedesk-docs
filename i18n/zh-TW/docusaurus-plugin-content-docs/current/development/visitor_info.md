# 訪客資訊對接

本頁說明微語系統中的訪客概念，以及訪客與註冊使用者的差異。

## 訪客是什麼

訪客對應後端 `VisitorEntity`，主要用於承載客服會話中的訪客身份。

典型特點：

- 預設無需登入
- 主要用於網站、H5、App、小程式等前端會話場景
- 不參與後台 RBAC 權限體系
- 不會被賦予管理員、客服、主管等角色

## 註冊使用者與訪客的差異

### 註冊使用者 User

- 對應 `UserEntity`
- 需要登入
- 可加入組織
- 可分配角色與權限

### 訪客 Visitor

- 對應 `VisitorEntity`
- 預設無需登入
- 只用於會話身份識別
- 不參與後台權限控制

## 常見誤區

業務系統中的登入會員，在接入微語客服時，通常會被映射為訪客，而不是直接成為後台註冊使用者。

也就是說：

- 會員 id 可以傳給 `visitorUid`
- 會員暱稱可以傳給 `nickname`
- 會員頭像可以傳給 `avatar`
- 這只是映射為會話訪客身份
- 不會自動建立 `UserEntity`
- 不會自動取得任何後台權限
