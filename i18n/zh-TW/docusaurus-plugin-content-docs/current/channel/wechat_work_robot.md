# 企業微信智能機器人（長連線）

## 功能簡介

微語支援透過「長連線」方式對接企業微信**智能機器人**。連線成功後，你在企業微信 PC 用戶端建立的智能機器人，將由微語的 AI 機器人作為「大腦」驅動，自動接收並回覆客戶訊息。整個過程無需設定回呼地址、無需撰寫程式碼，完成設定後即可投入使用。

這類機器人更適合「客戶與機器人一對一對話」的場景，例如智能諮詢、業務答疑、線索蒐集與服務分流。同時，它也可以被加入企業微信內部群聊，在群內透過 @ 機器人 的方式參與對話。如果你要對比傳統 Webhook 方式，請同時參考[企業微信群聊機器人](./wechat_work_group_robot.md)。

:::tip 前置條件

- 僅企業版和平台版支援此功能。如需開通，請[掃碼聯絡微信](/img/wechat.png)
- 企業微信**管理後台沒有建立智能機器人的入口**，建立入口在企業微信 PC 用戶端
- 請先在微語後台準備好可用的 AI 機器人；如需人工協同，建議同時準備好對應工作組
:::

## 第一步：在企業微信 PC 用戶端建立智能機器人

1. 開啟企業微信 PC 用戶端，進入「通訊錄 → 智能機器人」
2. 點擊「建立智能機器人」

![企業微信用戶端中的智能機器人入口](/img/wechat_work/wechat_work_create_bot.png)

1. 在建立頁面填寫機器人名稱、簡介等基礎資訊
2. 選擇 **API 模式**，用於與微語建立連線

![在企業微信用戶端中選擇 API 模式建立機器人](/img/wechat_work/wechat_work_create_bot_2.png)

1. 在 API 設定中選擇**長連線**方式
2. 記錄頁面展示的 **BotID** 和 **Secret**，下一步綁定微語時需要使用

![在企業微信用戶端中取得 BotID 和 Secret](/img/wechat_work/wechat_work_create_bot_3.png)

## 第二步：在微語後台綁定機器人

1. 登入微語管理後台
2. 進入「渠道 → 企業微信機器人」
3. 點擊「綁定」，填寫表單：

![微語後台綁定企業微信智能機器人](/img/wechat_work/wechat_work_bot_bytedesk.png)

| 欄位 | 說明 |
| --- | --- |
| 名稱 | 用於識別該機器人 |
| BotID | 企業微信 PC 用戶端中，智能機器人 API 模式下發的 BotID |
| Secret | 企業微信 PC 用戶端中，智能機器人 API 模式下發的 Secret |
| AI 機器人 | 選擇作為問答大腦的微語 AI 機器人 |
| 路由工作組 | 機器人會話路由到的工作組（客服協同） |
| WebSocket 位址 | 預設 `wss://openws.work.weixin.qq.com`，私有部署可覆蓋 |
| 是否啟用 | 是否在啟動時自動建立連線 |

1. 點擊「儲存」

如果你希望機器人先自動回覆，再在需要時轉交人工，建議在這裡一併設定好 AI 機器人與路由工作組。

## 第三步：建立長連線

儲存後點擊「連線」，微語會與企業微信建立持久的 WebSocket 長連線。連線成功後狀態顯示為 **CONNECTED**。如果你只是想確認目前連通情況，也可以在詳情頁中重新整理或查看狀態。

- **CONNECTING** — 正在連線
- **CONNECTED** — 已連線，可正常收發訊息
- **RECONNECTING** — 連線中斷，正在自動重連
- **DISCONNECTED** — 未連線
- **DISABLED** — 已停用

## 第四步：測試效果

你可以透過企業微信用戶端直接發起與機器人的一對一對話，驗證微語是否已經接管訊息處理。

![在企業微信用戶端中發起機器人對話](/img/wechat_work/wechat_work_bot_start_chat.png)

進入會話後，向機器人發送一條測試訊息，確認微語 AI 機器人能夠正常回覆。

![機器人一對一對話介面](/img/wechat_work/wechat_work_chat.png)

建議至少驗證以下兩項：

1. 機器人是否能正常收到訊息並回傳答案
2. 當 AI 無法獨立處理時，是否能依預期路由到目標工作組

## 第五步：按需加入企業微信群聊

如果你的使用場景需要在企業內部群組中呼叫機器人，也可以把該智能機器人加入群聊。加入後，可在群裡透過 @ 機器人的方式發起對話。

![企業微信內部群聊中的機器人對話示例](/img/wechat_work/wechat_work_group_chat.png)

這種方式適合內部協作、知識問答與群內輔助處理，但它底層仍然是智能機器人長連線能力，而不是傳統的群聊 Webhook 機器人。

## 智能機器人 與 群聊機器人 的區別

| | 群聊機器人 | 智能機器人（長連線） |
| --- | --- | --- |
| 對接方式 | Webhook 回呼地址 | WebSocket 長連線 |
| 使用場景 | 內部群聊通知、播報、簡單自動回覆 | 一對一對話，也可被加入企業內部群聊 |
| 設定方式 | 複製 Webhook 地址到微語後台 | 在微語後台綁定企業微信 PC 用戶端產生的 BotID + Secret |

群聊（Webhook）機器人的設定，請參考[企業微信群聊機器人](./wechat_work_group_robot.md)。

## 常見問題

**問：狀態一直顯示 CONNECTING，無法變成 CONNECTED？**

- 請確認 BotID 和 Secret 複製無誤
- 請確認該機器人在企業微信中已開啟「API 模式（長連線）」
- 請確認伺服器可以正常訪問 `wss://openws.work.weixin.qq.com`

**問：為什麼我在企業微信管理後台裡找不到「建立機器人」入口？**

這是正常現象。智能機器人的建立入口不在企業微信管理後台，而在企業微信 PC 用戶端的「通訊錄 → 智能機器人」中。

**問：剛連線成功，隨後又變成 RECONNECTING 或 DISCONNECTED？**

- 先檢查企業微信端設定是否仍然有效
- 再檢查伺服器網路是否穩定，以及是否存在代理、防火牆或出口策略限制 WebSocket 連線

**問：綁定後可以更換問答大腦嗎？**

可以。編輯該機器人，重新選擇 AI 機器人或路由工作組後儲存即可。

**問：這個功能和企業微信群聊機器人有什麼差別？**

智能機器人（長連線）主要用於客戶與機器人的一對一會話，也可以加入企業內部群聊；群聊機器人主要用於企業微信群內通知、播報與簡單自動回覆。兩者接入方式、使用場景與設定項都不同。

**問：智能機器人可以加入企業微信群聊嗎？**

可以。你可以先在企業微信用戶端中建立並設定好智能機器人，再將其加入企業內部群聊，在群裡透過 @ 機器人的方式使用。
