# 工具

微語中的 Tools，是 AI 工作流調用實際業務能力的執行層。它的核心作用，不是讓模型只輸出文本，而是讓模型在需要時能夠查詢資料、觸發動作、協同後端流程，從而完成真正可執行的業務操作。

## 一、微語中的 Tools 是什麼

在微語的 AI 架構中，Tools 用於把模型推理與可執行能力連接起來，常見場景包括：

- 查詢業務資料
- 觸發服務動作
- 透過結構化介面呼叫領域邏輯
- 讓大模型推理與後端流程協同工作

目前程式碼中已存在與工具相關的機器人設定、工具配置與部分領域工具抽象，說明 Tools 已經是微語 AI 能力的重要組成部分。

## 二、目前已有基礎

目前專案裡已經具備一些工具能力基礎：

- 機器人層級的 tools 清單與 tools 設定
- 部分模組中的後端工具抽象
- 面向外部開放 tools 與 agent 調用能力的後續規劃

這意味著微語已經具備從「純問答」走向「可執行 AI 工作流」的基礎結構。

## 三、Tools 適合解決什麼問題

當 AI 工作流不僅需要回答問題，還需要實際操作系統時，Tools 會非常有價值，例如：

- 查詢客戶資料或訂單資料
- 在客服會話中取得業務記錄
- 以可追蹤方式呼叫服務端動作
- 支撐客服助手、自動化流程與 AI Copilot 場景

## 四、與其它能力頁的關係

- [技能](./skills) 更偏向可複用的 AI 能力包與工作流知識。
- [MCP](./mcp) 更偏向標準協議層的外部 agent 互通。
- [文本模型指南](./model_text) 負責模型推理層配置。

## 五、總結

Tools 是微語 AI 推理層與業務執行層之間的橋樑。它是微語從簡單聊天回覆，走向智慧助手、可執行 Agent 與業務自動化的重要基礎能力。
