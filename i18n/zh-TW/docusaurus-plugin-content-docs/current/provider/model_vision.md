# 視覺能力總覽

微語的視覺能力主要面向客服場景中的截圖理解、圖片文本提取與圖像資訊結構化處理，幫助客服團隊更高效地處理客戶傳送的圖片類資訊。

本頁用於說明微語目前視覺能力的整體範圍。就現階段而言，微語已落地的核心視覺能力是 OCR。

## 一、微語中的視覺能力是什麼

在真實客服業務中，客戶經常會傳送各種圖片內容，例如：

- 系統報錯截圖
- 訂單頁面截圖
- 物流頁面截圖
- 付款憑證截圖
- 帳號資訊圖片

這些資訊往往包含關鍵業務欄位，但如果沒有視覺能力支援，客服只能靠人工閱讀與手動錄入，效率較低。

視覺能力的價值在於把圖片中的資訊轉成可處理、可複用、可檢索的結構化內容，為人工客服與 AI 自動化處理提供統一輸入。

## 二、目前已支援的視覺能力

目前微語已落地的主要視覺能力為：

- [OCR 能力介紹](./model_ocr)

OCR 可以從截圖、聊天圖片與票據圖片中提取文字內容，讓圖片中的資訊變成可複製、可搜尋、可歸檔的文本。

## 三、視覺能力與其它能力的關係

視覺能力通常需要和其它能力協同使用：

- OCR 負責把圖片轉成文本
- ASR 負責把語音轉成文本
- TTS 負責把文本轉成語音

它們共同構成微語在客服場景中的多模態能力基礎。

## 四、推薦閱讀路徑

1. 先閱讀 [OCR 能力介紹](./model_ocr)，了解目前已落地的圖片文本提取能力。
2. 再閱讀 [語音與視覺能力總覽](./model_audio)，從更高層理解 OCR、ASR、TTS 三者之間的關係。

## 五、總結

微語的視覺能力目標，是幫助客服團隊更高效地處理截圖與圖片證據。目前 OCR 已經是可以直接投入使用的視覺能力，也是後續擴展更豐富圖像理解場景的基礎入口。
