# TTS 能力介紹

微語客服系統支援 TTS（Text To Speech，文本轉語音）能力，可將文本內容即時合成為語音，用於客服播報、語音回覆、輔助溝通、無障礙服務與 AI 語音互動等場景。

## 一、TTS 可以解決什麼問題

在客服業務中，很多場景不僅需要文字回覆，也需要更自然的語音表達。例如面向長者用戶、弱閱讀用戶、電話場景、語音接待場景，或者客服希望快速播放標準話術時，文本轉語音會明顯提升溝通效率。

接入 TTS 後，微語可以幫助企業實現：

- 將客服文本訊息直接播報為語音
- 將標準回覆、通知、引導語自動合成為語音
- 為 AI 客服、語音機器人、電話場景提供語音輸出能力
- 讓知識、話術與流程具備更自然的語音互動方式

## 二、微語已支援的 TTS 能力

目前版本已支援以下 TTS 相關能力：

### 1. 管理後台 TTS 測試與配置

管理後台已提供獨立的 TTS 測試入口，可直接輸入文本並執行語音合成，便於管理員確認目前組織下的 TTS 能力是否可用，並驗證實際參數效果。

目前頁面已支援以下測試能力：

- 輸入待合成文本並立即執行 TTS
- 按語言篩選可用音色，目前介面可見語言包括簡體中文、粵語 / 繁體中文、英語、日語、韓語、法語、德語、西班牙語
- 查看音色名稱、音色代碼、適用場景、特質，以及是否支援 SSML / Instruct / 時間戳等資訊
- 對部分已接入本地試聽資源的音色直接播放預覽音訊
- 選擇音訊輸出格式，例如 mp3、wav
- 在進階設定中查看 DashScope TTS 模型說明與適用場景

測試呼叫會同步記錄到 TtsEntity 表中，方便營運分析、問題排查與能力驗證；列表頁也可直接查看文本內容、模型、語言、音色、執行狀態、音訊結果與建立時間，並支援單筆刪除與批次刪除。

### 自訂音色

依照最新實作，這裡更準確地說是音色瀏覽與選擇輔助，而不是完全自由的音色自訂。頁面會依目前語言過濾出可用音色，並展示音色說明與試聽資訊，幫助管理員快速判斷哪種聲音風格更適合客服場景。

需要注意的是，目前後台測試鏈路仍以系統預設音色路徑為主，頁面主要承擔以下作用：

- 快速瀏覽目前模型支援的系統音色
- 確認哪些音色適合客服播報、語音助手、專業播報等不同場景
- 判斷某個音色是否具備本地試聽資源，或是否需要前往官方音色列表進一步試聽
- 在正式接入前完成語言與音色相容性確認

![tts_yinse](/img/tts/tts_yinse.png)

### 自訂模型

結合最新後台實作，這裡建議理解為模型選型說明與進階參數確認。頁面已整理出多種 DashScope TTS 模型的能力說明，包括高品質、低延遲、低成本、多語言、教育朗讀、品牌音色定製等不同方向，便於管理員評估。

現階段後台測試鏈路已固定在 DashScope TTS 能力範圍內，預設執行模型為 cosyvoice-v3-flash。頁面保留模型候選、標籤說明與官方文件入口，主要用於：

- 了解不同模型的適用場景與注意事項
- 比較 plus / flash / v1 / v2 / v3 系列能力差異
- 為後續正式配置或版本擴充提供選型依據
- 避免在不相容模型下誤配系統音色

![tts_model](/img/tts/tts_model.png)

### 2. 客服工作台文本訊息語音播放

在 desktop 客服端中，客服可對文本訊息使用右鍵選單，直接執行語音播放。

這項能力適用於：

- 快速試聽客服或客戶的文本內容
- 在忙碌場景下以聽音代替閱讀
- 輔助多工處理與長文本瀏覽

系統優先走後端 TTS 合成鏈路，在適配場景下可將文本轉換為語音進行播放。

## 三、典型應用場景

### 1. 客服標準話術播報

- 將常見回覆、服務說明、流程提醒轉換為語音
- 降低重複朗讀成本
- 保持話術表達一致性
- 支援在正式上線前先透過後台測試頁確認語言、預設音色與輸出格式

### 2. AI 語音回覆基礎能力

- 機器人或大模型生成文本後，透過 TTS 輸出語音
- 為後續語音客服、電話客服、數位人客服提供基礎能力
- 支撐更自然的人機對話體驗
- 可透過後台執行記錄持續觀察合成成功率、失敗原因與音訊輸出效果

### 3. 無障礙與多場景互動

- 適配不方便閱讀文本的使用者族群
- 適配耳機、外呼、音訊播報等場景
- 提升行動辦公與複雜業務場景下的資訊取得效率

## 四、能力價值

微語 TTS 能力的核心價值在於：

- 將靜態文本轉化為可聽內容
- 提升客服響應效率與溝通自然度
- 為 AI 語音化輸出提供統一基礎設施
- 為電話、音訊客服、智慧助手等場景打好能力底座

## 五、推薦使用方式

建議企業按照以下方式使用 TTS：

- 先在管理後台完成文本轉語音測試，確認語言、預設音色、模型說明與輸出格式
- 在客服工作台中使用文本訊息語音播放能力
- 借助後台執行記錄持續排查失敗任務、驗證音訊結果並沉澱營運資料
- 逐步將 TTS 與機器人、AI 助手、語音通知與電話場景打通

## 六、總結

微語已具備面向客服場景的 TTS 基礎能力，包括後台測試、語言與音色輔助選擇、模型選型說明、文本轉語音記錄沉澱以及桌面端文本訊息語音播放。對於需要語音播報、標準話術複用、AI 語音輸出的企業來說，TTS 是建設智慧客服與語音客服體系的重要基礎能力。
