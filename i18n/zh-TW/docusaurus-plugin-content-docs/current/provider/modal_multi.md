# Multimodal Integration

微語支援多模態工作流，這代表系統可以理解並處理使用者上傳的圖片、影片與音訊，再結合知識庫輸出更精準的回答。

## 概述

多模態整合代表系統可接收文字、圖片、影片與音訊輸入，並將它們轉換成統一的理解結果，用於檢索、推理與回覆生成。在微語中，這讓客服機器人可以：

- 讀取並理解上傳圖片
- 從影片內容中提取有用資訊
- 轉錄並理解音訊內容
- 將多模態輸入與企業知識庫結合
