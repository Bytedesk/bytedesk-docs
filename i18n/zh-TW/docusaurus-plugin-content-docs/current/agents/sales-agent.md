# 售中 Agent

售中 Agent 面向銷售旅程中的成交環節，覆蓋報價說明、下單引導、付款提醒、履約諮詢，以及客服系統與業務系統之間的協同。它的目標是減少從諮詢到交付之間的摩擦，幫助企業穩住成交過程。

本文件描述產品方向與實作規劃，相關能力會隨著微語對訂單、付款、物流和外部業務工具的接入逐步完善並分階段上線。

## 適用場景

- 客戶詢問如何購買、升級、續費或組合購買產品與服務。
- 客服或銷售需要解釋報價、折扣、套餐和交付週期。
- 客戶在付款、確認訂單或提交資料階段猶豫。
- 服務團隊需要查詢訂單狀態、庫存、發貨、發票或合約進度。
- B2B 團隊需要把線上諮詢平滑轉交給銷售營運流程。

## 核心能力

- 下單引導：說明購買步驟、所需資訊、付款方式和交付時間。
- 報價輔助：基於配置的商品、折扣和審批規則生成報價草稿。
- 業務查詢：透過具備權限控制的工具查詢訂單、客戶、合約、發票和物流資料。
- 履約協同：提醒待付款、資料缺失、發貨延遲和審批卡點。
- 人工交接：把價格例外、商務談判、大客戶和敏感商業問題升級給人工處理。

## 實作規劃

1. 定義銷售階段狀態，例如有意向、已報價、待付款、已付款、履約中、異常延遲和已完成。
2. 透過受控工具層接入 CRM、訂單、付款、合約、發票和物流介面。
3. 為折扣、承諾邊界、退款邊界和合規話術配置組織級策略提示詞。
4. 實作報價草稿、訂單詳情、付款提醒和履約進度等結構化卡片訊息。
5. 允許 Agent 為人工銷售或營運團隊建立跟進任務、關聯工單和內部備註。
6. 從會話、訂單和客戶維度追蹤成交與履約指標。

## 衡量指標

- 縮短從諮詢到訂單確認的時間。
- 降低因價格、流程或付款資訊不清導致的流失。
- 提升待付款與履約異常的可見性。
- 保持跨通路、跨客服的一致銷售溝通品質。
- 讓客服、銷售和營運之間的交接記錄更清晰。

## 與其他 Agent 的關係

售中 Agent 接收售前 Agent 識別出的成交意圖，並把服務問題轉交給售後 Agent。人工客服在處理業務系統問題時，也可以透過客服助手 Agent 呼叫售中 Agent 的能力。
