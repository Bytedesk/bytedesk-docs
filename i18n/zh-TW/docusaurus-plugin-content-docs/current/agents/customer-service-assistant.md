# 客服助手 Agent

客服助手 Agent 是面向人工客服的 AI Copilot。它幫助客服快速理解客戶背景、檢索可信知識、生成回覆草稿、摘要會話內容，並推薦下一步服務動作，讓 AI 成為客服團隊的一部分，而不是取代人工服務流程。

本文件描述產品方向與實作規劃，相關能力會隨著微語 AI、知識庫、工作流程、工單和資料分析模組逐步完善並分階段上線。

## 適用場景

- 網站客服、行動端客服、社群私訊、郵件、呼叫中心等全通路接待過程中的即時輔助。
- 針對重複問題進行知識庫檢索和回覆草稿生成。
- 自動生成會話摘要、客戶意圖、情緒訊號和服務質檢提醒。
- 當問題需要持續跟進時，建議建立工單或升級處理。
- 根據客戶上下文推薦轉接、升級、補償、回訪或工作流程動作。
- 當通話從 IVR 或語音服務 Agent 轉人工時，為坐席提供連續接待輔助。

## 核心能力

- 上下文感知：讀取會話歷史、訪客畫像、組織、通路、標籤、訂單、工單和知識庫權限。
- 回覆建議：基於已審核知識、FAQ 和優秀歷史回覆生成可編輯的回覆草稿。
- 服務提醒：提示客服注意語氣、缺失資訊、SLA 風險、敏感詞和未解決意圖。
- 摘要自動化：為會話關閉、工單流轉、質檢複盤和後續跟進生成結構化摘要。
- 動作推薦：建議建立工單、添加標籤、預約回訪、轉接專家或觸發工作流程。
- 轉接連續性：展示語音已採集欄位、轉寫重點、信心分數信號和下一步建議，讓人工坐席不用重新詢問。

## 實作規劃

1. 建構會話上下文組裝器，彙整訊息、訪客畫像、客服資料、組織設定、知識片段和訂單/工單引用。
2. 為不同工作組、客服角色、通路和服務場景配置可調整的助手提示詞。
3. 在 Desktop 客服工作台中實作串流回覆建議，並提供採納、編輯、拒絕和重新生成操作。
4. 持久化已採納建議、會話摘要和質檢回饋，讓系統從優秀人工回覆中持續學習。
5. 增加具備權限控制的工具呼叫能力，包括知識檢索、客戶查詢、工單建立、訂單查詢和工作流程執行。
6. 在呼叫中心場景中，將通話記錄、錄音、ASR 轉寫和語音 Agent 摘要接入客服工作台。
7. 建立採用率、採納率、回應時間降低、摘要準確率、轉接連續性和服務品質提升等分析指標。

## 衡量指標

- 降低平均首次回應時間和會後處理時長。
- 提升一次解決率和知識命中率。
- 讓新老客服都能保持更穩定的服務品質。
- 提升工單摘要品質，減少跟進資訊遺漏。
- 將優秀人工服務經驗沉澱為可複用的知識和流程。

## 與其他 Agent 的關係

客服助手 Agent 是整套智慧體系統面向人工客服的工作台。它可以呼叫售前 Agent 處理商品/方案諮詢，呼叫售中 Agent 輔助訂單與成交，呼叫售後 Agent 處理投訴和退換貨，呼叫語音服務 Agent 取得呼叫中心上下文，也可以呼叫營運 Agent 進行客戶分群和後續觸達建議。
