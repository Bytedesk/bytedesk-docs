# 營運 Agent

營運 Agent 用於把服務會話轉化為可複用的成長資產。它幫助團隊進行客戶分群、發現營運機會、設計活動策略、觸發精準跟進，並複盤客戶全生命週期中的服務與成長效果。

本文件描述產品方向與實作規劃，相關能力會隨著客戶資料、標籤、工作流程、通路觸達和資料分析模組逐步完善並分階段上線。

## 適用場景

- 市場與營運團隊希望啟用存量客戶，而不是只依賴新增流量。
- 服務團隊從會話中發現重複需求、購買異議或產品問題。
- 管理者希望識別哪些客戶需要跟進、教育、續費、挽回或關懷。
- 企業需要面向沉睡用戶、高意向訪客、復購用戶、VIP 客戶和不滿意客戶自動觸達。
- 組織需要建立從服務資料到活動執行再到效果複盤的閉環。

## 核心能力

- 客戶資產沉澱：彙聚畫像、通路、行為、會話、訂單、工單、標籤和滿意度資料。
- 客戶分群：按意圖、生命週期階段、價值、風險、商品興趣和服務歷史生成動態人群。
- 策略生成：推薦活動主題、目標人群、觸達內容、觸達時間、通路和預期目標。
- 工作流程執行：觸發訊息、任務、回訪、優惠、問卷、知識推送或人工跟進。
- 複盤優化：對比活動前後的轉化、留存、復購、滿意度和服務工作量變化。

## 實作規劃

1. 建立連接訪客、用戶、成員、組織、通路、會話、訂單、工單和標籤的客戶資料模型。
2. 增加生命週期、意圖、價值、風險、滿意度和通路行為等分群定義與規則建構器。
3. 沉澱線索培育、復購、續費、防流失、投訴挽回和客戶教育等營運劇本。
4. 將活動動作連接到郵件、簡訊、公眾號通知、網頁會話、社群通路和內部任務。
5. 增加審批、頻控、退訂、隱私和稽核控制，確保自動觸達可控合規。
6. 建構分群成長、活動轉化、復購、留存、滿意度和 ROI 看板。

## 衡量指標

- 從既有流量和服務會話中啟用更多客戶。
- 提升復購率、續費率和留存率。
- 更清楚地看到客戶生命週期階段與成長機會。
- 降低人工分群和跟進的工作量。
- 建立跨通路可衡量的服務到成長閉環。

## 與其他 Agent 的關係

營運 Agent 消費客服助手 Agent、售前 Agent、售中 Agent 和售後 Agent 產生的訊號，並把優化後的標籤、活動和客戶策略回饋到服務旅程中，讓每個 Agent 隨著業務營運持續變得更懂客戶。
