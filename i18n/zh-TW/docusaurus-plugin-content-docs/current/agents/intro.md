# 微語 AI 智慧體

微語 AI 智慧體是面向客戶全生命週期規劃的數位化團隊成員。它把全通路會話、知識庫問答、工作流程自動化、CRM 客戶畫像、訂單資料、工單與資料分析連接起來，讓企業把每一次服務對話沉澱為可複用的客戶資產。

目前 Agent 文件用於說明產品方向與後續實作規劃，部分能力會隨著 AI、工作流程、通路、工單和營運模組逐步完善並分階段上線。

## 智慧體矩陣

- [客服助手 Agent](./customer-service-assistant.md)：輔助人工客服完成回覆建議、知識檢索、會話摘要、質檢提醒和下一步動作推薦。
- [售前 Agent](./pre-sales-agent.md)：識別訪客意圖，推薦商品或方案，收集線索，並引導訪客完成轉化。
- [售中 Agent](./sales-agent.md)：支援報價、下單引導、付款提醒、履約諮詢，以及服務系統與業務系統之間的協同。
- [售後 Agent](./after-sales-agent.md)：處理訂單、物流、退款、退換貨、保固、投訴和工單跟進等場景。
- [語音服務 Agent](./voice-service-agent.md)：把呼入接待、語音 IVR、報修受理、預約確認、工單派發、服務回訪和客訴預警串成服務履約閉環。
- [營運 Agent](./operations-agent.md)：把服務資料轉化為用戶分群、活動觸達、復購營運和成長分析。

## 產品理念

微語將 AI Agent 定位為能夠執行業務動作的數位員工，而不是簡單的聊天機器人。長期架構圍繞一個閉環展開：

1. 會話產生結構化客戶資料。
2. 客戶資料沉澱為畫像、標籤、意圖和服務歷史。
3. 智慧體基於上下文提供個人化服務，並觸發自動化流程。
4. 營運團隊複盤效果，持續優化知識、流程、轉化與留存。

透過這個閉環，客服不再只是成本中心：客服助手降低人工負擔，售前提升轉化，售中保障成交，售後守住滿意度，營運把每次互動變成可複用的成長洞察。

## 服務閉環設計

智慧體系統不能停留在「回答問題」。真實服務工作的難點，是整條鏈路不能斷：客戶來電後，系統要識別意圖、採集必要欄位、建立工單、完成派單、追蹤履約、確認結果，並把風險信號回饋給營運和管理者。

微語圍繞這個閉環設計 Agent 時遵循四個原則：

1. 優先選擇目標清晰、流程可拆、結果可驗的場景，例如報修受理、報裝預約、進度確認、滿意度回訪和客訴回訪。
2. 將自然對話轉化為結構化業務資料，包括客戶身分、地址、設備、訂單、問題分類、緊急程度、預約時間、憑證和期望結果。
3. 將 Agent 接入可執行系統，包括 CRM、訂單、工單、工作流程、通話記錄、錄音、ASR 轉寫、知識庫和通知通路。
4. 持續營運 Agent，重點觀察轉人工率、完成率、Bad Case、打斷節點、缺失欄位、客戶回饋和人工複盤結果。

在這個模型中，Agent 是服務流程裡的數位執行單元。它的價值不只是和客戶對話，而是幫助企業看見、推進並持續優化完整服務過程。
