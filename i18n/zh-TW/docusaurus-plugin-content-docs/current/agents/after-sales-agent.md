# 售後 Agent

售後 Agent 面向購買後的服務場景，包括訂單狀態、物流、退款、退換貨、保固、投訴、維修和工單跟進。它幫助企業守住客戶滿意度，同時減少客服團隊在重複售後問題上的工作量。

本文件描述產品方向與實作規劃，相關能力會隨著訂單、工單、呼叫中心、知識庫和工作流程整合逐步完善並分階段上線。

## 適用場景

- 客戶諮詢訂單狀態、配送、發票、退款、退貨、換貨或保固。
- 服務團隊需要對投訴和異常問題進行結構化受理。
- 客戶需要及時收到物流延遲或工單處理進展通知。
- 呼叫中心與線上客服會話需要關聯工單、錄音和文字轉寫記錄。
- 管理者需要查看售後分類、根因、SLA 風險和質檢訊號。
- 語音 Agent 場景需要承接報修受理、進度確認、滿意度回訪和客訴預警等售後流程。

## 核心能力

- 自助解答：回答常見訂單、物流、退款、退換貨和保固問題。
- 案件受理：收集必要欄位、憑證、圖片、訂單號、聯絡方式和期望處理方式。
- 工單自動化：根據會話內容建立、分類、分派、摘要和更新工單。
- SLA 監控：識別逾時、重複投訴、負面情緒和升級風險。
- 主動跟進：向客戶同步處理進度、待補充材料、解決結果和滿意度評價。
- 服務結果確認：透過線上訊息或語音回訪確認問題是否解決、服務承諾是否兌現。

## 實作規劃

1. 透過具備權限控制的查詢工具接入訂單、物流、保固、退款和工單資料。
2. 定義退款、退貨、投訴、維修、回訪和升級等售後場景模板。
3. 增加訂單狀態、工單進度、憑證收集和處理確認等結構化卡片。
4. 將聊天、通話記錄、錄音、ASR 文字、工單和客戶畫像關聯到統一售後時間線。
5. 針對 SLA 逾時、高價值客戶、重複投訴和負面情緒配置升級規則。
6. 增加進度確認、滿意度調研、客訴挽回和未解決工單跟進等回訪工作流程。
7. 建立問題分類、解決時長、滿意度、重複聯絡、升級率、回訪完成率和產品缺陷趨勢等看板。

## 衡量指標

- 提升重複售後問題的自助解決率。
- 縮短工單建立時間，並提高案件資訊完整度。
- 降低重複聯絡率，減少跟進遺漏。
- 更清楚地識別投訴原因和產品/服務缺陷。
- 提升滿意度與購買後的信任感。

## 與其他 Agent 的關係

售後 Agent 接收來自各通路的服務問題。它可以向售中 Agent 查詢訂單上下文，透過客服助手 Agent 輔助人工處理複雜案件，與語音服務 Agent 協同完成報修和回訪場景，並將售後問題洞察同步給營運 Agent，用於客戶挽回和復購營運。
