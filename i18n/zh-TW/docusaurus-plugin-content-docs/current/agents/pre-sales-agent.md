# 售前 Agent

售前 Agent 用於幫助訪客明確需求、比較方案、獲得個人化推薦，並留下高品質線索。它把被動諮詢轉化為有引導的成交機會，同時讓人工銷售團隊專注處理更高價值的客戶。

本文件描述產品方向與實作規劃，相關能力會隨著商品資料、客戶畫像、工作流程自動化和通路整合逐步完善並分階段上線。

## 適用場景

- 官網、獨立站、落地頁中的訪客購買前諮詢。
- 商品、套餐、價格、功能、服務範圍和產業方案比較。
- B2B、教育、醫療、零售、房產等產業的線索初篩。
- 社群私訊接待、主動建聯和線索收集。
- 訪客停留、瀏覽商品、重複搜尋或表達明確意圖後的主動邀請。

## 核心能力

- 意圖挖掘：識別預算、使用場景、緊急程度、客戶角色、地區、來源通路和採購階段。
- 方案推薦：根據客戶需求匹配商品、套餐、解決方案、文件和知識庫內容。
- 線索收集：採集姓名、電話、公司、需求、預計採購時間和偏好聯絡方式。
- 轉化引導：推薦演示、試用、優惠、預約、表單或轉人工銷售。
- 風險識別：發現猶豫、異議、價格敏感、競品比較和流失風險。

## 實作規劃

1. 按組織或工作組配置售前表單、線索欄位和線索評分規則。
2. 接入商品目錄、解決方案文件、價格規則、FAQ 和客戶案例。
3. 基於頁面路徑、來源、停留時長、訪問次數和訊息意圖配置主動觸發規則。
4. 將合格線索沉澱到 CRM，並關聯會話、訪客、通路和負責人。
5. 支援預約演示、分配銷售、發送資料、建立跟進任務等工作流程動作。
6. 建立線索收集率、有效線索率、轉人工率和後續成交進展等分析指標。

## 衡量指標

- 提升諮詢到留資的轉化率。
- 讓人工跟進前獲得更完整的客戶資訊。
- 更快回應全通路高意向訪客。
- 打通市場、售前和銷售團隊之間的協作。
- 減少因商品問題無人回應或回應延遲導致的流失。

## 與其他 Agent 的關係

售前 Agent 負責需求發現和線索建立。當客戶準備下單時，可交給售中 Agent；當客戶提出已有訂單或服務問題時，可轉給售後 Agent 或人工客服。
