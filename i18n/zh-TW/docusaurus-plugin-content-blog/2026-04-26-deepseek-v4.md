DeepSeek 已於 2026 年 4 月發布 DeepSeek-V4 預覽版，正式推出 deepseek-v4-flash 與 deepseek-v4-pro 兩個新模型。微語目前版本已經支援這兩個最新模型，企業可以直接在微語管理後台完成切換與配置，無需改動集成方式。

<!-- truncate -->

## DeepSeek-V4 帶來了什麼

根據 DeepSeek 官方發布說明，DeepSeek-V4 預覽版重點帶來以下變化：

- 支援 1M 超長上下文，更適合長文件問答、複雜知識庫和多輪業務對話
- Agent 能力進一步增強，在程式碼生成、文件生成和工具調用場景中表現更強
- 提供更清晰的產品分層：deepseek-v4-pro 面向高品質複雜任務，deepseek-v4-flash 面向高性價比與更快回應場景

對於客服、智慧問答、知識庫檢索和自動化流程這類業務來說，長上下文和 Agent 能力的提升都非常關鍵。尤其是在需要持續理解歷史會話、工具調用結果和業務文件時，DeepSeek-V4 會比舊模型更穩定。

## 微語目前已支援的 DeepSeek 新模型

在微語的模型配置中，DeepSeek 供應商下已提供以下模型：

| 模型名 | 說明 | 適用場景 |
| --- | --- | --- |
| deepseek-v4-flash | 快速、經濟、回應延遲更低 | 線上客服、常見問題、批量問答 |
| deepseek-v4-pro | 能力更強，適合複雜推理與 Agent 任務 | 複雜業務流程、知識庫深問、智慧助手 |
| deepseek-chat | 舊模型名，將於 2026-07-24 停止使用 | 僅用於相容舊配置 |
| deepseek-reasoner | 舊模型名，將於 2026-07-24 停止使用 | 僅用於相容舊配置 |

也就是說，如果你此前已經在微語中使用 DeepSeek，現在只需要在 AI 模型配置頁把模型切換為 deepseek-v4-flash 或 deepseek-v4-pro，即可開始使用最新能力。

## 舊模型名棄用說明

DeepSeek 官方已明確說明：

- deepseek-chat 將於 2026-07-24 停止使用
- deepseek-reasoner 將於 2026-07-24 停止使用

在目前過渡階段，這兩個舊模型名仍然可用，但它們主要用於相容舊配置：

- deepseek-chat 目前指向 deepseek-v4-flash 的非思考模式
- deepseek-reasoner 目前指向 deepseek-v4-flash 的思考模式

如果你正在新建機器人、工作組或租戶級 AI 配置，建議直接使用 deepseek-v4-flash 或 deepseek-v4-pro，不再繼續依賴舊模型名。

## 微語中的建議遷移方式

如果你已經在生產環境使用 DeepSeek，建議按下面方式遷移：

### 1. 優先從舊模型名切換到新模型名

將預設模型從下列舊值替換為新值：

- deepseek-chat -> deepseek-v4-flash
- deepseek-reasoner -> deepseek-v4-pro 或 deepseek-v4-flash

如果你的場景更看重回應速度和成本，優先使用 deepseek-v4-flash；如果更看重複雜推理、長鏈路任務和 Agent 表現，優先使用 deepseek-v4-pro。

### 2. 保持 base URL 不變

DeepSeek-V4 的 API 接入方式沒有改變，仍然使用原有 DeepSeek API 地址：

```bash
https://api.deepseek.com
```

遷移時主要修改的是 model 參數，而不是接入地址。

### 3. 在微語後台完成切換

你可以直接在微語管理後台中完成以下操作：

1. 登入管理後台
2. 進入 AI 模型配置頁面
3. 選擇 DeepSeek 作為模型供應商
4. 將預設模型切換為 deepseek-v4-flash 或 deepseek-v4-pro
5. 儲存並測試對話效果

整個過程不需要重新嵌入聊天程式碼，也不需要改動訪客端接入方式。

## 選擇建議

如果你不確定該如何選擇，可以參考下面的實踐建議：

- 線上客服機器人預設首選 deepseek-v4-flash
- 複雜業務問答、知識庫深度問答、工作流助手優先選擇 deepseek-v4-pro
- 對歷史配置做相容保留時，可暫時保留 deepseek-chat 與 deepseek-reasoner，但應盡快遷移

## 總結

隨著 DeepSeek-V4 發布，微語已經同步支援最新的 deepseek-v4-flash 與 deepseek-v4-pro。對於需要長上下文、複雜推理、Agent 協作和更高品質自動化客服體驗的團隊來說，這是一輪值得儘快完成的升級。

如果你已經在使用微語對接 DeepSeek，建議盡快把預設模型從 deepseek-chat 或 deepseek-reasoner 遷移到新的 V4 模型名稱，以避免後續棄用帶來的影響。
