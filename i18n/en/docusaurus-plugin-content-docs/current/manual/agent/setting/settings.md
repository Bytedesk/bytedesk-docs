# Settings

The settings page maintains your profile and adjusts interface and notification preferences.

![Settings page](/img/manual/agent/setting.png)

## Profile

Under "Profile" you can maintain:

- **Avatar**: upload a personal avatar
- **Nickname**: display name
- **Email / phone**: bound account information
- **Bio**: personal introduction

## Agent Profile

Accounts with the agent role can maintain the agent profile under "Agent settings": avatar, nickname, email, phone, description, etc.

## General Settings

General settings provide the following options:

| Option | Description |
| --- | --- |
| Message sound | Sound alert for new messages |
| Network status notice | Reconnection reminders |
| Message notifications | Desktop notifications |
| Agent assistant switch | Enable/disable the AI assistant |
| Order info switch | Show order info in conversations |
| Theme | Light / Dark / Follow system |
| Language | Interface language |
| Translation | Provider and target language |
| Mode | Team / Agent / Personal mode |

Notes on frequently used options:

- **Auto-accept next queued visitor**: after ending the current conversation, the next queued visitor is accepted automatically, reducing manual steps
- **Theme**: switch light/dark mode or follow the system
- **Translation**: after configuring a provider and target language, use "Translate" in the message context menu

:::tip Tip
Enable "Message notifications" and "Message sound" to avoid missing new conversations; switch to dark mode for night shifts.
:::

## Notifications

The "Notifications" tab lists system notifications:

- **Transfer/invite requests**: transfers or invites from colleagues
- **Transfer/invite results**: accepted, declined, timed out, cancelled
- **New-ticket notices**: ticket number, priority, and status

Supports viewing, marking read, marking all read, and refreshing.

## Favorites

The "Favorites" tab aggregates messages you favorited in conversations for quick review and reuse.
