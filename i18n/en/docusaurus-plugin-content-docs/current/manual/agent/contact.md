# Contacts

Contacts manage internal members and external contacts, making it easy to start conversations and find customers.

![Contacts](/img/manual/agent/contact.png)

## Contact Categories

The left side organizes contacts into:

| Category | Description |
| --- | --- |
| Internal contacts | Members of the organization |
| External contacts | Visitors and external customers |
| New contacts | Recently added contacts |
| Starred contacts | Favorited contacts |
| Email contacts | Contacts imported from email |
| My groups | Groups you joined |
| Service desk | Service-desk contacts |

## Finding Contacts and Starting Conversations

1. Select a category on the left
2. Find the target contact in the list
3. Click the contact to view the profile and start a conversation

The search box at the top supports searching by nickname, phone number, email, and other keywords.

## Wide Layout

On wide screens contacts show the full category tree and contact list:

![Contacts wide layout](/img/manual/agent/contact-wide.png)

:::note Note
The Contacts menu depends on account permissions; if it is missing, the account lacks the contact permission.
:::
