# Todo and Calendar

The Todo page contains a calendar and a to-do list, helping agents schedule and track tasks.

![Todo page](/img/manual/agent/todo.png)

## Calendar

The calendar shows schedules and task distribution in a month view:

- Click a date to quickly view that day's arrangements
- Schedule entries are color-coded by type
- You can create new schedules or tasks directly in the calendar

## Todo

The to-do list gathers tasks to handle:

- **Pending**: newly created or assigned tasks not yet started
- **In progress**: tasks being handled
- **Completed**: finished tasks

For each task you can view details, mark complete, update progress, or delete it.

## Typical Usage

1. After starting work, open "Todo" to view today's tasks and plan by priority
2. During reception, create a to-do for anything promised to a visitor
3. Check items off when done to keep tasks closed-loop

:::note Note
Todo and Calendar require their own permissions; without permission the page shows a notice. Contact your administrator.
:::
