# Agent Desktop Quick Start

The Agent Desktop is the unified workspace where agents handle customer conversations, process tickets, and collaborate to resolve issues. This guide helps you get familiar with the workspace and complete the flow from login to serving your first visitor.

## What Is the Agent Desktop

The workspace provides these core capabilities:

- **Conversation handling**: accept and reply to visitors via text, images, files, and voice
- **Ticket processing**: create tickets from conversations; track processing, transfer, resolution, and verification
- **AI assistant**: generate reply suggestions, conversation summaries, and next-step suggestions
- **Data and records**: review conversation history, customer profiles, and offline messages

## Getting Access and Signing In

1. Get an agent account from your administrator (username/password or phone number)
2. Open the desktop client or web entry of the workspace
3. Choose a login method: account and password, phone number with verification code, or QR code
4. After login the workspace opens the "Chat" page by default

:::tip Tip
If you see "Access denied" on first use, the account usually lacks the agent role or permissions. Contact your administrator.
:::

## Interface Overview

![Agent desktop chat page](/img/manual/agent/chat.png)

On wide screens the workspace shows the full four-column layout:

![Agent desktop wide layout](/img/manual/agent/chat-wide.png)

The left side is the **main navigation**, which by default contains (depending on permissions and edition):

| Menu | Description |
| --- | --- |
| Chat | Conversation workspace for receiving and replying to visitors |
| Tickets | Ticket list and processing |
| Todo | Calendar and to-do items |
| Contacts | Internal and external contacts |
| Data | Conversation records, customer management, and messages |
| Settings | Profile, preferences, and notifications |

The "Chat" page uses a four-column layout: **conversation categories, conversation list, chat window, and right panel**. When the window narrows, the right panel and category list collapse in turn.

## Switching Availability Status

Click your avatar in the lower-left corner to switch availability:

![Availability status switching](/img/manual/agent/status.png)

| Status | Description |
| --- | --- |
| Available | Receive new conversations; the system keeps assigning new visitors |
| Rest | Temporarily away; no new visitors (a rest reason such as meeting or training can be selected) |
| Busy | Handle current conversations only; no new visitors |
| Offline | No new conversations or messages |

:::warning Note
Before going offline or exiting, the system confirms if you still have ongoing conversations, to avoid losing visitors by accident.
:::

## A Day in the Workspace

1. **Go online**: log in and switch to "Available"
2. **Accept**: accept visitors from the "Queue" category and start chatting
3. **Reply**: use text, images, quick replies, or the AI assistant
4. **Collaborate**: transfer or invite colleagues when help is needed
5. **Create tickets**: for complex issues, create a ticket from the conversation
6. **Close**: end the conversation when the issue is resolved and invite the visitor to rate
7. **Go offline**: finish ongoing conversations and switch to "Offline"
