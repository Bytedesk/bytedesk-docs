# Ticket Processes

![Ticket process page](/img/manual/admin/ticket/process.png)

Ticket processes define status transitions and handling nodes of tickets.

## Page Layout

The left side is the process type tree; the right side the process list.

## Managing Processes

- **Create / edit**: create or modify process definitions
- **Open the editor**: orchestrate the flow in the visual editor
- **Deploy / undeploy**: publish or take a process offline
- **View deployment**: see deployment ID and status

:::note Note
Only deployed processes can be used by tickets; after modification, redeploy to take effect.
:::
