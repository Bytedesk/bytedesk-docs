# Ticket Settings

![Ticket settings page](/img/manual/admin/ticket/settings.png)

Ticket settings configure basic rules, categories, SLA, and visibility.

## Page Layout

The left side lists settings; the right side shows configuration tabs of the selected setting, with an "External / Internal" scope switch.

## Configuration Items

| Item | Description |
| --- | --- |
| Basic settings | Basic ticket rules |
| Category settings | Ticket categories and fields |
| Process and form | Bound process and form |
| SLA settings | Timeliness and service levels |
| Notification settings | Status-change notifications |
| Auto-create | Rules for automatic ticket creation |
| Visibility settings | Department and member visibility |

## Managing Settings

1. Click "Create" for a new setting, or select an existing one to "Edit"
2. Configure the tabs
3. Bind a workgroup
4. "Publish" to take effect
