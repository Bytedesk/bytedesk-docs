# Ticket Data

![Ticket data page](/img/manual/admin/ticket/data.png)

The ticket data page manages external and internal tickets.

## Page Layout

The left side is the ticket category tree; the right side the ticket list. The top switches between "External / Internal".

## Ticket Fields

| Field | Description |
| --- | --- |
| Number / description | Ticket identity and summary |
| Status / priority / SLA | Handling status and timeliness |
| Type | External / internal |
| Contact / phone / email / WeChat | Visitor information |
| Category / department | Business classification |
| Handler / reporter | Processing and creation |
| Process | Associated process |

## Ticket Operations

- **View details**: open the ticket drawer to view the form and flow records
- **Edit**: modify ticket fields
- **Batch delete**: select multiple tickets and delete them
