# Settings

![System settings page](/img/manual/admin/setting.png)

The settings module provides profile management, general settings, and identity verification, helping users personalize the system and maintain personal information.

## Profile

The profile page lets you view and edit basic information:

- **Avatar upload**: click the upload button to change your avatar
- **Username**: view and change the username (note: re-login is required after changing it)
- **Nickname**: change your display nickname
- **Reset password**: click "Reset password" to change the login password
- **Email management**: view the current email and verification status; click "Reset email" to change the bound email
- **Phone management**: view the current phone number and status; click "Reset phone" to change the bound number
- **Bio**: edit your personal introduction

Click the submit button to save changes.

## General Settings

The general settings page provides interface and language configuration:

### Color Theme

- **Light mode**: default light theme
- **Dark mode**: eye-friendly dark theme
- **Follow system**: follow the OS theme automatically

### Language Settings

- **English**
- **Simplified Chinese**
- **Traditional Chinese**

The system switches to the selected language immediately.

## Identity Verification

The verification module validates personal identity information to improve account security:

### Personal Verification

- **Email verification**: verify your email address; it is then marked "Verified"
  - If not verified, click "Verify email" to start
  - The process requires the code sent to your mailbox

- **Phone verification**: verify your phone number; it is then marked "Verified"
  - If not verified, click "Verify phone" to start
  - The process requires an image captcha and the SMS code

After both verifications your account is more secure and more features become available.

:::tip Tip
- Changing email and phone requires security verification
- Make sure the codes you enter are correct
- Use a strong password when changing it
:::
