# Settings

The system settings module provides profile management, basic preferences, and identity verification features to help users personalize the system and maintain their account information.

## Profile

The profile page lets users view and update their basic information, including:

- **Avatar Upload**: Click the upload button to change your profile picture.
- **Username**: View and update your username. Changing the username requires signing in again.
- **Nickname**: Update your display name.
- **Reset Password**: Click the Reset Password button to change the login password.
- **Email Management**: View the current email address and verification status. Click Reset Email to change the bound email address.
- **Phone Number Management**: View the current phone number and verification status. Click Reset Phone Number to change the bound phone number.
- **Bio**: Update your personal introduction.

After editing your profile, click Submit to save the changes.

## Basic Settings

The basic settings page provides configuration for the interface and language.

### Color Theme

Choose the display theme for the system:

- **Light Mode**: Default light theme.
- **Dark Mode**: Dark theme designed for reduced eye strain.
- **Follow System**: Automatically follows the operating system theme.

### Language Settings

Choose the display language for the system:

- **English**: English interface.
- **Simplified Chinese**: Simplified Chinese interface.
- **Traditional Chinese**: Traditional Chinese interface.

The system switches to the selected language immediately after the change.

## Identity Verification

The identity verification module helps users verify personal contact information and improve account security.

### Personal Verification

- **Email Verification**: Verify your email address. After verification, it is marked as Verified.
  - If the email is not verified, click Verify Email to start verification.
  - During verification, enter the code sent to your email inbox.

- **Phone Verification**: Verify your phone number. After verification, it is marked as Verified.
  - If the phone number is not verified, click Verify Phone Number to start verification.
  - During verification, complete the image captcha and enter the SMS verification code.

After completing email and phone verification, your account becomes more secure and more system features become available.

:::tip

- Updating an email address or phone number requires a security check.
- Make sure the verification codes are entered correctly.
- Use a strong password when changing your password.

:::
