# Quick Reply Management

![Quick reply page](/img/manual/admin/kb/quickreply.png)

Quick replies are a key feature of the customer service system. They help agents answer common questions efficiently and improve productivity and service quality. This guide shows how to manage and use quick replies.

## Overview

The quick reply system provides:

- **Create and edit**: add common replies with rich-text support
- **Category management**: organize quick replies by category
- **Status control**: enable or disable specific replies
- **Batch operations**: batch delete, enable, or disable
- **Import and export**: Excel import/export
- **Content types**: text, image, video, audio, and file

## Quick Reply List

The list shows:

- **Title**: name of the quick reply
- **Content**: the reply content
- **Type**: content type (text, image, video, file, etc.)
- **Shortcut**: hotkey for quick invocation
- **Status**: enabled or not
- **Category**: the category it belongs to
- **Tags**: associated tags
- **Effective time**: validity window
- **Updated**: last update time

## Creating a Quick Reply

1. Click "New quick reply" in the upper-right corner
2. Fill in the form:
   - **Category**: select the category
   - **Type**: content type (text, image, video, audio, file)
   - **Title**: enter the title or name
   - **Reply**: write the content in the rich-text editor
3. Click "Save"

## Editing a Quick Reply

1. Find the target reply in the list
2. Click "Edit"
3. Modify the fields in the form
4. Click "Save"

## Deleting a Quick Reply

1. Find the target reply
2. Click "Delete"
3. Confirm in the dialog

## Batch Operations

1. Select multiple replies (check the boxes)
2. Click a batch action:
   - **Batch delete**: remove all selected replies
   - **Batch enable**: enable the selected replies
   - **Batch disable**: disable the selected replies

## Import and Export

### Importing

1. Click "Import quick replies"
2. Drag or select an Excel/CSV file to upload
3. The system processes the data and appends it to the list

### Exporting

1. Click "Export quick replies"
2. The system generates an Excel file with all replies under the current filters
3. The file downloads automatically

### Downloading the Template

For bulk import:

1. Click "Download template"
2. Get the standard Excel template
3. Fill in data following the template and import

## Search and Filter

1. Search by title, content, or shortcut in the search box
2. Filter by type, category, or enabled status
3. Save frequently used filters for quick access

## Use Cases

Quick replies are suitable for:

- Answering common questions
- Unifying reply wording
- Sending standard greetings and closings
- Sharing frequently used links or files

## Notes

- Update reply content regularly to keep it accurate and timely
- Categorize and tag replies properly for quick lookup
- Set simple, memorable shortcuts to improve efficiency
- Use effective/expiry times for temporary campaigns or promotions
