# Auto Reply

![Auto reply page](/img/manual/admin/kb/autoreply.png)

Auto replies answer visitors automatically based on keywords or fixed rules.

## Page Layout

The left side is the category tree; the right side shows reply rules.

## Reply Types

| Type | Description |
| --- | --- |
| Keyword reply | Auto-reply with configured content when a keyword matches |
| Fixed reply | Fixed replies for specific scenarios |
