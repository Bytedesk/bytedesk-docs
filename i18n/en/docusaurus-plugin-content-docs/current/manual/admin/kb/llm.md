# LLM Knowledge Base

![LLM knowledge base page](/img/manual/admin/kb/llm.png)

The LLM knowledge base provides vector-retrieval Q&A capability for bots.

## Q&A

Maintain Q&A pairs (FAQ) under the "Q&A" tab.

## Enterprise Capabilities

The Enterprise edition provides additional tabs:

- **Text entry**: enter knowledge text
- **File upload**: upload knowledge files
- **Chunking**: view and manage chunk results
- **Web crawl**: crawl web knowledge
- **Translation**: multilingual translation of knowledge
- **Vector settings**: vector retrieval configuration
