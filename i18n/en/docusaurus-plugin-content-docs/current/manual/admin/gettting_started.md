# Admin Console Quick Start

![Admin console dashboard](/img/manual/admin/welcome-new.png)

The Admin console manages organizations and members, agent and workgroup configuration, knowledge base and AI configuration, and ticket and data analytics. This guide walks you through first-day setup from login to going live.

## Login

1. Sign in to the admin console with an administrator account
2. After login the "Dashboard" page opens by default

The default administrator account is created during system initialization; change the password and bind an email/phone as soon as possible.

## Navigation

The main navigation on the left contains (shown by edition and permission):

| Module | Description |
| --- | --- |
| Dashboard | Organization selection, account verification, statistics |
| Organization | Members, organization, roles, notifications, email, SMS, logs, tasks |
| Online Service | Agents, workgroups, unified routing, conversations, messages, tags, channels |
| Knowledge Base | Articles, LLM knowledge base, auto replies, quick replies, taboo words, uploads |
| AI Assistant | Bots, agents, prompts, LLMs, tools, skills |
| Tickets | Tickets, processes, settings |
| Data Analysis | Online service, tickets, bots |
| Settings | Profile and system settings |

## Recommended Setup Order

1. **Organization and members**: complete organization info, add members, and assign roles
2. **Agents and workgroups**: create agent accounts, workgroups, and routing rules
3. **Channels**: configure web, WeChat, and other access channels
4. **Knowledge base / bots**: upload knowledge, configure auto replies and bots
5. **Tickets**: configure ticket categories, processes, and SLA
6. **Analytics and QA**: configure quality-inspection rules and review data analysis
