# Conversation Management

![Conversation management page](/img/manual/admin/service/thread.png)

Conversation management views and manages all conversations.

## All Conversations

View all conversation records and details.

## Enterprise Tabs

The Enterprise edition provides additional tabs:

| Tab | Description |
| --- | --- |
| Queue | Queues and queue statistics |
| Queue members | Queue members with AI intent/sentiment |
| Ratings | Conversation rating records |
| Transfer / invite | Transfer and invitation records |
| Summary | Conversation summaries |
| Intent / sentiment | AI intent and sentiment analysis |
