# Agent Management

![Agent management page](/img/manual/admin/service/agent-new.png)

Agent management maintains agent accounts, reception configuration, and work status.

## Agent Accounts

View and maintain agent accounts under the "Agents" tab; add, edit, or disable agents.

## Agent Configuration

Under "Agent settings" configure reception behavior, including:

- **Welcome / tips**: greetings and notices when a visitor enters
- **Service / display settings**: reception capability and display style
- **Input association**: input-box suggestion settings
- **Rating**: satisfaction survey settings
- **Pre-chat survey / leave message**: pre-chat questionnaire and offline messages
- **Queue settings**: queueing rules
- **Auto-resolve**: rules for auto-closing conversations
- **Working hours**: reception time range
- **Agent status**: agent status and wrap-up
- **Audio / video**: audio/video conversation capability
- **AI agent**: associated bot/agent
- **Toolbar / quick buttons / right panel**: workspace UI customization

## Agent Status

The Enterprise edition shows agent status logs under the "Agent status" tab.

## Agent Seats

The Enterprise edition manages agent seats under the "Seats" tab.
