# Unified Routing

![Unified routing page](/img/manual/admin/service/unified.png)

Unified routing configures a single reception entry for multiple workgroups or businesses.

## Entry List

Create and maintain unified entries under the "Unified" tab to distribute visitor traffic to different workgroups or bots.

## Entry Configuration

Under "Unified settings" configure display and reception behavior of the unified entry.
