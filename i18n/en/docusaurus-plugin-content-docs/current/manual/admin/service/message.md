# Message Management

![Message management page](/img/manual/admin/service/message.png)

Message management views various conversation messages.

## Feature Tabs

| Tab | Description |
| --- | --- |
| All messages | All message records |
| Leave messages | Visitor offline messages |
| Ratings | Conversation ratings |
| Group messages | Group-chat messages |
| Member messages | One-to-one member messages |
| Taboo messages | Messages hitting taboo words |
