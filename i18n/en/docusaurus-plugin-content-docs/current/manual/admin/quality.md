# Service Quality Inspection

![Quality inspection page](/img/manual/admin/quality.png)

Quality inspection checks and scores conversations.

## Conversation Inspection

Includes the following items:

| Item | Description |
| --- | --- |
| Inspect | Run inspection and scoring on conversations |
| Results | View inspection results |
| Appeals | Handle inspection appeals |
| Statistics | Inspection statistics |

## Manual Inspection Configuration

Consists of inspection schemes, tasks, and rules, defining QA standards and task assignment.

## Intelligent Inspection

Rule-based automatic inspection (results and statistics) for batch auto-scoring.

:::note Note
Intelligent inspection depends on the edition; inspection items and rules are defined by administrators in QA configuration.
:::
