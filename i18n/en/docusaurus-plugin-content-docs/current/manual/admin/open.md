# Open Platform

The open platform manages externally displayed business data such as stores, products, and orders.

## Feature Tabs

| Tab | Description |
| --- | --- |
| Stores | Manage connected stores |
| Products | Manage product information |
| Orders | View and manage orders |
| Bookings | View booking records |
| Consumers | Manage consumer information |
