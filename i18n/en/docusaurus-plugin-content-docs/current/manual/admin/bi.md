# Data Analysis

![Data analysis page](/img/manual/admin/bi.png)

Data analysis provides multiple statistical reports by business dimension.

## Online Service Analysis

Includes conversation, agent, satisfaction, hotword, browsing, and visitor statistics.

## Ticket Service Analysis

Includes ticket, workload, priority, category, and satisfaction statistics.

## Bot Service Analysis

Includes bot statistics, token consumption, and Q&A statistics.

:::note Note
All reports support filtering by time range, organization, department, workgroup, and agent; metric definitions follow the page.
:::
