# Prompt Management

![Prompt management page](/img/manual/admin/ai/prompt.png)

Prompts define the persona, reply rules, and business logic of bots and agents.

## Prompt List

Maintain prompts; create, edit, and delete as needed.

## Prompt Capabilities

- **Details**: view prompt content
- **Optimize**: generate or optimize a prompt from a description
- **Score**: rate prompt effectiveness
- **System prompts**: define system-level prompts
