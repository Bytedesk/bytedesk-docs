# Tool Management

![Tool management page](/img/manual/admin/ai/tools.png)

Tools extend bots and agents with invocable external capabilities.

## Feature Tabs

| Tab | Description |
| --- | --- |
| Tools | Create and maintain tool definitions |
| Invocation logs | View tool invocation records |
| Approval logs | View tool invocation approval records |

:::note Note
Tools must be referenced by a bot or agent and are invoked by the LLM on demand during conversations.
:::
