# LLM Management

![LLM management page](/img/manual/admin/ai/model-new.png)

LLM management configures AI providers and models.

## Page Layout

The left side lists model providers; the right side shows the configuration tabs of the selected provider.

## Supported Providers

The system supports many providers, including Ollama, Zhipu AI, DeepSeek, DashScope, SiliconFlow, Tencent, Baidu, Volcengine, MiniMax, iFlytek Spark, Moonshot, Baichuan, Yi, StepFun, OpenRouter, Groq, Anthropic, OpenAI, Gemini, Coze, Dify, n8n, MaxKB, RagFlow, and more.

## Configuring a Provider

1. Select a provider on the left
2. Fill in the API key and other configuration
3. Test the connection and save

:::tip Tip
Each provider needs its own key; after configuration, models can be selected in bots or agents.
:::
