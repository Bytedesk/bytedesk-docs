# MCP Service Management

MCP (Model Context Protocol) connects external tools and services to bots and agents.

## MCP Server List

Maintain the organization-level MCP server list on the MCP page; add, edit, delete, and test connections.

## Use Cases

Configured MCP servers can be referenced by bots and agents to extend capabilities such as knowledge-base retrieval, order queries, and ticket creation.

:::note Note
MCP servers are organization-level resources, visible within the organization once configured.
:::
