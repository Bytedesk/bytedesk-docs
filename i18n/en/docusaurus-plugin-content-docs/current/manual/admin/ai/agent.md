# AI Agent Management

![AI agent management page](/img/manual/admin/ai/agent.png)

AI agents are LLM-based conversational AI used to build bots with business capabilities.

## Agent List

Create and manage LLM agents under the "Agents" tab.

## Enterprise Capabilities

The Enterprise edition provides additional tabs:

- **TTS**: text-to-speech configuration
- **ASR**: speech recognition configuration
- **ASR hot words**: recognition hot words
- **OCR**: image text recognition
- **Voice cloning**: custom voices
