# Skill Management

![Skill management page](/img/manual/admin/ai/skill.png)

Skills are atomic capabilities a bot can execute, invoked by agents during conversations.

## Skill List

Maintain the skill list; create, edit, and delete as needed.

## Use Cases

Skills can be bound to bots or agents to trigger specific actions in conversations, such as querying information or performing operations.
