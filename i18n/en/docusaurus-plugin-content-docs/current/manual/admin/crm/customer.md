# Customer Management

Customer management maintains visitor and customer information.

## Feature Tabs

| Tab | Description |
| --- | --- |
| Visitors | Visitor list |
| Customers | Customer list |
| Company customers | Company accounts |
| Browsing | Browsing records |
| Blacklist | Visitor blacklist |
| IP blacklist | IP blacklist |

Custom fields are supported, and visitor dynamic tags show their conversation history.
