# Organization Management

![Organization info page](/img/manual/admin/team/org.png)

The organization page maintains organization information and handles join requests.

## Organization Info

View and edit basic organization information under the "Organization info" tab.

## Join Requests

Handle user requests to join the organization under the "Join requests" tab:

1. Review pending requests
2. Approve or reject

:::note Note
The Join-requests tab is visible only when the current account belongs to an organization and has the authorization.
:::
