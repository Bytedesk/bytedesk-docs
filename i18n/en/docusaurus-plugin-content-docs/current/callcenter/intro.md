# Intro

## Quick Trial Guide

Before you start a quick trial of the Bytedesk call center, prepare the following items:

- A desk phone or other landline handset
- An available landline number
- A Dinstar voice gateway for PSTN/SIP integration. See [Dinstar Voice Gateway](./dinstar.md)

After the environment is ready, contact us to get a trial extension number and integration guidance.
