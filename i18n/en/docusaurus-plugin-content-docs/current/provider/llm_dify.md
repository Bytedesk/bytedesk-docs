# LLM Dify

This page explains how to connect Bytedesk to Dify applications and use Dify as the LLM service behind a robot.

:::tip Note

This capability is not available in the community edition. Upgrade to Enterprise or Platform edition first.
:::

## Step 1. Create a Dify Provider in Bytedesk

![llm_provider_dify](/img/provider/dify/llm_provider_dify.png)

## Step 2. Get the API Key from Dify

Open the Dify app list: [https://cloud.dify.ai/apps](https://cloud.dify.ai/apps)

![llm_dify_apps](/img/provider/dify/llm_dify_apps.png)
![llm_dify_apikey](/img/provider/dify/llm_dify_apikey.png)
