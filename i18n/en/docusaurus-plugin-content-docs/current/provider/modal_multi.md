# Multimodal Integration

Bytedesk supports multimodal workflows, which means the system can understand and process images, videos, and audio uploaded by users, then combine that content with the knowledge base to generate more accurate answers.

## Overview

Multimodal integration means the system can accept text, images, video, and audio as input, then turn them into a unified understanding for search, reasoning, and response generation. In Bytedesk, this allows service bots to:

- read and understand uploaded images
- extract useful information from video content
- transcribe and understand audio
- combine multimodal inputs with enterprise knowledge bases

## Summary

Multimodal capabilities extend the service boundary of Bytedesk AI assistants. The system can not only read text, but also understand visual and audio inputs and combine them with internal knowledge for more complete customer support experiences.
