# 平台客服（Platform Service）

「平台客服」为多租户/平台版部署提供一条**用户与商户之间的纠纷处理通道**：当访客（用户）与某个商户的客服沟通中产生纠纷时，访客可以在聊天窗口直接联系平台方客服介入；平台客服也可以在工作台中有边界地跨组织回查相关数据。

该功能默认关闭，仅**超级管理员**可以开启和配置，租户管理员无法修改。

## 这是什么功能

平台客服包含两个互相配合的能力：

1. **访客端「平台客服」按钮**：访客与商户客服聊天时，如果遇到纠纷，可点击工具栏中的「平台客服」按钮，在当前窗口内直接打开与平台官方客服的对话，无需跳转或另开页面。
2. **客服工作台「平台查询」**：平台组织的客服在桌面端工作台左侧分类中选择「平台查询」，先选择一个目标组织（商户），即可只读查看该组织的会话列表、聊天记录和订单，用于了解纠纷的来龙去脉。
3. **客服端平台会话标识**：平台客服的会话列表中，平台会话带有醒目的紫色「平台会话」标签；选中会话后，右侧面板出现专属的「平台会话」标签页，可集中查看关联的原商户会话与发起访客信息。

## 什么情况下使用「平台客服」按钮

- 访客认为商户客服的处理结果不合理，希望平台介入评判；
- 访客与商户之间出现售后争议、承诺不符等纠纷，需要更高一级的协调；
- 访客遇到商户客服无法解决的技术或服务问题，需要平台技术支持。

访客侧使用步骤：

1. 访客在商户的聊天窗口中，点击工具栏的「平台客服」按钮；
2. 窗口右侧会打开一个平台客服对话抽屉；
3. 访客在抽屉内描述纠纷情况并发送；
4. 平台客服在桌面端工作台的会话列表中，可一眼识别带紫色「平台会话」标签的会话；选中后右侧出现「平台会话」标签页，点击「查看聊天记录」即可完整查看该访客与商户客服的原始对话（只读），作为评判依据。

## 如何开启（超级管理员）

1. 使用超级管理员账号登录管理后台；
2. 进入「系统设置」中的**平台客服**分组（`/super/system-config`）；
3. 打开「启用平台客服入口」开关；
4. 按需调整平台客服所属的组织与工作组（默认为系统默认组织下的默认工作组，通常无需修改）；
5. 保存后，刷新任意租户的访客聊天页面，工具栏即出现「平台客服」按钮；关闭开关后按钮消失。

注意：租户管理员的后台中没有任何与此功能相关的配置入口。

## 客服工作台如何识别平台会话

为方便平台客服快速定位纠纷介入会话，桌面端工作台提供了以下入口：

1. **会话列表「平台会话」标签**：凡是访客从商户会话发起平台介入的会话，在左侧会话列表中都会显示紫色「平台会话」标签，与普通会话一眼区分；
2. **右侧「平台会话」标签页**：选中平台会话后，右侧面板会出现「平台会话」标签页，集中展示：
   - **关联原会话**：原会话编号、原组织编号、原会话类型 / 状态 / 更新时间、原会话访客昵称；点击「查看聊天记录」可只读查看该访客与商户客服的原始对话；
   - **发起访客**：当前平台会话访客的头像、昵称与编号，点击「查看完整访客资料」可跳转到访客信息标签页；
3. **会话详情中的来源会话区块**：在「会话详情」标签页中同样保留来源会话信息，两处入口内容一致。

注意：「平台会话」标签页仅平台组织的客服可见；查看原始会话聊天记录为只读，不会切换您当前正在处理的会话，也不会向对方发送任何回执。

## 客服工作台如何先选组织再查询

平台组织的客服（账号属于平台默认组织）可以使用「平台查询」：

1. 在桌面端工作台左侧「分类」中找到「平台查询」（如未显示，可在分类设置「显示选项」中勾选）；
2. 进入后页面顶部有明确说明：您正在以平台客服身份查看所选组织的数据，仅用于处理纠纷与技术支持，数据只读且查询会记录审计日志；
3. **第一步：在顶部组织选择器中搜索并选择要查询的组织**——未选择组织时，查询区域为禁用状态；
4. **第二步：查询数据**——选择组织后，可以：
   - 在「会话」标签中查看该组织的会话列表，点击任一会话即可打开只读的聊天记录抽屉；
   - 在「订单」标签中查看该组织的订单列表（仅企业版/平台版可见，社区版无此标签）；
5. 切换组织或刷新页面后，会回到「未选组织」的初始状态，需要重新选择组织才能继续查询。

## 平台查询能看什么、不能做什么

**能看（只读）：**

- 所选组织的会话列表（访客、类型、状态、时间）；
- 所选组织任一会话的完整聊天记录（含图片、文件等分类浏览）；
- 所选组织的订单列表（企业版/平台版）。

**不能做：**

- 不能跨组织回复、接管、转派、修改、删除任何数据；
- 查看聊天记录时不会切换您当前正在处理的会话，也不会向对方发送任何已读回执；
- 普通租户的客服没有「平台查询」入口，即使直接调用接口传入其他组织的标识也会被系统拒绝。

## 常见问题

**为什么必须先选组织？**
平台查询面向处理具体纠纷场景，强制先选定组织可以避免误查其他组织数据，也让每次查询的范围清晰、可审计。

**为什么有些环境看不到「订单」标签？**
订单数据属于企业版功能。社区版部署没有订单模块，标签会自动隐藏，只保留会话查询。

**为什么我的「分类」里没有「平台查询」？**
仅平台组织（系统默认组织）的客服账号可见该分类；租户组织的客服不可见。如果确认是平台组织账号仍看不到，请在分类上方的「显示选项」中勾选「平台查询」。

**会话列表中的紫色「平台会话」标签是什么意思？**
表示该会话是访客从某个商户会话发起平台介入产生的纠纷会话。仅平台组织的客服可以看到配套的「平台会话」标签页；普通商户会话不会带有此标签。

**访客端按钮开了但不显示？**
请确认：访客聊天的会话已初始化（按钮点击要求会话存在）；开关保存后已刷新页面；配置中的组织与工作组 UID 正确无误。默认配置（默认组织 + 默认工作组）在标准部署下开箱即用。
