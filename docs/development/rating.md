# 满意度评价

满意度评价是微语客服系统的双向反馈功能，支持**访客评价会话**（星级评分 + 文字 + 图片）和**消息级别点赞/点踩**，帮助企业持续改善客服水平。

社区版不支持，请升级到企业版或平台版。请替换 [licenseKey](../development/license.md)
:::

## 会话评价

访客在会话结束后可对整次服务进行综合评价。

### 评价方式

- **星级评分**：1-5 星可视化评分，简单直观
- **文字评语**：可输入详细的评价内容
- **问题解决标记**：标记问题是否已解决
- **图片上传**：支持上传截图等辅助说明

### 评价流程

1. 会话结束后，访客在聊天界面看到评价入口
2. 访客选择星级评分（1-5 星）
3. 可选填写文字评语和标记问题是否解决
4. 提交评价后，客服实时收到评价通知

### 评价更新

- 同一会话多次评价时，以最新评价为准
- 评价结果同步到客服报表，便于绩效分析

## 消息评价

访客可对机器人回复的单个消息进行点赞或点踩，帮助评估和优化机器人回答质量。

### 消息评价方式

- **点赞**：表示回答有帮助
- **点踩**：表示回答不满意，可选择不满意原因（如"答非所问""内容不完整"等）

### 应用价值

- **知识库优化**：通过点踩数据识别低质量回答，触发内容更新
- **机器人优化**：收集负面反馈，持续改进回复策略
- **质量监控**：管理员可在后台查看消息评价数据

## 管理后台统计

管理员可在后台查看满意度相关数据：

- **会话评价列表**：按会话维度查看所有评价
- **消息评价列表**：按消息维度查看点赞/点踩数据
- **满意度仪表盘**：可视化的满意度趋势图和统计指标
- **评价 Tab 组件**：可在其他页面嵌入评价数据

## 通知机制

| 通知方式 | 触发场景 |
| --- | --- |
| 实时消息 | 评价提交或取消时通知客服 |
| 会话记录 | 评价完成后自动插入会话时间线 |
| 邮件/短信 | 可配置邮件或短信通知（需额外配置） |

## 注意事项

1. **版本要求**：会话评价功能需要企业版或平台版
2. **幂等性**：同一会话多次评价以最新为准
3. **邀请评价**：客服可主动邀请客户评价（功能开发中）
