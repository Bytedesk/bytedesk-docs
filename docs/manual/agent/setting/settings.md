# 设置

设置页面用于维护个人资料、调整界面与通知偏好。

![设置页面](/img/manual/agent/setting.png)

## 个人信息

在「个人信息」中可维护：

- **头像**：上传个人头像
- **昵称**：显示昵称
- **邮箱 / 手机号**：账号绑定信息
- **简介**：个人介绍

## 客服设置

客服角色账号可在「客服设置」中维护客服资料：头像、昵称、邮箱、手机号、描述等。

## 基本设置

基本设置提供以下选项：

| 设置项 | 说明 |
| --- | --- |
| 消息提示音 | 新消息声音提醒 |
| 网络状态通知 | 断线重连提醒 |
| 消息通知 | 桌面通知 |
| 客服助手开关 | 开启/关闭 AI 客服助手 |
| 订单信息开关 | 会话中显示订单信息 |
| 主题 | 明亮 / 黑暗 / 跟随系统 |
| 语言 | 界面语言 |
| 翻译设置 | 翻译提供商与目标语言 |
| 模式 | 团队 / 客服 / 个人模式 |

其中几个常用选项说明：

- **自动接入下一位排队访客**：开启后结束当前会话时自动接入排队中的下一位访客，减少手动操作
- **主题**：切换明亮/黑暗模式，或跟随系统自动切换
- **翻译设置**：配置翻译提供商与目标语言后，可在消息右键菜单中使用消息翻译

:::tip 提示
建议开启「消息通知」与「消息提示音」，避免漏接新会话；夜间值班可切换黑暗模式。
:::

## 通知

「通知」标签显示系统通知列表，包括：

- **转接/邀请请求**：同事发起的转接或邀请
- **转接/邀请结果**：成功、拒绝、超时、取消
- **新工单通知**：工单编号、优先级、状态

支持查看、标记已读、全部标为已读、刷新。

## 收藏

「收藏」标签聚合你在对话中收藏的消息，便于快速回顾与复用。
