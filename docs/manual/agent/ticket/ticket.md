# 工单管理

工单用于记录需要跟进处理的问题，支持从会话直接创建，并在客服之间流转、转派直至解决与验证。

## 工单列表

工单页面左侧为筛选区，右侧为工单列表。

![工单工作台](/img/manual/agent/ticket.png)

宽屏下工单工作台完整展示筛选区与列表：

![工单工作台宽屏布局](/img/manual/agent/ticket-wide.png)

### 筛选

可按以下维度筛选工单：

| 维度 | 可选值 |
| --- | --- |
| 状态 | 全部状态、新创建、处理中、挂起、重新打开、已解决、已关闭、已验证 |
| 优先级 | 最低、低、中、高、紧急、严重 |
| 分配 | 全部、我创建的、分配给我的、未分配 |
| 时间 | 全部、今日、昨日、本周、上周、本月、上月 |

### 列表字段

工单列表显示：工单编号、描述摘要、类型标签、状态标签、优先级标签、更新时间。顶部提供搜索框、刷新按钮、创建工单按钮与工单总数。

## 创建工单

1. 点击工单页面顶部的「创建工单」按钮，或在会话窗口顶部点击「创建工单」
2. 填写工单信息：
   - **标题、问题摘要、描述**：说明问题
   - **紧急程度、分类**：选择优先级与业务分类
   - **客户、处理人、报告人、工作组、部门**：关联人员与组织
   - **联系称呼、联系电话、联系邮箱、联系微信**：访客联系方式
   - **渠道来源**：工单来源渠道
3. 可选择「关联访客会话」，将工单与当前会话绑定
4. 上传必要附件后保存

## 工单详情

点击工单进入详情，包含对话窗口与右侧「工单详情」「流转过程」标签：

![工单详情与认领指派](/img/manual/agent/ticket-detail.png)

- **工单详情**：查看与编辑工单字段
- **流转过程**：查看工单的状态流转与处理记录

## 处理工单

工单支持以下操作（按状态与权限显示）：

| 操作 | 说明 |
| --- | --- |
| 编辑 | 修改工单字段 |
| 指派 | 指定处理人 |
| 关闭 | 关闭工单 |
| 重新打开 | 重新打开已关闭工单 |
| 验证 | 验证工单处理结果 |
| 邀请 | 邀请其他成员参与处理 |
| 委托 | 委托他人处理 |
| 抄送 | 抄送给相关人员 |
| 加签 | 增加处理意见 |
| 退回 | 退回上一环节 |
| 撤销 | 撤销操作 |

## 工单状态

工单状态全集如下：

- **新创建**：工单刚创建
- **已分配**：已指定处理人
- **已认领**：处理人已认领
- **处理中**：正在处理
- **挂起**：暂时挂起
- **重新打开**：已解决或关闭后重新打开
- **已转派**：已转派给他人
- **已解决**：处理完成，等待验证
- **已关闭**：工单关闭
- **已取消**：工单取消
- **验证通过 / 验证失败**：访客或报告人对解决结果的确认

:::note 说明
工单状态与流程由管理员在管理后台配置，不同组织的状态流转可能不同。
:::
