# 数据看板

数据看板用于查看会话记录、客户信息与留言。

![数据看板](/img/manual/agent/data.png)

## 会话记录

默认显示会话记录列表：

- 支持按时间范围、会话状态、客服、关键词等条件检索历史会话
- 点击会话可查看完整消息内容与双方信息
- 可将会话导出备份

## 客户管理

查看与维护客户信息：

- **客户资料**：昵称、联系方式、来源渠道、标签等
- **历史会话**：该客户的历史会话列表
- **历史工单**：该客户的历史工单列表

## 留言管理

查看访客在客服离线或非工作时间留下的留言，可逐条跟进处理，处理完成后可标记已处理或转化为工单。

:::note 说明
不同账号按权限可见的数据范围不同；在线客服统计、工单统计等高级报表按版本与权限显示。
:::
