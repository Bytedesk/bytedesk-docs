# AI 客服助手与机器人

客服工作台内置 AI 能力，帮助客服提升回复效率与服务质量。

![AI 客服助手面板](/img/manual/agent/agent_preview.png)

## 客服助手

客服助手位于会话右侧面板，提供三个能力：

| 能力 | 说明 |
| --- | --- |
| 生成回复 | 根据当前对话生成回复建议 |
| 总结问题 | 生成会话小结 |
| 下一步 | 给出后续处理建议 |

使用方式：

1. 在会话右侧面板打开「客服助手」标签
2. 点击对应能力按钮
3. 查看生成结果，可点击「填入输入框」将建议回复带入输入框
4. 确认后发送

:::tip 提示
客服助手需在设置中开启「客服助手」开关，并配置相应的大模型。
:::

## 机器人协同

机器人可在客服离线或繁忙时自动接待访客，并可随时转人工：

- **机器人接待**：访客进入「机器人会话」分类，由机器人自动回复
- **转人工**：机器人无法解决或访客要求人工时，会话转入「排队中」等待客服接入
- **客服接管**：客服可从机器人会话直接接管，继续与访客对话

## 机器人管理

工作台的「机器人」页面可查看与管理机器人账号：

1. 左侧选择机器人分类，右侧查看机器人列表
2. 支持添加、编辑、删除机器人
3. 每个机器人可配置：
   - **大模型**：供应商、模型、温度、Top P、Top K、上下文消息数、最大 Tokens
   - **知识库**：启用与检索类型、知识库选择
   - **提示词**：机器人人设与回复规则
   - **默认回复**：未命中知识库时的兜底回复

:::note 说明
机器人的完整配置通常在管理后台「智能助手」模块进行，工作台侧侧重日常使用与快速调整。
:::
