# 待办与日历

待办页面包含日历与待办清单，帮助客服安排与跟踪任务。

![待办页面](/img/manual/agent/todo.png)

## 日历

日历以月视图展示日程与任务分布：

- 点击日期可快速查看当天安排
- 日程条目按类型着色区分
- 可在日历中直接创建新的日程或任务

## 待办

待办清单集中展示需要处理的任务：

- **待处理**：新建或分配给自己、尚未开始的任务
- **进行中**：正在处理的任务
- **已完成**：已完成的任务

对待办任务可执行：查看详情、标记完成、更新进度、删除等操作。

## 典型用法

1. 上班后打开「待办」查看当日待处理任务，按优先级安排工作
2. 接待过程中答应访客的跟进事项，及时创建为待办
3. 完成后勾选标记，保持任务闭环

:::note 说明
待办与日历分别需要相应权限；无权限时页面显示提示，请联系管理员开通。
:::
