# 机器人接待

机器人可在人工客服接入前回答常见问题，也可在非工作时间提供基础服务。机器人能否使用知识库、工具或转人工能力，由企业管理员配置。

## 开始提问

1. 在输入框中用一句话说明主要问题。
2. 补充必要的产品名称、订单场景或错误现象。
3. 等待机器人完成回答。流式回答过程中内容会逐步显示。

一次只问一个明确问题通常更容易获得准确答案。涉及密码、验证码、支付凭据等敏感信息时，不要直接发送。

## 快捷问题与推荐内容

聊天页可能显示欢迎语、热门问题、“猜你想问”或常见问题。点击问题后，系统会直接发送或展示对应答案，可用于快速了解高频业务。

推荐内容来自当前企业配置，因此不同咨询入口显示的内容可能不同。

## 评价机器人回答

机器人回答下方可能显示“有帮助”和“没帮助”：

- 回答解决问题时点击“有帮助”；
- 回答不准确、过时或与问题无关时点击“没帮助”；
- 继续补充上下文，或转人工处理复杂问题。

反馈可帮助企业改进知识库，但不会替代正式的服务评价。

## 转人工

出现以下情况时建议转人工：

- 机器人连续多次未理解问题；
- 需要核验账号、订单或其他业务数据；
- 需要人工审批、退款、投诉或异常处理；
- 回答提示未找到相应答案。

点击“转人工”后，根据页面提示等待接入或排队。客服离线时，可改为提交留言或工单。

## 使用限制

- 机器人回答由 AI 或知识库生成时，请结合实际业务信息判断；
- 不要把机器人回复作为法律、医疗、财务等专业决定的唯一依据；
- 工具调用、订单查询和其他业务操作只有在管理员明确开启并授权后才可用；
- 页面未显示思考过程、来源或反馈按钮，不代表系统异常，可能是当前机器人未启用相应功能。
