# 我的工单

“我的工单”用于提交需要持续跟踪的服务请求，并查看客服或处理部门的进度。访客工单与聊天应用独立运行，但会共享当前企业和访客身份。

## 打开工单中心

![访客工单中心](/img/manual/ticket/gettting_started.png)

您可以从聊天工具栏点击“工单”，也可以打开企业提供的工单链接。进入后，页面会显示当前访客在该企业下提交的工单，不按聊天工作组拆分。

匿名访客的工单身份依赖当前浏览器保存的信息。若需要跨设备长期查看，建议先登录。

## 查看和搜索工单

![工单列表](/img/manual/ticket/list.png)

工单列表通常显示工单编号、标题、状态、紧急程度、问题分类和更新时间。可按页面提供的条件搜索：

- 输入完整或部分工单编号；编号前带 `#` 时系统也会尝试识别；
- 按问题描述中的关键词搜索；
- 按状态或问题分类筛选。

## 创建工单

![创建工单表单](/img/manual/ticket/create-filled.png)

1. 点击“创建工单”。
2. 填写问题描述，必要时调整自动生成的标题。
3. 选择紧急程度和问题分类。
4. 填写称呼、手机号、邮箱或微信等页面要求的联系方式。
5. 按动态表单补充业务字段，并上传必要附件。
6. 检查信息后提交。

部分环境提供“智能填写”，可根据描述辅助填写字段。提交前仍需自行核对内容。未完成的联系方式可能保存在当前浏览器草稿中，公共设备使用后请及时清理。

## 查看详情与处理流程

点击列表中的“查看”，详情抽屉包含两个页签：

![工单详情](/img/manual/ticket/detail.png)

- **工单详情**：编号、状态、紧急程度、描述、分类、提交人、处理人、联系方式、时间、渠道、自定义字段和附件；
- **处理流程**：按时间显示工单活动、处理人、处理时间和备注。

![工单处理流程时间线](/img/manual/ticket/detail-timeline.png)

## 与处理人员沟通

页面提供工单会话入口时，可打开工单聊天继续补充信息。请围绕当前工单回复，新的独立问题建议创建新工单，避免处理记录混杂。

## 确认解决或未解决

处理人员将工单标记为“已解决”后，符合条件的访客会看到验证操作：

- 点击“确认解决”，工单进入验证通过后的结束状态；
- 点击“未解决”，工单退回继续处理。

提交验证前请确认问题现状。操作成功后按钮可能消失或禁用，避免重复提交。

## 工单通知

通知页面用于查看工单创建、状态变化和处理进度等消息。打开通知后，可按页面提供的入口进入对应工单。

## 常见问题

| 现象 | 处理建议 |
| --- | --- |
| 列表为空 | 确认当前组织、账号或匿名访客身份与提交时一致 |
| 搜索不到编号 | 尝试去掉空格，仅输入编号主体或部分编号 |
| 无法提交 | 检查必填字段、联系方式、附件大小和网络状态 |
| 没有验证按钮 | 仅已进入访客验证阶段且当前访客有权限时显示 |
| 无法继续发消息 | 工单可能已关闭或当前状态不允许继续回复 |
