# 登录与匿名访问

访客可以直接匿名咨询，也可以使用企业提供的账号登录。是否显示账号、手机号或扫码登录，由当前部署和管理员配置决定。

## 匿名访问

从企业提供的客服链接打开聊天页后，系统会自动建立匿名访客身份。匿名访问无需输入账号，适合一次性咨询。

匿名身份通常保存在当前浏览器中。清理浏览器数据、更换浏览器或设备后，系统可能无法继续识别原身份，因此重要问题建议登录后再提交工单。

## 账号密码登录

![访客端登录窗口](/img/manual/chat/auth/login.png)

1. 打开登录页面。
2. 输入账号和密码。
3. 根据页面提示完成验证码或隐私协议确认。
4. 点击“登录”。

登录成功后，系统返回聊天页。连续多次输入错误密码可能触发剩余次数提示或临时锁定，请等待锁定时间结束或联系管理员。

:::warning 账号安全
仅在可信设备上使用“记住密码”。公共电脑使用完毕后应退出账号，并清理浏览器保存的登录信息。
:::

## 手机号登录

1. 切换到手机号登录。
2. 输入手机号并获取验证码。
3. 输入有效验证码，确认隐私协议后登录。

收不到验证码时，请检查手机号、发送间隔和网络状态。短信服务未配置或账号未绑定手机号时，需要联系服务提供方处理。

## 扫码登录

当页面显示扫码登录入口时：

1. 使用页面指定的移动端扫描二维码；
2. 移动端确认登录；
3. 等待网页自动进入聊天页。

二维码会过期。页面提示已过期时，请刷新二维码后重新扫码。部分部署会关闭扫码登录，此时使用账号或手机号登录。

## 注册与服务器切换

- 如果登录页提供“注册”入口，可按页面要求创建账号；是否允许注册由部署方决定。
- 私有部署环境可能提供服务器切换入口，用于配置 API 和 WebSocket 服务地址。普通用户不要修改；地址错误会导致无法登录或收发消息。

## 登录失败排查

| 现象 | 处理建议 |
| --- | --- |
| 用户名或密码错误 | 检查大小写和输入法，不要连续反复尝试 |
| 验证码错误或过期 | 刷新验证码后重新输入 |
| 账号被锁定 | 等待提示的时间结束，或联系管理员解锁 |
| 页面一直加载 | 检查网络并刷新；私有部署用户确认服务器地址 |
| 登录后没有历史记录 | 确认使用的是同一账号、组织和服务器 |

登录并不是发起咨询的必要条件。若企业允许匿名访问，可返回[快速开始](../gettting_started.md)直接咨询。
