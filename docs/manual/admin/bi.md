# 数据分析

![数据分析页面](/img/manual/admin/bi.png)

数据分析按业务维度提供多类统计报表，包含三大板块：**在线客服、工单统计、AI机器人**。支持按日期（今日/昨日/本周/上周/本月/自定义）、组织等维度筛选，并可刷新、导出报表。

## 在线客服分析

包含以下子报表：

| 子报表 | 说明 |
| --- | --- |
| 会话统计 | 今日会话总数、进行中、接通率、平均等待/响应/会话时长、放弃率、满意度、消息量等 |
| 客服统计 | 按客服汇总的接待量、响应时长、满意度等 |
| 满意度统计 | 评价分布与趋势 |
| 热词统计 | 会话高频词分析 |

## 工单统计

按日期统计工单数量、状态分布、处理情况等。

## AI机器人

机器人会话量、消息量等机器人服务统计。

:::note 说明
各统计报表均支持按时间范围、组织等维度筛选；具体指标口径以页面为准。
:::
