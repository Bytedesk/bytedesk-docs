# 工作台首页

![工作台首页](/img/manual/admin/welcome-new.png)

仪表盘是登录后的默认首页，以「运营概览」为核心，汇总在线客服、工单、客服绩效等关键运营数据。

## 运营概览

页面顶部为运营概览总览，覆盖即时通讯、在线客服、音视频客服、工单系统、知识库、智能助手等模块的整体状态，支持刷新、显示设置与全屏显示。

## 在线客服统计

以指标卡展示：

- **在线客服**：当前在线客服数 / 总数
- **排队会话**：当前排队中的会话数
- **接通率**：会话接通比例
- **平均首响**：平均首次响应时长
- **工单总数** 与 **满意度**

## 会话分析图表

- **会话状态分布**：按状态统计会话数量
- **会话时长分布**：按时长区间统计（单位：会话数）
- **在线客服会话请求时间点**：按小时统计请求人次

## 客服绩效统计

按客服汇总：在线时长、接待会话数、平均响应时间、平均会话时长、满意度评分、工作时长、转接率、首次解决率、超时会话数等指标。

## 平台动态与通知

- **平台动态**：以博客列表形式展示平台发布的内容与公告
- **通知列表**：展示新工单、SLA 预警等系统与业务通知

:::note 说明
统计指标口径与筛选范围以页面实际显示为准；部分统计模块按版本开放。
:::
