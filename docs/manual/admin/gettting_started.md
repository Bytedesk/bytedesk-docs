# 管理后台快速开始

![管理后台工作台首页](/img/manual/admin/welcome-new.png)

管理后台（Admin）用于组织与成员管理、客服与工作组配置、知识库与 AI 配置、工单与数据分析等。本文档帮助你完成从登录到上线接待的首日配置。

## 登录

1. 使用管理员账号登录管理后台
2. 登录后默认进入「工作台」首页

默认管理员账号由系统初始化时创建，正式使用前请尽快修改密码并绑定邮箱/手机号。

## 界面导航

左侧主导航包含以下模块（按版本与权限显示）：

| 模块 | 说明 |
| --- | --- |
| 仪表盘 | 登录后默认首页，运营概览与统计数据 |
| 组织管理 | 成员、角色、任务、通知、邮件、短信、日志、组织 |
| 在线客服 | 一对一、工作组、统一入口、会话、消息、标签、渠道、快捷按钮、表单、节假日、工作流 |
| 智能助手 | 机器人、智能体、提示词、大模型、消息、工具、MCP、技能 |
| 知识库 | 帮助中心、大模型、自动回复、快捷回复、敏感词、上传记录 |
| 工单管理 | 工单、流程、设置 |
| 客户之声 | 意见反馈、社交评论 |
| 营销管理 | 博文 |
| 客户管理 | 客户、线索、商机、产品、合同、标讯 |
| 数据分析 | 在线客服、工单、机器人统计报表 |
| 服务质检 | 会话质检与智能质检 |
| 个人设置 | 个人信息、系统设置、实名认证、通知、AccessToken、WebHook |
| 开放平台 | 店铺、商品、订单等开放能力 |
| 帮助文档 | 跳转官方文档中心 |
| 超级管理 | 平台级管理（仅超级管理员可见） |

## 推荐初始化顺序

1. **组织与成员**：完善组织信息，添加成员并分配角色
2. **客服与工作组**：创建客服账号、工作组与路由规则
3. **渠道**：配置网页、微信等接入渠道
4. **知识库 / 机器人**：上传知识、配置自动回复与机器人
5. **工单**：配置工单分类、流程与 SLA
6. **统计与质检**：配置质检规则，查看数据分析
