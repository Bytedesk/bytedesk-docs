# 角色管理

![角色与权限页面](/img/manual/admin/team/role.png)

角色用于控制成员的权限范围。

## 页面布局

左侧为角色列表，右侧为选中角色的权限配置。

## 创建角色

1. 点击「创建」
2. 填写角色名称，可选择有效期与级别
3. 配置该角色的权限项
4. 保存

## 配置权限

1. 在左侧选择角色
2. 在右侧勾选或取消权限项
3. 保存后该角色下的成员权限即时生效

:::tip 提示
建议按岗位划分角色（如管理员、客服主管、质检员），便于统一授权与审计。
:::
