# 工单数据

![工单数据页面](/img/manual/admin/ticket/data.png)

工单数据页面用于查看与管理外部工单、内部工单。

## 页面布局

左侧为工单分类树，右侧为工单列表，顶部可切换「外部工单 / 内部工单」。

## 工单字段

工单列表显示以下字段：

| 字段 | 说明 |
| --- | --- |
| 工单编号 / 描述 | 工单标识与摘要 |
| 状态 / 优先级 / SLA | 处理状态与时效 |
| 类型 | 外部 / 内部 |
| 联系人 / 电话 / 邮箱 / 微信 | 访客信息 |
| 分类 / 部门 | 业务分类与归属 |
| 受理人 / 提交人 | 处理与创建人员 |
| 流程 | 关联流程 |

## 工单操作

- **查看详情**：打开工单详情抽屉，查看表单与流转记录
- **编辑**：修改工单字段
- **批量删除**：勾选多个工单后批量删除
