# 工单流程

![工单流程页面](/img/manual/admin/ticket/process.png)

工单流程用于定义工单的状态流转与处理节点。

## 页面布局

左侧为流程类型树，右侧为流程列表。

## 管理流程

- **创建 / 编辑流程**：新建或修改流程定义
- **打开流程编辑器**：在可视化编辑器中进行流程编排
- **部署 / 取消部署**：发布或下线流程
- **查看部署信息**：查看部署 ID 与状态

:::note 说明
部署后的流程才能被工单使用；修改流程后需重新部署生效。
:::
