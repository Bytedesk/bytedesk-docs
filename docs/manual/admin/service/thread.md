# 会话管理

![会话管理页面](/img/manual/admin/service/thread.png)

会话管理用于查看与管理全部会话。

## 全部会话

查看所有会话记录与详情。

## 企业版标签

企业版额外提供以下标签：

| 标签 | 说明 |
| --- | --- |
| 队列 | 排队队列与统计 |
| 队列成员 | 队列成员与 AI 意图/情绪识别 |
| 评价 | 会话评价记录 |
| 转接 / 邀请 | 转接与邀请记录 |
| 总结 | 会话总结 |
| 意图 / 情绪 | AI 意图与情绪分析 |
