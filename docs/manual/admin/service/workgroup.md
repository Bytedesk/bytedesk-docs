# 工作组管理

![工作组管理页面](/img/manual/admin/service/workgroup.png)

工作组将客服组织为接待团队，并配置路由规则。

## 工作组

在「工作组」标签中创建与维护工作组。

## 工作组配置

在「工作组配置」标签中配置工作组的接待行为，子项与客服配置类似，并额外包含：

- **机器人 / 智能体**：工作组机器人
- **转人工**：机器人转人工规则
- **触发器**：自动触发规则

## 工作组路由

在「工作组路由」标签中配置访客分配到工作组的路由规则。

## 手动接入路由

在「手动接入路由」标签中查看等待手动接入的路由池会话。
