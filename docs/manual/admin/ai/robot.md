# 机器人管理

![机器人管理页面](/img/manual/admin/ai/robot-new.png)

机器人用于自动接待访客、回答常见问题并支持转人工。

## 机器人账号

在「机器人账号」标签中创建与维护机器人账号。

## 机器人配置

在「机器人配置」标签中配置机器人的接待行为：

- **欢迎语 / 提示信息**：机器人问候
- **服务 / 展示设置**：接待能力与样式
- **智能体**：绑定大模型智能体
- **右侧设置**：对话界面定制
- **触发器**：自动触发规则
- **工具**：机器人可调用的工具

## 关联知识库

机器人需关联知识库才能回答业务问题：

1. 在机器人配置中选择知识库
2. 设置检索类型
3. 保存后机器人即可基于知识库回答

:::note 说明
机器人回答不了或访客要求人工时，可自动或手动转接到人工客服。
:::
