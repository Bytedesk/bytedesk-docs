# 大模型知识库

![大模型知识库页面](/img/manual/admin/kb/llm.png)

大模型知识库为机器人提供基于向量检索的问答能力。

## Q&A

在「Q&A」标签中维护问答对（FAQ）。

## 企业版能力

企业版额外提供以下标签：

- **文本录入**：录入知识文本
- **文件上传**：上传知识文件
- **文件切块**：查看与管理切块结果
- **网页抓取**：抓取网页知识
- **翻译**：知识多语言翻译
- **向量配置**：向量检索配置
