# 企业微信智能机器人（长连接）

## 功能简介

微语支持通过「长连接」方式对接企业微信**智能机器人**。连接成功后，你在企业微信管理后台创建的智能机器人，将由微语的 AI 机器人作为「大脑」驱动，自动接收和回复客户消息。整个过程无需配置回调地址、无需编写代码，完成配置后即可投入使用。

这类机器人更适合“客户与机器人一对一对话”的场景，例如智能咨询、业务答疑、线索收集和服务分流。同时，它也可以被添加到企业微信内部群聊中，在群内通过 @ 机器人 的方式参与对话。如果你要对比传统 Webhook 方式，请同时参考[企业微信群聊机器人](./wechat_work_group_robot.md)。

:::tip 前置条件

- 仅企业版和平台版支持此功能。如需开通，请[扫码联系微信](/img/wechat.png)
- 企业微信**后台没有创建智能机器人的入口**，创建入口在企业微信 PC 客户端
- 请先在微语后台准备好可用的 AI 机器人；如需人工协同，建议同时准备好对应工作组
:::

## 第一步：在企业微信 PC 客户端创建智能机器人

1. 打开企业微信 PC 客户端，进入「通讯录 → 智能机器人」
2. 点击「创建智能机器人」

![企业微信客户端中的智能机器人入口](/img/wechat_work/wechat_work_create_bot.png)

1. 在创建页面填写机器人名称、简介等基础信息
2. 选择 **API 模式**，用于与微语建立连接

![在企业微信客户端中选择 API 模式创建机器人](/img/wechat_work/wechat_work_create_bot_2.png)

1. 在 API 配置中选择**长连接**方式
2. 记录页面展示的 **BotID** 和 **Secret**，下一步绑定微语时需要使用

![在企业微信客户端中获取 BotID 和 Secret](/img/wechat_work/wechat_work_create_bot_3.png)

## 第二步：在微语后台绑定机器人

1. 登录微语管理后台
2. 进入「渠道 → 企业微信机器人」
3. 点击「绑定」，填写表单：

![微语后台绑定企业微信智能机器人](/img/wechat_work/wechat_work_bot_bytedesk.png)

| 字段 | 说明 |
| --- | --- |
| 名称 | 用于识别该机器人 |
| BotID | 企业微信 PC 客户端中，智能机器人 API 模式下发的 BotID |
| Secret | 企业微信 PC 客户端中，智能机器人 API 模式下发的 Secret |
| AI 机器人 | 选择作为问答大脑的微语 AI 机器人 |
| 路由工作组 | 机器人会话路由到的工作组（客服协同） |
| WebSocket 地址 | 默认 `wss://openws.work.weixin.qq.com`，私有部署可覆盖 |
| 是否启用 | 是否在启动时自动建立连接 |

1. 点击「保存」

如果你希望机器人先自动回复，再在需要时转给人工，建议在这里一并配置好 AI 机器人和路由工作组。

## 第三步：建立长连接

保存后点击「连接」，微语会与企业微信建立持久的 WebSocket 长连接。连接成功后状态显示为 **CONNECTED**。如果你只是想确认当前连通情况，也可以在详情页中刷新或查看状态。

- **CONNECTING** — 正在连接
- **CONNECTED** — 已连接，可正常收发消息
- **RECONNECTING** — 连接中断，正在自动重连
- **DISCONNECTED** — 未连接
- **DISABLED** — 已禁用

## 第四步：测试效果

你可以通过企业微信客户端直接发起与机器人的一对一对话，验证微语是否已经接管消息处理。

![在企业微信客户端中发起机器人对话](/img/wechat_work/wechat_work_bot_start_chat.png)

进入会话后，向机器人发送一条测试消息，确认微语 AI 机器人能够正常回复。

![机器人一对一对话界面](/img/wechat_work/wechat_work_chat.png)

建议至少验证以下两项：

1. 机器人是否能正常收到消息并返回答案
2. 当 AI 无法独立处理时，是否能按预期路由到目标工作组

## 第五步：按需加入企业微信群聊

如果你的使用场景需要在企业内部群里调用机器人，也可以把该智能机器人添加到群聊中。添加后，可在群里通过 @ 机器人的方式发起对话。

![企业微信内部群聊中的机器人对话示例](/img/wechat_work/wechat_work_group_chat.png)

这种方式适合内部协作、知识问答和群内辅助处理，但它底层仍然是智能机器人长连接能力，而不是传统的群聊 Webhook 机器人。

## 智能机器人 与 群聊机器人 的区别

| | 群聊机器人 | 智能机器人（长连接） |
| --- | --- | --- |
| 对接方式 | Webhook 回调地址 | WebSocket 长连接 |
| 使用场景 | 内部群聊通知、播报、简单自动回复 | 一对一对话，也可被加入企业内部群聊 |
| 配置方式 | 复制 Webhook 地址到微语后台 | 在微语后台绑定企业微信 PC 客户端生成的 BotID + Secret |

群聊（Webhook）机器人的配置，请参考[企业微信群聊机器人](./wechat_work_group_robot.md)。

## 常见问题

**问：状态一直显示 CONNECTING，无法变成 CONNECTED？**

- 请确认 BotID 和 Secret 复制无误
- 请确认该机器人在企业微信中已开启「API 模式（长连接）」
- 请确认服务器可以正常访问 `wss://openws.work.weixin.qq.com`

**问：为什么我在企业微信管理后台里找不到“创建机器人”入口？**

这是正常现象。智能机器人的创建入口不在企业微信管理后台，而在企业微信 PC 客户端的「通讯录 → 智能机器人」中。

**问：刚连接成功，随后又变成 RECONNECTING 或 DISCONNECTED？**

- 先检查企业微信侧配置是否仍然有效
- 再检查服务器网络是否稳定，以及是否存在代理、防火墙或出口策略限制 WebSocket 连接

**问：绑定后可以更换问答大脑吗？**

可以。编辑该机器人，重新选择 AI 机器人或路由工作组后保存即可。

**问：这个功能和企业微信群聊机器人有什么区别？**

智能机器人（长连接）主要用于客户与机器人一对一会话，也可以加入企业内部群聊；群聊机器人主要用于企业微信群内通知、播报和简单自动回复。两者接入方式、使用场景和配置项都不同。

**问：智能机器人可以加入企业微信群聊吗？**

可以。你可以先在企业微信客户端中创建并配置好智能机器人，再将其添加到企业内部群聊中，在群里通过 @ 机器人的方式使用。
