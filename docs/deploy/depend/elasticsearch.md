# elasticsearch

:::info Version Dependency

- **Bytedesk 3.x** depends on Elasticsearch **8.18.0**
- **Bytedesk 4.x** depends on Elasticsearch **9.4.2**

Please choose the matching Elasticsearch version according to your Bytedesk version. Version mismatch may cause feature abnormalities.
:::
